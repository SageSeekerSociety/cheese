# 模式 B — 宣传页

官网首页、赛题推广页、活动落地页。人只看一眼就决定走不走，所以这里的目标跟
产品界面**相反**：产品界面追求看一天不累，宣传页追求三秒钟留下印象。

产品界面那套"95% 中性"在这里不适用。但也不是没有约束 —— 品牌得是同一个品牌。

## 锁死的三样

**品牌色是琥珀 `#F57F17`**。用法自由（可以大面积铺、可以做渐变、可以当背景），
但不要换成别的主色。这是唯一让人认出"这是同一个产品"的东西。

深色变体可以取 `#D96E0A`（产品里的 `--accent-press`），淡染可以取 `#FDF1E2`
（`--accent-wash`）。需要更多层次就在这两个之间插值，别引入无关色相。

**字体维持 Bricolage Grotesque（标题）+ Inter（正文）**。中文回退
PingFang SC / 微软雅黑。产品和官网用同一套字，视觉连续性大半来自这里。

**无障碍底线不放松**：键盘焦点必须看得见、正文对比度达标、
`prefers-reduced-motion` 下动效要收敛。宣传页更容易堆动效，也更容易在这里翻车。

## 放开的部分

- **渐变、大色块、强对比** —— 都可以，这是宣传页该有的表现力
- **动效** —— 首屏入场、滚动触发、hover 微交互都可以做
- **技术栈独立** —— 不必用 Vuetify。快速原型用 TailwindCSS CDN 是合理的，
  产品的 token 体系不必搬过来
- **图标** —— 用在线矢量图标库即可。**不要给图标加背景色块、底板或外框**，
  裸图标干净得多
- **图片** —— 用开源图库的直链（Unsplash、Pexels 之类），不要占位灰块

## 响应式是硬要求

桌面和手机都要真的能看。不是加个 `max-width: 100%` 就算数 —— 窄屏下要检查：
标题会不会挤成一团、多列有没有塌成一列、横向有没有溢出、点击目标够不够大。

写完至少在心里过一遍 375px 宽度的样子。

## 别做成模板货

宣传页最大的风险不是难看，是"看着眼熟"。几个已经被用烂的套路，用之前先确认
它真的适合这个内容：

- 巨大数字配小标签 + 三个并排统计块
- `01 / 02 / 03` 编号列表 —— 只有当内容真的是有序流程时才用
- 通篇毛玻璃卡片
- 米白底 + 高对比衬线大标题 + 陶土色点缀
- 纯黑底 + 一个荧光色

不是说不能用，是说别因为"大家都这么做"而用。先想清楚这个页面要讲的那件事
**最有特点的地方**是什么，让它当主角。

## 文案

宣传页的字比产品界面更容易写飘。两条：

**说具体的**。"让团队协作更高效"这种话读者已经免疫了。换成具体能做什么、
具体解决了什么麻烦。

**不要编造**。数字、用户量、案例、引述，没有就不要写。占位文案要明显是占位
（写"[此处待填：真实用户数]"），不要写一个看起来很真的假数字 —— 那种东西
一旦被当真发出去就是事故。
