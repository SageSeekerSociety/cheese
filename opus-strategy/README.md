# 芝士Opus 四人终极策略

这份目录包含主策略和逐卡拉表运行数据，目标模式为 `act3autochess@V3_1` 四人终极。

## 文件

- `botOpus2.js`：动态选盟约、买卡、刷新、冻结、升本、卖卡和阵容评分。
- `botOpusCarry.js`：逐卡拉表的 `mid`、`late`、`boss` 数据。`mid`/`late` 是 R8/R13 边际清怪率，`boss` 是精锐、445 层、60 秒领袖战边际伤害（百万）。

## 接入方式

把两个文件放入模拟器的机器人模块目录，并让 `botOpus2.js` 与同版本的 `bot.js`、`botOpusCarry.js` 一起加载。主策略依赖旧版扩展接口：

```js
createBotPrepSteps
botPickBand
setUnitBonus
sellJunk
```

如果目标模拟器没有 `setUnitBonus`，先适配该扩展点，不要把默认机器人接口直接当成兼容版本运行。当前公开模拟器版本与这份历史策略的接口不完全一致，因此本目录没有把未验证的整局胜率写成结论。

## 运行边界

策略只读取自己的持有、可见商店、公开库存、队友公开盟约和当前回合公开敌人信息，不读取隐藏信息，也不修改游戏规则。

触发分类：

- 获得时：雪猎、灰喉、拜松、仇白、黍等；雪猎按每次获得给所属盟约 `+5` 层。
- 刷新时：拉普兰德、安洁莉娜。
- 本回合每获得一名干员：风絮、夕。
- 休整期或战斗持续：由 `STACKERS` 中的卡处理。

语法检查和 `git diff --check` 已通过；完整整局验证需使用与历史策略匹配的模拟器依赖后执行。
