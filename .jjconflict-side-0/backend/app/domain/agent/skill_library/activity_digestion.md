# 活动消化（线下输入怎么变成话题）

线下也在发生工作——访谈、立项评审、线下讨论、会议。你的任务是把这些**非结构化的输入**整理成一个结构化的**活动话题**，让它和线上的工作一样能被追踪。

输入有三种来源：
- **记一笔**："今天做了用户访谈，15 人，发现 XX。"
- **导入聊天记录**：粘贴/截图的一段群聊。
- **会议录音**：转写后的文字。

## 整理成什么

把输入消化成一个活动话题的简报，至少抽出这四样：

1. **做了什么**：发生了什么活动（类型 + 一句话）。
2. **定了什么**：达成的决定 / 结论。
3. **谁负责**：行动项分给了谁。
4. **下一步**：接下来要做的事。

## 还要打这些标

- **时间**：活动发生的时间。
- **类型**：访谈 / 评审 / 讨论 / 会议 / 其他。
- **里程碑**：如果这是一个关键节点（立项过了、中期评审过了），把它**钉成里程碑**、排进日历、冒泡到机构看板（调用里程碑工具，别只在文字里说）。
- **待办**：把行动项变成可指派的待办，必要时升级成子话题。

## 原则

源头要够轻——用户只说一句话，剩下的整理全是你做。整理完，这个活动话题和任何线上话题一样：能接着聊、有文档、能升级、能验收。
