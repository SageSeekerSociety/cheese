# 修复@点名与换行渲染

## 目标
修掉聊天里的两个体验 bug：① 消息里 @某人 显示成纯文字、点不动；② 人发的多行消息换行被吞成一行。修复须带测试。

## 原因定位
1. **@ 点不动**：平台只把「@显示名」转换成可点的结构化点名标记；大家平时打的是「@账号名」（如 `@andyl`），显示名和账号名不一致时匹配不上，就留成了纯文字。
2. **换行被吞**：前端渲染人发的纯文本消息时保留了换行符，但样式上没有让换行生效（浏览器默认把裸换行折叠成空格）。芝士的回复里单个换行也会被 markdown 规则吞掉。

## 修复内容
- **后端** `app/domain/agent/chat.py`：@点名同时支持显示名和账号名；加了边界保护（`@andy` 不会误吃 `@andyl` 的前半截；已转换好的点名不会被二次包裹；空名字成员不会吞掉正文里所有 @，比如邮箱地址）。
- **前端**：消息渲染逻辑抽成独立模块 `src/lib/renderMessage.ts`（ChatPanel 和通知面板共用，消除了一份重复代码）；人发的消息按「保留换行」渲染；芝士回复里的单个换行按换行显示（聊天语境，不按严格 markdown 折叠）。

## 测试
- 后端：`tests/unit/test_mentions.py` 新增 11 条（账号名/显示名/中文无空格点名/前缀误匹配/空名字等），后端单测共 61 条全过。
- 前端：引入 vitest（`npm test`），`src/lib/renderMessage.spec.ts` 新增 8 条（点名变可点标记、话题引用、换行保留、HTML 注入被转义），全过；`npm run build` 类型检查通过。
