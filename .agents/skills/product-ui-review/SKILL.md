# Product interface review

Every delivery of product interface changes includes a PDF in the user's language, explained from the product user's perspective. A PR link, test report or loose screenshots does not replace this artifact.

Show the current changed screens and explain what users see, what they can do, and any changed limits or unavailable actions. Label sample data and distinguish previews from deployed screens. Describe settings by their effect on users; keep code, database and command details in the engineering report.

Keep the PDF proportional to the change. Give the user the PDF directly with the delivery report, and regenerate it when the interface revision changes.
