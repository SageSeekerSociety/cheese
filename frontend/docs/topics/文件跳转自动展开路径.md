# 文件跳转自动展开路径

## 目标

点消息/文档里的「📄 文件」链接跳到文件面板时，左侧目录树自动展开该文件所在的层层目录并定位到它——之前树默认全收起，跳过去后看不出文件在哪。

## 原因

文件面板（<&frontend/src/components/DocPanel.vue>）的目录树默认全收起，点文件 chip 走的 `openFileRef → selectFile` 只加载文件内容，从不动记录展开状态的 `expandedDirs`。

## 修法（已完成）

在 `selectFile` 成功后调用新增的 `revealInTree(path)`：

1. 把目标文件的每一级父目录都加入展开集合（如 `backend/app/domain/x.py` → 展开 `backend`、`backend/app`、`backend/app/domain`）；
2. 渲染后把高亮的文件行滚动进可视区域。

手动在树里点文件也走同一路径，父目录本就展开，无副作用。

## 验证

- `npm run build`（含 vue-tsc 类型检查）通过。
