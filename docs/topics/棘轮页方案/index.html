⑤ 采集：每合入一次，一份快照

页面只读检查器自己的输出，不重算、不另写评分规则
检查区实际冻结失效豁免状态规则指纹
采集在 arch-metrics.yml 里、合入 main 之后跑：装前后端依赖、按各道检查自己的命令跑一遍、把每道吐出的一条 JSON 记录合成 ratchet-snapshot.json 存进 CI 产物（保留 90 天），后端读最新一份存库。
没跑到的检查记 not_collected，不记 0——命令不在、超时、没吐记录、吐了两行，都算没跑到，快照里 actual 是 null。0 的意思是「量过了，没有问题」，这正是这套东西要避免的说法。
每条记录带规则指纹（判定脚本与配置的 SHA-256；基线文件不算，多冻结一条豁免不是改规则）。指纹一变，本页开一个新的比较起点，前后不画成一条线。
退出码仍是判据：0 通过 / 1 违规 / 2 判不了，--json 只加输出、不改判定；默认模式的 stdout 逐字节不变。
