# 棘轮页方案（评审材料）

当前评审材料只有这两份，别的不再并列：

- `棘轮页方案.pdf`：第三份中文评审稿 —— 用户在这一页上能做什么、真实维度盘点、数据从哪来、页面结构三种做法、已定项、未做与未核实。`pdf.py` 由 `review.typ.tpl` 生成，每个数字是 `snapshot.json` 里的 `%%V:…%%` 占位符，不手抄。
- `棘轮页采集设计.pdf`：采集层设计 —— 快照字段、规则指纹、在哪跑、后端怎么存、历史怎么补、页面据什么判方向。由 `design.typ` 编译。

- `index.html`：可交互预览，`build.py` 由 `template.html` 加采集到的 `snapshot.json` 生成；房间右侧摆的就是它。

数字来自 `snapshot.json` 记的那一次采集（提交与时间写在页面和 PDF 顶部）。界面本身等用户定了页面结构再动；采集这一步是当前这个 PR。

历史：第一份评审稿和第二版预览与采集设计（当时的截图、138 个场景的旧口径数字）留在提交 `74aab1be`、`c4ec0368`，已不再单列，免得和当前数字并列被误读。
