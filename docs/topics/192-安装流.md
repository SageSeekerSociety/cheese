## 范围（本卡净新工作）

1. **新表** `project_git_installations`（project_id FK→projects.id / installation_id / repo / account）+ 迁移，down_revision=`a8c2d4e6f901`
2. **回调路由** `GET /github/app/callback`：校验 HMAC 签名的 state（防伪造，仿 `sandbox_auth.mint_scoped_token` 思路，把 project_id 签进去）+ upsert 落库，redirect 回前端项目设置页（成功/失败都是跳转，不返回 JSON，仿 `users.py` 里 oauth callback 的 try/except-always-redirect 写法）

6. **前端**：项目设置页加"连接 GitHub 仓库"入口（按状态展示已连接的 repo/account，未连接则给安装按钮）+ "连接 GitHub 账号"入口（App user-to-server 授权，与现有 `oauth_github_client_id` 登录态是两条独立流程，不复用）
