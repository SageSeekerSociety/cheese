# 文档内引用语法遵循

## 目标

搞清楚为什么活文档里经常出现裸人名/话题名/文件路径（而不是可点的 @名字 / @话题 / <&文件>），并给出让 AI 稳定遵循的方案。

## 根因（已查明，四条叠加）

1. **规则写错了地方**：引用语法的教学全在 cheese 技能说明（<&backend/sandbox/skills/cheese/SKILL.md>）里，且语境全是"聊天/点名/通知"（"要让某人去做事就 @ 他"、"报告改了哪些文件时用 <&>"）。而专门教怎么写文档的 <&backend/app/domain/agent/skill_library/doc_form.md> **一个字没提引用语法**。模型写文档时激活的是文档规则，自然按普通 markdown 习惯写裸名。
2. **写文档的动作本身脱离"消息模式"**：文档是先 Write 一个 .md 文件再 doc set——模型处在"写 markdown 文件"的心智里，倾向裸路径、裸名、或标准 markdown 链接。
3. **没有服务端兜底**：聊天回复有规范化兜底（<&backend/app/domain/agent/chat.py> 第 932 行 `_expand_mention_names`，把友好写法 `@张衡`/`@话题名` 转成结构化 token）；但文档 PUT、决策、结论、通知正文**都不过这一层**。就算模型偶尔写了 `@张衡`，进文档也只是普通文字（前端 DocPanel 只装饰已是 token 形式的引用）。
4. **提示词自己做了坏示范**：注入 system prompt 的"项目记忆"里的事实本身就是裸文件路径（如 `backend/app/domain/topic/services.py` 原样出现）。模型模仿示例的力量远大于遵守规则——prompt 展示什么形态，它就写什么形态。

## 方案（按投入产出排序）

| # | 改法 | 效果 | 成本 |
|---|---|---|---|
| A | **服务端兜底**：把 `_expand_mention_names` 同样应用到 doc PUT / decision / conclude / notify 正文（@人、@话题两类；改动集中在后端一处） | 确定性修复大部分场景，不依赖模型自觉 | 小 |
| B1 | **doc_form.md 补规则+示例**：加一条核心原则"文档里提人/话题/文件同样用 @名字 / @话题 / <&文件>"，并附 3 行示例文档片段（示例比规则管用） | 提升模型主动遵循率，覆盖 <&文件>（A 管不了这个，路径没有 @ 前缀无法可靠猜） | 小 |
| B2 | **记忆注入时规范化**：项目记忆里的文件路径注入 prompt 前包成 `<&path>`，让 prompt 自身示范正确形态 | 消除坏示范的 few-shot 污染 | 小 |
| C | doc set 时检测疑似裸成员名并在现场标黄提醒（类似 @错人标红） | 反馈回路，兜住长尾 | 中，可后置 |

结论：**A + B1 + B2 一起上**，C 观察效果后再说。文件引用 `<&路径>` 只能靠 B1/B2（提示词），因为裸路径无法像 @名字 那样确定性识别（误伤风险大）。

## 已完成（2026-07-03，@张衡 拍板后实施）

- **A 后端兜底**：规范化逻辑抽到共享模块 <&backend/app/domain/mentions.py>，文档 PUT / 决策 / 结论回流三个写入口都过这一层（<&backend/app/api/routes/topics.py>）；聊天原路径不变。**通知正文有意没上**——通知面板是纯文本渲染，转成 token 反而显示成乱码，等通知面板支持引用 chip 再说。
- **B1**：<&backend/app/domain/agent/skill_library/doc_form.md> 补了"文档里的人/话题/文件也要可点"原则 + 示例片段。
- **B2**：记忆注入 prompt 前把裸相对路径包成 `<&路径>`（<&backend/app/domain/agent/chat.py> 的 `_chipify_paths`，保守匹配：须含斜杠+扩展名；URL/绝对路径/已包的不动）。
- **表格渲染修复**：装 `@tiptap/extension-table` 并在 <&frontend/src/components/DocPanel.vue> 注册 TableKit + 补表格边框样式。修复后本文档上方的方案对比表应能正常显示（可作验收用例），编辑保存也不再丢表格。
- 测试：后端 232 通过（1 个 market 失败与本次无关，是环境配置问题）；前端构建+测试通过；新增 doc 兜底集成测试和路径包装单测。

## 附带发现：文档面板不渲染表格（@张衡 报告"看不到 A/B/C"）

- **根因**：文档面板用 TipTap 编辑器渲染，<&frontend/src/components/DocPanel.vue> 第 753 行只注册了 `StarterKit + Markdown + TokenChips`，没装表格扩展 → markdown 表格在解析阶段被**整块静默丢弃**（前后段落正常）。与引用 chip 装饰、CSS 均无关。
- **数据丢失风险**：面板保存走"编辑器内容序列化写回"，表格加载时已丢，**在文档面板编辑并保存会把表格永久删掉**。
- **聊天侧不受影响**：聊天消息用 marked（GFM 开启）渲染，表格正常，两套管线不共用。
- **修法**（三处）：`npm install @tiptap/extension-table` → DocPanel.vue 引入并注册 `TableKit` → 补 `.doc-prose table/th/td` 最小边框样式。
