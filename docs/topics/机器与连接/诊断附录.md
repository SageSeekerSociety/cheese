## 任务快照备份 500（task 4db75afb，连续三次）

路径：post-commit → cheese sync → git bundle（只含不在 origin/main 的对象）→ PUT /projects/{id}/git/tasks/{id}/snapshots/{sha}（客户端超时 120s）→ 512MiB 上限、digest/magic 校验失败是 422 → R2 上传带服务端 asyncio.timeout(120)，超时/上传错误未捕获 → 500。

结论：500 落在 R2 上传/120s 超时层，push（forge）与备份（R2）是两条独立路径，所以 push 成功、备份 500 不矛盾。大包（二进制多的分支）确定性失败最可能；部署窗口是备选解释。精确定位需要 dev 机后端日志异常类型 + worktree cheese-sync.log 时间戳（都要 sudo），unknown。
