# 现场@渲染排查

## 目标
弄清「@点名显示为原始文本（如 `<@mentor-1>`）」出在哪一层，并把「现场」改成原始内容展示（Claude Code 风格）。

## 结论
- **聊天正文链路是好的**：`renderMessage.ts` 会把 `<@handle>` 换成可点的名字胶囊，8 个单测全过，`收到 <@mentor-1>。` 这类句中标记也实测能正确变胶囊。
- **看到原始标记的地方是「现场」抽屉**，根因：现场之前是"半渲染"——芝士的消息走了 markdown 渲染、但没走点名标记替换那一步，于是排版变了、`<@mentor-1>` 却原样漏出来，看起来像 bug。
- 按 @现场内容改为raw 的决定，现场本来就该展示**原始文本**（类似 Claude Code 的会话记录），半渲染才是偏差。
