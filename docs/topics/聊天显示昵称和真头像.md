# 聊天显示昵称和真头像

## 目标

修好聊天面板（ChatPanel）里**人类消息的作者名和头像**：

- **A（前端）**：消息头显示成员昵称（`fulu`），不是 handle（`wangchangxin`）；头像色块里的字跟着昵称走。
- **B（跨端）**：项目名册接口补 `avatar_id`，前端优先渲染真头像，取不到 / 加载失败再退回彩色首字母。

A+B 一起做、一个 PR 交付 —— @fulu 拍板的范围。上游定位见 @对话内显示名称。

## 关键设计决策（为什么这么写）

- **名字映射只能在前端做。** 消息落库的 `author` 被后端有意钉死成连接认证出来的 handle（防伪造），不能改，也不往消息里冗余存昵称。
- **不复用 `mentionNames` 那张表。** 它额外塞了 `all` / `here` 两个保留键（渲染成「所有人」「在线成员」），一个恰好叫 `all` 的用户会被显示成「所有人」。另建了只由名册铺成的 `memberByHandle`，两处各用各的。已有测试钉住这个边界。
- **头像底色的种子继续用 handle**，只有色块里的**字**改成昵称首字 —— 换成昵称当种子会让每个人的颜色都变一遍，是无意义的视觉扰动。
- **名册上查不到的人（退出项目的、`anonymous` 兜底作者）不去取 `/avatars/default`。** 给陌生人配一张默认脸，不如保留按 handle 哈希、认得出是谁的色块。
- `avatar_id` 按现有 `name` / `agent` 的写法挂在返回字典上，没动 `MemberOut` schema（那是 ORM 模型的投影，本来就没有这一列）。
