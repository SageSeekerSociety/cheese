## 关键约束（已内化）

- note 有 `[:2000]` 长度上限，多写入方会互相顶——新写入要么复用/兼容已有的 `⚠️` 去重前缀家族，要么用独立可辨识前缀，避免把更重要的信息（❌ 部署失败、合并冲突）顶掉。
- 轮询 60 秒一次：任何"每 tick 都写"的实现都会刷屏，必须按状态变化去重（参考 `_nudge_pr_fix` 的 `note.startswith("⚠️")` 套路）。
- 不做数据库迁移/新字段；不改前端；不动 `oauth/services.py`（有未合并 PR #211）；不动 `.github/workflows/`；不改变任何降级/回落的判定逻辑本身，只加可见性。
