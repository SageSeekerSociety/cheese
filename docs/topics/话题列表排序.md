## 目标

话题列表/侧边栏支持按「最后更新时间」「标题」排序，并在列表处加一个可见的排序入口，不破坏现有父子树形结构和已归档分组逻辑。

## 约束

- `Topic` 模型已通过 `Timestamps` mixin 带 `updated_at`（`onupdate` 自动刷新），`TopicOut` 也已返回该字段——**不需要迁移**，这条比父话题调研摘要更明确。
- 排序目标：`backend/app/domain/topic/repositories.py` 的 `list_for_project()` / `list_children()`（目前硬编码 `order_by(Topic.created_at)`）+ 路由 `GET /api/topics`（`backend/app/api/routes/topics.py`）+ 前端 `frontend/src/components/TopicSidebar.vue`。
- `frontend/src/network/api/topics/index.ts` 对接的是无关的 legacy 数字 id 搜索接口（`topics_legacy.py`），不要改错地方。
- 已归档分组（`archivedRows`，按 `archived_at` 倒序硬编码）不用改。
- 父子树形结构（`TopicSidebar.vue` 的 `tree` computed，~L155-192）要保留：排序作用于同一层级内的顺序，不能打散父子挂载关系。
