# 看板文档表格溢出

## 目标

@马霄宇 报的问题：平台右侧那一栏（看板/总览）显示话题文档时，**文档里有表格就会横向溢出**。修掉它。

## 结论：已修，一行 CSS

改的是 <&frontend/src/components/panels/PanelOverview.vue>：给 `.panel-overview` 加一条 `min-width: 0`。

## 为什么是这里

说人话版：flex 布局里，一个格子默认「不肯挤到比自己内容还窄」。表格里那种拆不开的单元格（文件路径、URL、英文标识符）没有可换行的地方，于是整个文档栏被表格顶宽，直接伸到面板右边界外面——外面被上层的 `overflow: hidden` 剪掉，**既看不见也滑不到**，连「只读 / 源码」那排按钮都被顶出屏幕。

代码里这一列每一层都写了 `min-height: 0`，唯独没人管宽度。表格本身其实早就有自己的横向滚动条（`.tableWrapper` 的 `overflow-x: auto`），但**上面那一栏不肯收缩，它就没有机会生效**。让 `.panel-overview` 能收缩之后，滚动条自己就工作了。

实测量出来的数（1440px 窗口、右栏 543px 宽）：

| | 修之前 | 修之后 |
| --- | --- | --- |
| 文档栏宽度 | 773px（超出面板 230px） | 543px（正好） |
| 表格能不能滑 | 不能，直接被剪掉 | 能，滚动区 447 → 677px |
| 页面横向滚动条 | 有 | 无 |

**纯中文表格复现不出来**——中文逐字换行，挤得下。要触发必须让单元格里有拆不开的东西（路径、URL、英文标识符），这也是回归测试里那张表长成那样的原因。

顺带核实过、**不需要**改的地方：`.doc-stage` 和 `.doc-page`（逐个还原试过，不影响结果，所以没留多余 CSS）、项目文档页（ProjectDocsView）、手机端——都已经是好的。

## 验证

- 真浏览器实测（不是读 CSS 推的）：本地起后端 + 前端，用 Playwright 在 1440 / 1100 / 390 三个宽度下量元素盒子，桌面和手机都不再溢出。
- 新增回归测试 <&e2e/tests/doc-panel.spec.ts>：往房间文档塞一张宽表格，断言它不越过面板右边界、表格自己能横向滑、页面没有横向滚动条。**故意把修复撤掉跑过一次，确认它会红**（超出 231px），不是永远绿的假测试。这个 bug 只有真浏览器能看见——jsdom 不排版，组件单测对它一律绿。
- 仓库自带检查全绿：eslint 0 error、stylelint 维持基线、vue-tsc 0 error、脚本测试 21/21、前端单测 956/956、e2e 全套 9/9。
