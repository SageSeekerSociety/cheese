成员页与私聊 · 效果预览

侧栏加一行「成员」，点进去管理项目成员（升职 / 降职 / 踢出 / 邀请）；私聊从每一行直接开，未读也全部收到这里。

这是跑在真代码上的截图（真组件、真样式、真交互），只有数据是编的——预览不该碰任何一个真人的名册，而一份编好的名册正好能把三种角色、AI 队友、未读同时摆进一张图里。

成员页 + 未读搬家

侧栏底部那一整栏私聊撤掉了。未读挂在「成员」这一行上（图里是 3 = 李干 2 条 + 芝士 1 条），进来之后精确到人：谁有未读，数字就长在谁那颗私聊按钮的右上角。用的是琥珀数字而不是红药丸——侧栏原来那颗徽标的注释里写着红圆和石墨药丸都被否过，同一个产品里未读只能有一种读法。

改角色 / 移出（⋯ 菜单）

升职、降职、踢出都在这里。当前角色那一项是灰的。这个菜单只对项目所有者和组长出现——后端本来就只让这两种人写名册。

邀请成员

填 handle、选角色。多打一个 @ 也认。

移出要先确认

菜单里点「移出项目」不会直接把人踢了。下面能看到 AI 队友单独一段。

点私聊 + 左上角的 ← 成员

点行右边的对话图标直接进私聊，标题左边就是回名册的 ←。注意侧栏「成员」上的未读从 3 掉到了 1——李干那 2 条读掉了，剩下芝士那 1 条。手机上顶栏那颗 ← 指的也是成员页，两颗是同一个落点。
