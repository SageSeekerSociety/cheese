# 项目 {#projects}

项目把一件长期要做的事装在一起：里面有话题（和芝士讨论、交代任务的地方）、成员、AI 队友、文件和看板。第一次用知是，建一个个人项目就行。

## 创建项目 {#create-project}

1. 在「我的工作」点「新建项目」，或点左侧导航最下面的「新建项目」按钮。一个项目都还没有时，「空间」页的「从这里开始」里也有这颗按钮。
2. 填写「项目名称」，选择「所属团队」：个人项目保持默认的「个人」；选一个团队，团队成员会自动进入这个项目。
3. 「代码仓库」一般保持默认的「由芝士托管」。要把已有的 GitHub 仓库交给芝士，选「连接 GitHub」，建好后在项目设置里连接。托管方式建好后不能再改。
4. 点击「下一步」，在「项目的 AI 队友」里填「队友名字」，点击「创建项目」。

完成后：进入项目的总览房间。话题怎么用见[话题](/rooms#rooms)。

## 在项目里找到各个页面 {#project-navigation}

- 点侧栏顶部的项目名：进入项目首页，也就是看板，见[任务与看板](/tasks#tasks)。
- 侧栏常驻「资料库」「成员」和「项目文档」，下面是「话题」分组。
- 项目名右边的「项目菜单」里有「日历」和「项目设置」等其余页面。打开过一次的日历会留在侧栏。

## 成员从哪里来 {#project-members}

项目属于团队时，团队成员自动出现在项目「成员」页，不用逐个邀请；他们的加入和退出在团队里管理。团队以外的人，要单独邀请成为「外部成员」。

![项目的「成员」页：按所有者、团队成员、外部成员、等待接受和 AI 队友分组](/images/members.jpg)

「成员」页按「所有者」「团队成员」「外部成员」「等待接受」「AI 队友」分组，右上角可以「搜索名字或用户名」。

## 邀请外部成员 {#invite-project-member}

项目所有者，以及所属团队的所有者和管理员，可以邀请外部成员。

1. 在项目侧栏打开「成员」，点击右上角的「邀请外部成员」。
2. 在「用户名或邮箱」里填对方完整的用户名或邮箱，等页面显示出这个人。
3. 点击「发送邀请」。

完成后：对方出现在「等待接受」里。对方接受前，你可以「撤回」邀请。

受邀者在「团队 → 待定」的「收到的项目邀请」里，点对勾接受、点叉拒绝。接受后就能进入项目。

## 管理外部成员 {#manage-project-member}

能邀请的人，也能在外部成员那一行点「管理成员」，选择「移出项目」。团队成员不在这里移出。

外部成员可以在页面右上角「退出项目」；所有者和管理者可以「转让项目」。其他成员只能查看名单。

## 连接 GitHub 仓库 {#upstream}

只有创建时「代码仓库」选了「连接 GitHub」的项目需要这一步。

1. 在「项目菜单」里打开「项目设置」，找到「仓库」。
2. 填写完整的「GitHub 仓库地址」，点击「保存」。
3. 点击「连接 GitHub 仓库」，按提示授权。

由芝士托管的项目没有这一步；在话题里使用芝士也不要求连接 GitHub。
