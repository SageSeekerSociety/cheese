# 项目 {#projects}

项目是一件事的工作空间，例如一份大作业「B 树大作业」：做这件事的成员、对话和文件都放在这个项目里。

## 新建项目 {#create-project}

点最左侧一列项目图标下方的「＋」（「新建项目」）新建项目。在团队的「项目」页点「新建项目」也可以。新建时要做两个决定：

- 「归属」：选你自己（「你名下，可以另外邀请人」）时，项目只有你一个人，之后可以逐个邀请[外部成员](#project-members)。选一个团队（「团队的 N 位成员会自动加入」）时，团队成员都成为项目成员。
- 「代码仓库」：保持「平台托管（默认）」时，项目文件由平台保存。选「连接 GitHub」时，建好后在「项目设置 → 仓库与署名」连接一个 GitHub 仓库，见[连接 GitHub 仓库](#upstream)。这一项建好后不能再修改。

「你打算做什么（可选）」写一句项目的目标，例如「帮我把这学期的课程材料整理成一份大纲」。下一步给项目的 AI 队友起名字，名字已随机填好，可以修改。点「创建项目」后进入频道「综合」。

建项目的完整过程见[快速开始](/quickstart#project)，在团队下建项目见[和同学一起做一个项目](/team-project#project)。

## 项目里的页面 {#project-navigation}

项目左侧栏最上面是项目名，下面是「总览」和「资料库」，再往下是「频道」分组。分组的第一行是「综合」，最后一行是「浏览频道」。[资料库](/files#library)存放项目的文档和文件，频道的用法见[频道](/rooms#rooms)。

点项目名打开项目菜单。菜单上半部分是「项目文档」「成员」「定时与触发」「技能」和「全部任务」，下半部分是「项目设置」，以及「转让项目」或「退出项目」。

在手机上，「总览」和「资料库」也在这个菜单里，频道列表最上面另有一行「总览」。

## 总览 {#project-home}

「总览」是项目的首页。左侧是「项目总览」和「最近进展」，右侧是「谁在做什么」和「做出了什么」：

![项目「总览」页：项目目标、分工和约定，最近的任务进展，林晓手上的两个任务，以及暂无产物的成果区](/images/overview.jpg)

- 「项目总览」：项目的目标和约定，是一份所有成员都能改的文档。点「编辑」修改；还没写时显示「暂无项目总览」。
- 「最近进展」：最近两周的事，按天排列，例如任务的新建、开始、采纳、退回，以及成果的新版本。点一条打开对应的任务或成果。
- 「谁在做什么」：进行中的任务按负责人分组，你的排在最前面。等你处理的写着「待你审阅」「待你回答」或「待你开始」；「全部任务」打开项目的[全部任务](/tasks#board)。
- 「做出了什么」：采纳后的成果和发布的网站。成果的「⋯」里可以「重命名」「合并到…」和「删除」；网站见[发布网站](/sites#publish)。

## 成员从哪里来 {#project-members}

项目属于团队时，团队成员自动出现在项目的「成员」页，他们的加入和退出在[团队](/teams#teams)里管理。团队以外的人要单独邀请，接受后成为外部成员。外部成员只参与这一个项目，能在频道里发消息、把任务交给芝士，不能新建频道或邀请别人。

「成员」页按「所有者」「团队成员」「外部成员」「等待接受」「AI 队友」分组；成员超过 8 人时，列表上方出现搜索框。

### 邀请外部成员 {#invite-project-member}

在「成员」页右上角点「邀请外部成员」，按完整的用户名或邮箱邀请。项目所有者，以及所属团队的所有者和管理员，有这个权限。对方接受之前，邀请列在「等待接受」下，点「撤回」收回。完整过程见[邀请一个人加入你的项目](/invite-to-project#invite-to-project)。

能邀请的人也能移出外部成员：点外部成员那一行的「⋯」，选「移出项目」。团队成员不在这里移出。

### 转让和退出 {#transfer}

所有者以外的成员在项目菜单或「成员」页右上角点「退出项目」。所有者不能退出，只能「转让项目」：项目所有者和团队的所有者、管理员都能转让。团队下的项目只能转让给团队成员；你名下的项目可以转让给任何人，转让后归到对方名下。

## 项目设置 {#settings}

点项目名，在菜单中点「项目设置」。左侧按组列出各项：

- 「协作」：「频道」「项目地址」。
- 「AI」：「AI 队友」（见 [AI 队友](/agents#agents)）、「任务命名」。
- 「运行」：「环境」，包括新 AI 队友默认使用的环境和项目的额度，见[选择环境](/devices#topic-environment)。
- 「代码」：「合并规则」「仓库与署名」「MCP 服务器」。
- 「数据」：「导出项目」，把代码仓库、资料库文件、各频道的文件与产物和每份文档打包下载。
- 「归档项目」：只有项目所有者看得到。

## 连接 GitHub 仓库 {#upstream}

新建时「代码仓库」选了「连接 GitHub」的项目，在「项目设置 → 仓库与署名」中填写「GitHub 仓库地址」，点「保存」，再点「连接 GitHub 仓库」，按提示授权。

连接要由项目所有者或团队管理员完成。完成的人需要先连接自己的 GitHub 账号，并对这个仓库有写权限。

一个 GitHub 仓库只能连接一个项目。仓库已经连接在别的项目上时，连接失败，提示里写明是哪个项目（你是那个项目的成员时）。

平台托管的项目没有这一步；在频道里使用芝士也不需要 GitHub。

## 归档项目 {#archive-project}

不再使用的项目可以归档，内容全部保留，随时可以取消归档。只有项目所有者能归档和取消归档；平台没有删除项目的入口。

在「项目设置」最下面点「归档项目」，输入项目名称确认，再点「归档」。归档之后：

- 项目从所有成员的项目列表和团队的「项目」页中消失。打开项目链接，看到的是「项目已归档」。
- 项目不能再修改：发消息、建频道、改设置、邀请成员都会被拒绝。
- 正在运行的任务停止，平台回收频道的环境。定时任务不再运行，平台不再跟进项目在 GitHub 上的合并请求（PR）。
- 尚未接受的邀请被撤回。
- 频道、文件、审阅记录、额度用量和仓库连接都保留；已发布的网站仍然打得开。

取消归档：点左下角的头像，打开「已归档的项目」，在那一行点「取消归档」。也可以打开项目链接，在「项目已归档」页点「取消归档」。随项目归档的频道随之恢复，被撤回的邀请不会恢复。
