# 项目 {#projects}

项目把一件长期要做的事装在一起：里面有频道（人说话的地方）、任务、成员、AI 队友和文件。第一次用知是，在自己名下建一个项目就行。

## 创建项目 {#create-project}

建项目时先填项目信息，再给项目的 AI 队友取名字。

1. 点最左侧那一列里、项目方块下面的「＋」，鼠标停在上面会显示「新建项目」。一个项目都还没有时，「待办」页上也有「新建项目」按钮。
2. 填写「项目名称」，选择「归属」：默认是你自己的名字，项目只有你；选一个团队，团队成员会自动进入这个项目。
3. 「代码仓库」一般保持默认的「平台托管（默认）」。要把已有的 GitHub 仓库交给芝士，选「连接 GitHub」，建好后在「项目设置 → 仓库与署名」里连接。托管方式建好后不能再改。
4. 点「下一步」，在「项目的 AI 队友」里填「队友名字」，点「创建项目」。

完成后：进入项目的频道「综合」。频道怎么用见[频道](/rooms#rooms)。

## 在项目里找到各个页面 {#project-navigation}

项目侧栏按下面的方式分了几块：

- 项目名下面是「总览」和「资料库」。「总览」是项目首页，见[总览](#project-home)。
- 再往下是「频道」分组，第一行是「综合」。
- 点项目名弹出项目菜单，里面是「项目文档」「成员」「定时与触发」「全部任务」「项目设置」等其余页面。

在手机上，「总览」「资料库」也在点项目名弹出的菜单里，频道列表最上面也有一行「总览」。

## 总览 {#project-home}

「总览」是项目的首页，在电脑上进项目先到这一页。它分四块：

![项目「总览」：左边是「项目总览」文档和「最近进展」，右边是「谁在做什么」和「做出了什么」](/images/overview.jpg)

- 「项目总览」：显示[项目总览](/rooms#edit-topic-document)这份文档，太长时点「展开全文」。点「编辑」去改；还没写时显示「暂无项目总览」，点「写一份」。
- 「最近进展」：最近两周项目里发生的事，按天排列，比如任务的新建、开始、采纳、完成、关闭、退回、停滞，以及成果的新版本。点一条打开那件任务或那份成果。
- 「谁在做什么」：还在进行的任务按负责人分组。等你的那几件写着「待你审阅」「待你回答」「待你开始」。标题旁的「全部任务」打开[全部任务](/tasks#board)。
- 「做出了什么」：项目采纳的成果和发布的网站。成果可以重命名、合并和删除；网站怎么发布见[发布网站](/sites#publish)。

需要你处理的事不在这一页另列，集中在「待办」里，见[需要你处理的事](/tasks#needs-attention)。

## 成员从哪里来 {#project-members}

项目属于团队时，团队成员自动出现在项目「成员」页，不用逐个邀请；他们的加入和退出在团队里管理。团队以外的人，要单独邀请成为「外部成员」。

![项目的「成员」页：按所有者、团队成员、外部成员、等待接受和 AI 队友分组](/images/members.jpg)

「成员」页按「所有者」「团队成员」「外部成员」「等待接受」「AI 队友」分组，右上角可以「搜索名字或用户名」。

## 邀请外部成员 {#invite-project-member}

项目所有者，以及所属团队的所有者和管理员，可以邀请外部成员。

1. 点侧栏顶部的项目名，在弹出的菜单里打开「成员」，点右上角的「邀请外部成员」。
2. 在「用户名或邮箱」里填对方完整的用户名或邮箱，等页面显示出这个人。
3. 点「发送邀请」。

完成后：对方出现在「等待接受」里。对方接受前，你可以「撤回」邀请。

受邀者会在通知里收到这条邀请，可以直接点「接受」或「拒绝」；也可以在「团队 → 待定」的「收到的项目邀请」里，点对勾接受、点叉拒绝。接受后就能进入项目。

## 管理外部成员 {#manage-project-member}

能邀请的人，也能在外部成员那一行点「管理成员」，选择「移出项目」。团队成员不在这里移出。

每个成员的页面右上角都有「退出项目」，所有者没有这颗按钮，他用「转让项目」。所有者和管理者可以「转让项目」，也可以邀请成员；其他人只能查看名单。

## 连接 GitHub 仓库 {#upstream}

只有创建时「代码仓库」选了「连接 GitHub」的项目需要这一步。

1. 在「项目菜单」里打开「项目设置」，选左边的「仓库与署名」。
2. 填写完整的「GitHub 仓库地址」，点「保存」。
3. 点「连接 GitHub 仓库」，按提示授权。

一个 GitHub 仓库只能连接一个项目；同一组织下的不同仓库可以分别连接不同的项目，组织只需安装一次芝士的 GitHub App。仓库已经连在别的项目上时，连接会失败并说明是哪个项目（你是那个项目的成员时）。

由平台托管的项目没有这一步；在频道里使用芝士也不要求连接 GitHub。

## 归档项目 {#archive-project}

不再用的项目可以归档。归档后它从所有成员的项目列表中移除，内容全部保留，随时可以取消归档。只有项目所有者能归档和取消归档；平台没有删除项目的入口。

1. 在「项目菜单」里打开「项目设置」，选左边最下面的「归档项目」。
2. 点「归档项目」，输入项目名称确认，再点「归档」。

归档之后：

- 项目不再出现在任何成员的项目列表和团队的项目页里。直接打开它的链接，看到的是「项目已归档」。
- 项目不能再修改：发消息、建频道、改设置、邀请成员都会被拒绝。
- 正在运行的任务会停止，频道占用的环境会按频道归档的规则回收；定时任务不再运行，平台也不再跟进它在 GitHub 上的 PR。
- 还没被接受的邀请会被撤回。
- 频道、文件、审阅记录、额度用量和仓库连接都原样保留。

取消归档：打开头像菜单里的「已归档的项目」，在那一行点「取消归档」；或者直接打开项目链接，在「项目已归档」页面点「取消归档」。项目和随它一起归档的频道会恢复；归档之前就已归档的频道仍然留在「已归档」分组里。撤回的邀请不会恢复，需要的话重新邀请。
