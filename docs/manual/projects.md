# 项目 {#projects}

一个项目就是**一处放东西的地方加一支团队**：你和 AI 队友做出来的文件都落在这里，队里的人一起看着它。

## 项目是什么 {#what}

项目里存的不一定是代码——文档、方案、报告、一个能访问的网站，都住在同一个地方。底下用的是 git，所以每一次改动都有记录、都能回溯，但你不需要懂 git 才能用。

它自带这块地方，你什么都不用准备就能开工；也可以在项目设置里关联一个已有的仓库，把历史拉进来。项目归属于一个团队，队里的人默认就是这个项目的成员——不用一个个邀请。一个人用就是「个人」团队，规则完全一样，只是队里只有你。

## 连接你已有的仓库 {#upstream}

在**项目设置 → 上游仓库**里填一个 git 地址，保存之后点「同步上游」，那个仓库的历史就拉进来了。有冲突时同步会原样中止，不会只合一半。

如果还想让[采纳](/accept#accept)变成 GitHub 上的一次真实合并，在同一页点「连接 GitHub 仓库」，把 cheesex-app 装到那个仓库上。装完之后，芝士读 CI 状态、开 PR 需要的临时凭据会按这个连接自动签发，你不用手工配任何 token。
