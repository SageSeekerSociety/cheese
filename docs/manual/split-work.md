# 和同学分头推进 {#split-work}

这一页讲一个小组怎么把一份作业拆成几个任务，每人负责一个，各自和芝士推进，再在看板上看谁做到哪。比如 B 树大作业，林晓负责插入和查找，陈默负责删除，王珊负责实验报告。

开始前，你们已经在同一个项目里，见[和同学一起做一个项目](/team-project#setup)。

## 每人开一个任务 {#own-a-task}

谁建的任务谁负责；在「综合」里各自把自己那一块转成任务。

:::steps

### 在频道里说清分工 {#plan}

先在「综合」里把分工说定，每人一条消息写清自己那一块。

```prompt
我负责插入和查找：3 阶 B 树，插入时节点满了要分裂，查找返回键所在的节点。周五前写完并过测试。
```

```prompt
我负责删除：节点不够时先向兄弟节点借，借不到再合并。要有连续删到只剩根节点的测试。
```

```prompt
我负责实验报告：实现思路、测试结果、复杂度分析三节，复杂度用表格。等代码定了再写测试结果。
```

### 把自己那条转成任务 {#convert}

鼠标停在自己那条消息上，点「转为任务」。

页面进入新任务，页头写着「〈你的名字〉 负责」。频道里那条消息下面多出「已转为任务」，还有一行「@〈你的名字〉 创建了任务「…」，由 @〈你的名字〉 负责」，点「查看任务」能进去。

也可以在侧栏的「综合」上点右键，选「新建任务」，建一个空任务再在里面和芝士说。<!-- 待确认：「新建任务」菜单项在本地看到了，点下去建出空任务未实测 -->

### 在自己的任务里推进 {#work}

任务里的输入框写着「给芝士发消息」，说的话都交给芝士。

```prompt
先把插入和查找的函数接口写进任务文档，我确认后再开始写代码。
```

接口定好后点页头的「开始」，芝士才动手改项目。项目还没有默认审阅人时，先在「审阅人」里选一位同学。

:::

## 请同学帮忙，或者交给别人 {#collaborate}

一个任务需要两个人一起做时，加协作者；自己做不了时，转交。

- 加协作者：点页头的「〈你的名字〉 负责」打开任务信息，在「协作者」里选同学，点「添加协作者」。协作者能在任务里和芝士说话、改任务文档；他自己可以点「退出协作」，你可以点「移除」。
- 转交：点页头右上的「更多操作」，选「转交」，再选新的负责人。
- 关闭：同一个菜单里的「关闭任务」。写下结论表示做完了；不写表示不再做。

只有负责人和协作者能在任务里和芝士说话。别人打开你的任务，页面上写着「只有负责人和协作者可以在这里和芝士对话」，有话回「综合」里说。

## 看谁做到哪 {#progress}

两个地方看进度：频道的「全部任务」和项目看板。

- 「全部任务」：在侧栏「综合」下面那一行。按「全部」「我负责的」「我协作的」「其他人的」筛选，点「已关闭」看已经结束的；右上角也能「新建任务」。侧栏「综合」下面还直接列出你负责和协作的几个任务。
- 看板：点侧栏的「看板」。五列是「未开始」「进行中」「检查中」「待处理」「做出了什么」，每张卡写着任务名、所在频道、负责人和状态（「讨论中」「已开始」「待审阅」等）。
- 「只看我的」：看板右上角的开关。打开后每列只留下分配给你的任务，列头写成「1 / 2」这样的数，没有时写着「暂无分配给你的任务」。

各列的完整含义见[任务与看板](/tasks#board)。

> [!TIP]
> 任务停在「待处理」里时，通常是在等审阅人。打开任务，输入框上方那一条写着待谁审阅，在群里叫那位同学去点「审阅」。
