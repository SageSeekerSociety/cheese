# 学生：在空间里完成第一道题目 {#tut-student}

这篇教程带你走完一道题目：加入老师的空间，领取题目，和芝士一起做完，按要求提交。大约二十分钟。

开始前你需要：一个知是账号，以及老师给的邀请码或课程链接。

## 1. 加入空间 {#join}

打开「我的工作」，在「我加入的空间」一排点「用邀请码加入」，填入邀请码后点「加入」。

老师发的是课程链接时，直接点开即可，系统会自动加入并进入课程。

完成后：「我加入的空间」一排里出现这个空间。

## 2. 找到并领取题目 {#claim}

进入空间，在左侧栏「全部题目」里打开老师布置的题目。先读「概览」里的题目详情、提交类型和截止时间，然后点击顶部的「领取题目」。

完成后：顶部按钮变成「前往提交」。如果显示需要实名信息或团队，按[领取题目](/challenges#claim)里的说明处理。

## 3. 从题目创建项目 {#project}

在「概览」的「项目」一栏点击「从这道题目创建项目」。

完成后：进入新项目的话题，芝士已经在里面了。

## 4. 和芝士一起完成 {#work}

在话题底部说明你要做什么，并点名芝士。例如：

> 这是我的题目要求（粘贴题目详情）。先帮我讲清楚题目要什么，再一起列出要做的几步。

芝士会先复述它的理解，再开始干活。你可以随时插话补充要求；它交付文件时，会出现验收卡，你查看后「采纳」或「退回」，见[验收与采纳](/accept#accept)。

完成后：项目里有你要提交的作品文件。

## 5. 提交 {#submit}

回到题目，点击「前往提交」，按表单填写、上传作品，点击「提交」。

完成后：「提交记录」页里出现这一次提交。只能提交一次的题目，提交前请再检查一遍。
