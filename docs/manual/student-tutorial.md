# 学生：在空间里完成第一道题目 {#tut-student}

这篇教程带你走完一道作业：加入老师的课程，找到这一周的题目，领取并在项目里和芝士一起做完，最后提交。大约二十分钟。

开始前你需要：一个知是账号，以及老师给的课程链接或邀请码。

## 1. 加入课程 {#join}

拿到课程链接就直接点开，只有邀请码就从「我的工作」加入；两种方式都会把你带进这门课。

1. 老师发来课程链接时，直接点开。还没登录会先跳到登录页，登录后回到这条链接。
2. 页面显示「正在把你加进这门课……」，随后进入课程首页。
3. 第一次进入会弹出「要不要找同学组队？」：一个人做点「先一个人」，想先看看小组点「去看看小组」。以后随时可以在「我的小组」里改。
4. 只有邀请码时：打开「我的工作」，在「我加入的空间」一排点「用邀请码加入」，填写「邀请码」后点「加入」。

![课程链接的加入页：显示正在把你加进这门课，完成后进入课程首页](/images/join-course.jpg)

完成后：进入这门课的「我的课程」页。

## 2. 找到这一周的作业 {#week}

学生做作业的入口在课程首页的「本周任务」里。

1. 在课程里打开「我的课程」。
2. 「本周任务」显示「第 N 周」和老师写的那句话：有作业点「去交这一周的作业」，有小测点「去做这一周的小测」。
3. 老师还没发布这一周的内容时，这里显示「老师还没有发布这一周的内容。」，等老师发布后再来。

下面的「我在这门课里做的」列出你要交的每一道题和它的状态：还没交、等老师看、可以重交、没通过、已通过。

![课程首页的学生视图：本周任务卡片上有「去交这一周的作业」，下面是「我在这门课里做的」列表](/images/course-student-home.jpg)

完成后：打开这一周的题目页。

## 3. 读题目详情 {#overview}

题目页的「概览」页签写着这道题要交什么、什么时候交、能交几次。

- 「题目详情」：题目正文；有视频时下面还有「题目视频」（Bilibili）。
- 「题目信息」：「提交类型」（个人任务或团队任务）、「难度等级」、「提交次数」（「可多次提交」或「仅可提交一次」）、「参与者人数限制」或「队伍数量限制」。
- 「时间信息」：「报名截止时间」和「默认提交期限」（领取后多少天内要交）。
- 「项目」：从这道题目建出来的项目。

页面顶部提示需要补实名信息或团队时，先按提示处理：点「前往填写」补实名信息，或先建团队、加入团队，见[团队](/teams#teams)。条件不满足时顶部不会出现「领取题目」。

![题目「概览」页：题目详情、题目信息（提交类型/难度等级/提交次数）、时间信息和项目](/images/task-overview.jpg)

完成后：知道这道题要交什么、什么时候交、要满足哪些条件。

## 4. 领取题目 {#claim}

领取题目要填一次参与确认；确认后系统给你建好项目，报名进入待审核。

1. 在题目顶部点「领取题目」。
2. 弹出「参与确认」对话框：手机号或邮箱至少填一项，可以填「申请理由」，点「确认参与」。
3. 确认后系统已经给你建好一个项目，并直接把你带进这个项目。

![「参与确认」对话框：联系方式至少填一项，下面是申请理由和「确认参与」按钮](/images/task-join-dialog.jpg)

报名不会立刻生效：状态先是「待审核」，老师在题目的「参与者」页点「通过」之后，题目顶部才会出现「前往提交」。领取后想放弃，可以在题目顶部点「退出题目」。

完成后：人已经在项目里，芝士是你的 AI 队友；等老师通过后，题目顶部出现「前往提交」。

## 5. 项目：作品在哪里 {#project}

你要提交的作品在项目里做出来，题目和项目从领取那一刻就挂在一起了。

1. 题目「概览」的「项目」一栏列出从这道题目建出来的项目，点名字直接进。
2. 没有项目时这一栏显示「还没有人从这道题目开始做。」，可以点「从这道题目创建项目」建一个。
3. 再点一次「从这道题目创建项目」会另建一个新项目，一般不需要。

完成后：知道要交的作品在哪个项目里。

## 6. 和芝士一起完成 {#work}

在项目话题里说清要做什么，芝士是你的 AI 队友。

1. 在话题底部说明你要做什么，并交给芝士。例如：

   > 这是我的题目要求（粘贴题目详情）。先帮我讲清楚题目要什么，再一起列出要做的几步。

2. 芝士会先复述它的理解，再开始干活；你可以随时插话补充要求。
3. 芝士交付文件时会出现验收卡，点「审阅」查看后「采纳」或「退回」，见[验收与采纳](/accept#accept)。

完成后：项目里有你要提交的作品文件。

## 7. 提交 {#submit}

提交在题目的「提交」页完成：填写或上传，然后点「提交」。

1. 回到题目：课程首页「本周任务」→「去交这一周的作业」，或在题目顶部点「前往提交」。
2. 同时有个人身份和团队身份时，先在「请选择您要使用的提交身份：」里选一个。
3. 按「提交表单」填写：文件项点上传，文本项直接写。必填项没填会提示「此项为必填项」。
4. 点「提交」。上传时显示「正在上传提交内容」和进度，完成后跳到「提交记录」。

题目「概览」里的「提交次数」决定你能交几次：

| 提交次数 | 含义 |
|---|---|
| 可多次提交 | 截止前可以反复交，系统保存每一版 |
| 仅可提交一次 | 交过之后不能再交，提交前请检查完整 |

![题目「提交」页：提交表单里有文件上传项，下面写着「提交须知」和「提交」按钮](/images/task-submit.jpg)

完成后：「提交记录」页里出现这一版提交。

## 8. 查看提交记录 {#records}

「提交记录」页留着你的每一版提交，以及老师有没有看过。

- 最新一版在最上面，带版本号和提交时间。
- 下面的「历史提交」可以展开看每一版。
- 每版右侧是评审状态：「未评审」「通过」或「驳回」。老师驳回后，题目允许重复提交时可以改完再交一次。

![「提交记录」页：最新提交卡带版本号和提交时间，下面是可展开的历史提交](/images/task-submissions.jpg)

完成后：知道老师看没看、通没通过，以及要不要再交一版。
