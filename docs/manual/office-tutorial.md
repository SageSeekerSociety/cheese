# 办公：完成第一个协作项目 {#tut-office}

这篇教程以「整理一份周报」为例，带一个小团队走完一件事：建团队、邀请同事、建项目、把任务交给芝士、中途补充要求、验收，最后拿到成果。

开始前你需要：一个知是账号、同事的 UID（在对方的头像菜单里），以及可用的运行环境（见[设备与运行环境](/devices#devices)）。

## 1. 建团队、邀请同事 {#team}

在「团队」页创建团队，进入团队后依次点「成员管理」→「邀请成员」，填入同事的 UID。详见[团队](/teams#teams)。

完成后：同事接受邀请后出现在成员列表里。

## 2. 建项目 {#project}

新建项目，「所属团队」选刚建的团队。团队成员默认就是项目成员。详见[项目](/projects#projects)。

完成后：进入项目的第一个话题。

## 3. 把任务交给芝士 {#task}

把三份会议纪要拖进话题，然后说明要什么、给谁、什么时候要，并点名芝士。例如：

![话题里交代任务后，芝士先复述要做什么，再把活拆成两条并行推进](/images/room.jpg)

> 把这三份会议纪要整理成一页周报：按项目分节，结尾列待办和负责人，下午三点前要。

芝士会先复述它理解的目标和第一步。理解有偏差，现在说一声就好。

完成后：话题里显示芝士正在处理，右侧能看到它的进度。

## 4. 中途补充要求 {#followup}

不用等它做完，随时在话题里补一句，例如「标题用本周日期」。它会在下一步之前读到。

## 5. 验收 {#accept}

芝士交付后，话题里会出现验收卡。点「去验收」查看改动，满意就点「采纳」，不满意就「退回」并说明原因。详见[验收与采纳](/accept#accept)。

![验收卡：待你审阅，写着推荐理由和合并后的提交标题，可以「审阅」「退回」](/images/task-card.jpg)

完成后：任务显示「已采纳」，成果进入项目。

## 6. 拿到成果 {#result}

在项目的文件里下载周报，见[文件与成果](/files#files)。如果做出来的是网页，可以发布成项目网站，见[发布网站](/sites#sites)。
