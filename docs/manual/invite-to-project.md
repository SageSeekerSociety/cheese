# 拉一个人进你的项目 {#invite-to-project}

这一页讲不建团队、只请一个人进你名下的某个项目：按用户名或邮箱发邀请，对方在「待办」里接受，之后他就是这个项目的外部成员。比如你在自己名下建了「课程笔记整理」，想请同寝室的同学一起补笔记，但不打算为这一件事建一个团队。

开始前，你要是这个项目的所有者，或者项目所属团队的所有者、管理员。对方需要有一个知是账号。

## 发邀请 {#invite}

邀请从项目的「成员」页发出。

1. 点侧栏顶部的项目名，在菜单里点「成员」。
2. 点右上角的「邀请外部成员」。
3. 在「用户名或邮箱」里填对方完整的用户名或邮箱，下面出现这个人的名字后，点「发送邀请」。

![「邀请外部成员」对话框：填了用户名后，下面显示出这个人，右下是「发送邀请」](/images/invite-external.jpg)

对方出现在「成员」页的「等待接受」里，后面写着「@〈你的名字〉 邀请 · 待接受」。对方接受前，点那一行的「撤回」可以收回邀请。

> [!TIP]
> 要长期和同一群人做好几个项目，建一个团队更省事：团队成员自动进团队下的每个项目，见[和同学一起做一个项目](/team-project#setup)。

## 对方接受 {#accept}

这一步由被邀请的人在自己的账号里做。

打开「待办」，在「动态」里找到「@〈你的名字〉 邀请你加入项目」，点「接受」。这一行变成「你已加入项目 "〈项目名〉"」，他就能打开这个项目了。

不想加入就点「拒绝」。同一条邀请也列在「团队」→「待定」的「收到的项目邀请」里。

## 他能做什么 {#what-they-can-do}

外部成员在项目「成员」页上列在「外部成员」下面，名字旁标着「外部」。

- 能做的：在频道里说话、点名芝士；看「总览」「全部任务」、资料库和项目文档。<!-- 待确认：外部成员把消息转成任务、负责任务未实测 -->
- 不能做的：邀请别人、转让项目、新建频道。他的「成员」页右上角是「退出项目」，没有「邀请外部成员」和「转让项目」。<!-- 待确认：外部成员的项目菜单里也有「项目设置」，能改哪些设置未逐项核对 -->
- 他只看得到这个项目，看不到你名下或你团队里的其他项目。

要请他离开，在「成员」页他那一行点「管理成员」，选「移出项目」。他自己也可以随时点「退出项目」。
