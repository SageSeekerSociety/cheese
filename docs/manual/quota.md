# 额度 {#quota}

额度是知是给 AI 用量记账的点数。在团队「B 树小组」的项目里，芝士每调用一次模型、云端环境每运行一分钟，都从这个团队的额度里扣除。

## 由谁的额度支付 {#payer}

团队下的项目用团队的额度，你名下的项目用你的个人额度。别人在你名下项目的频道里 `@芝士`，扣除的也是你的个人额度。

额度以「点」计，1 点等于 0.01 美元。同样长的一段对话，单价高的模型扣除得多。

团队的额度不按人分，所有成员共用一份。额度由平台或发放方发放和调整，成员在界面上只能查看。

## 云端环境怎么计算 {#compute}

频道在云端环境中运行时，环境准备好之后到释放为止按分钟计费，不足一分钟按一分钟计算。云端环境每小时的价格固定，与实际用了多少 CPU 和内存无关。整台云虚拟机按虚拟机的规格定价。

等待环境准备的时间不计费。环境一段时间没有活动就会释放。下一条消息会准备新的环境，每轮结束时推送和备份的改动会带到新环境里。

频道运行在你接入的自有设备上时，不计算力费用，芝士调用模型照常扣额度。自有设备见[自有设备](/devices#devices)。

## 团队的「额度」页 {#team-quota}

在首页左侧栏展开团队，点「额度」。团队的每个成员都能查看这一页：

- 本月用量：标题是当月月份，例如「十月已用」。下方是已用和总数（如「120 / 2000 点」）、剩余点数和重置日期，「协作」（项目里的芝士）和「算力」（云端环境）用两种颜色区分。
- 「使用上限」：方案按时间窗口限额时，它代替本月用量，每个窗口一行，写明用掉的比例和重置时间。
- 「其他额度」：「管理员发放」「购买」和题目给项目的额度，各写明剩余点数、到期日和使用顺序（「最先使用」或「方案额度用完后使用」）。没有时不显示。
- 「每天用量」：本月每天用了多少点，两类叠在一起。
- 「按项目」：本月各项目用了多少点。

方案是平台给团队定的额度规则。点页面上的方案名，查看方案包含的内容：每月多少点或「使用上限」，以及「可用模型」。

## 频道和项目的用量 {#project-usage}

点频道顶部右侧的「⋯」（「更多」），菜单里的「用量」分「本频道」和「全项目」两行。每行的格式是「N 次运行 · N token · 费用」，费用以美元计。在电脑上把鼠标停在一行上，显示输入和输出 token 分别是多少。

项目的额度在「项目设置 → 环境」的「额度」区域。这个数字包含团队共享的额度和题目给本项目的额度，先用题目给的那部分。没有上限时显示「未设置额度上限」。

## 额度用完时 {#quota-exhausted}

芝士处理一条消息的一次运行称为一轮。额度用完后，芝士不执行新的一轮。你发的消息照常留在频道里，下方出现一条平台提示：

```demo-panel
title: 额度用完时频道里的提示
caption: 这一轮没有执行；提示写明哪天重置，以及需要谁补充额度。
head: 综合
parts:
  - kind: bars
    lines: 2
  - kind: msg
    who: 你
    to: 芝士
    say: 把这周的周报改一版，结尾加上下周待办。
  - kind: line
    text: 本月额度已用完，11月1日重置。这一轮没有执行。
    sub: 需要手动处理
    at: 1
  - kind: line
    text: 下一步
    value: 联系团队管理员或额度发放方补充额度。
    at: 1
```

团队的方案按下面两种方式之一发放额度：

- 按月发放：每月一份额度，每月 1 日重置，没用完的不留到下个月。
- 按时间窗口限额：每个时间窗口内有用量上限，例如每 5 小时、每周或每月。
  - 按小时的窗口从团队第一次使用时开始计时。
  - 每周的窗口在周一 0 点重置，每月的窗口在 1 日 0 点重置。
  - 窗口用满时，提示写明几点恢复，例如「本周的用量已达上限，10月12日 00:00 恢复。」

窗口用满时，团队还有「管理员发放」「购买」或题目给的额度，就先用这些额度，这一轮照常执行。

正在执行的一轮在下一次调用模型时停止，频道里出现同样的提示。额度用完后不再启动新的云端环境。已有的环境在这一轮结束后释放，频道里出现「额度已用完，环境已释放」。

额度补充后，重新 `@芝士` 发一条消息，芝士从这条消息继续。

## 个人额度 {#personal}

个人额度用于下面几处：

- 你名下项目里的芝士；
- 文档站的「问芝士」和题目页的「问芝士」；
- 发布题目时的「从文件导入」。

个人额度每月发放一次，当月没用完的不留到下个月。用完后提示「本月额度已用完」并写明重置日期；文档站「问芝士」的提示旁有「查看用量」。

点左下角的头像，打开「设置 → 芝士额度」查看个人额度。这一页的结构和团队的「额度」页相同，用量分四种颜色：

- 「协作」：你名下项目里的芝士；
- 「问答」：两处「问芝士」；
- 「写作」：「从文件导入」；
- 「算力」：你名下项目的云端环境。

页面下方的「我的项目」列出你名下各项目本月的用量。「我所在的团队」列出每个团队的方案和剩余额度，点一个团队打开它的「额度」页。

## 其他写着「额度」的提示 {#other-limits}

下面几种提示与团队额度、个人额度无关，补充额度不能解决：

| 提示 | 意思 | 处理 |
|---|---|---|
| 本轮未完成：AI 中继余额已用完 | 平台接入的 AI 服务余额用完了 | 联系平台管理员；重试没有作用 |
| 这个模型的额度已用完 | 当前模型暂时不能用 | 在项目设置或队友设置里换一个模型，或等额度恢复 |
| 当前方案不能使用模型「…」 | 团队的方案不包含这个模型 | 换一个方案包含的模型；点方案名可以看「可用模型」 |
