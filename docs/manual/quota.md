# 额度 {#quota}

这一页讲额度在哪里看、用完时会怎样。芝士每次调用模型都会消耗额度：团队的项目用团队的额度，你自己发起的提问和你名下的项目用你的个人额度。团队在侧栏里的「额度」页看本月用量，个人在设置里的「芝士额度」看。

## 查看团队额度 {#team-quota}

团队的额度在首页侧栏里：展开团队，打开「额度」。团队里的每个人都能看，页面上只有比例，不显示额度数，也不按人分。

| 显示项 | 意思 |
|---|---|
| 本月 | 团队方案和本月方案额度用掉的比例、还剩多少、哪天重置；方案有使用上限时，每条上限一行 |
| 其他额度 | 管理员发放、购买和题目发给项目的定向额度，各剩多少、何时到期；没有时不显示 |
| 每天用量 | 本月每天用量占本月总用量的比例 |
| 按项目 | 本月各项目用量的占比 |

你名下项目的额度不在团队里看，在个人设置的「芝士额度」里看，见[个人额度](/quota#personal)。界面上只能查看额度，不能发放或调整，额度由平台或发放方调整。

## 查看项目和话题用量 {#project-usage}

点话题顶部的「更多」，菜单里有「本话题」和「全项目」两行用量，每行写着「N 次运行 · N token · 费用」。鼠标停在行上，能看到输入和输出 token 的拆分。

项目的额度和上限在「项目设置 → 工作电脑」的「额度」一块；没有上限时显示「未设置额度上限」。

## 额度用完时 {#quota-exhausted}

每个团队每月有一份方案额度，月初重置，没用完的不留到下个月；另外还有题目发给项目的定向额度和发放的额度。额度用完时，话题里出现提示，例如「本月额度已用完，11月1日重置。这一轮没有执行。」，标着「需要手动处理」。方案还可能限制一段时间内的用量，满了会提示几点恢复。展开「下一步」，写着联系团队管理员或额度发放方补充额度。

```demo-steps
title: 额度用完时
note: 四步走一遍：拦下这一轮、查用量、补额度、接着干
embed: quota
steps:
  - label: 交代一件事
    desc: 王长鑫在话题里 @ 芝士改周报。每跑一轮都从这个项目所在团队的额度里扣，芝士空不空闲都一样。
  - label: 这一轮被拦下
    desc: 开跑前平台先看这个项目的额度，用完就不执行这一轮：消息还在房间里，芝士一个字都没答。
    link: /quota#quota-exhausted
  - label: 去哪里看用量
    desc: 团队侧栏里的「额度」看团队本月的用量；话题顶部「更多」里看本话题和全项目各用了多少；项目设置 → 工作电脑里有这个项目的额度和上限。
    link: /quota#team-quota
  - label: 补上额度，接着干
    desc: 额度由团队管理员或发放方补，界面上只能看。补上后重新 @ 芝士发一条消息，它就接着干。
```

这一轮被拦下时，还没开始的不执行；已经在跑的，停下前做的改动会留在工作区里。

额度补上后，重新 `@` 芝士发一条消息即可继续。

## 个人额度 {#personal}

不在项目里、由你自己发起的 AI 调用，扣的是你的个人额度，不扣团队额度。目前有三处：文档站的「问芝士」、题目页的「问芝士」，和发题时的「从 PDF 生成」。你名下项目里的芝士也扣这份额度，房间里别人召唤芝士也一样。

- 每个月初自动发放，当月没用完的不留到下个月。
- 按实际调用的模型折算：同样长的问答，贵的模型扣得多。
- 用完后会提示「本月额度已用完」，并写明哪天重置；「问芝士」的提示旁有「查看用量」。

在设置里打开「芝士额度」查看个人额度：

| 显示项 | 意思 |
|---|---|
| 本月 | 本月个人额度用掉的比例、还剩多少、哪天重置，按「协作」「问答」「写作」分三色 |
| 其他额度 | 方案之外的额度；没有时不显示 |
| 每天用量 | 本月每天用量占本月总用量的比例，按三类叠在一起 |
| 我的项目 | 你名下各项目本月用量的占比 |
| 我所在的团队 | 每个团队的方案和本月还剩多少，点开是那个团队的「额度」页 |

「协作」是你名下项目里的芝士，「问答」是两处「问芝士」，「写作」是「从 PDF 生成」。

## 其他写着「额度」的提示 {#other-limits}

下面几种提示也和额度有关，但不是团队或个人额度，补额度没有用：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| 本轮未完成：AI 中继余额已用完 | 平台接的 AI 服务余额用完了 | 联系平台管理员；重试没有作用 |
| 这个模型的额度已用完 | 当前模型暂时用不了 | 在项目设置或队友设置里换一个模型，或稍后再试 |
| 当前方案不能使用模型「…」 | 团队的方案不包含这个模型 | 在项目设置或队友设置里换一个方案包含的模型 |
