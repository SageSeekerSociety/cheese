# 额度与算力 {#quota}

芝士每次调用模型都会消耗 tokens。项目能用多少，由团队或机构发放的额度决定：1 额度 = 10,000 tokens。团队的「算力」页看总账，话题和项目设置里看各自用了多少。

## 查看团队额度 {#team-quota}

进入团队，在左侧打开「算力」。团队里的每个人都能看。

| 显示项 | 意思 |
|---|---|
| 团队云虚拟机 | 团队正在用的云机器数和上限 |
| 团队 tokens 额度 | 所有项目共享的额度，已用和剩余 |
| 占用云机器、累计 tokens | 按项目列出的用量 |
| 定向额度剩余 | 机构定向发给某个项目的额度，只能这个项目用 |

界面上只能查看额度，不能发放或调整，额度由平台或发放方调整。

## 查看项目和话题用量 {#project-usage}

点话题顶部的「更多」，菜单里有「本话题」和「全项目」两行用量，每行写着「N 次运行 · N token · 费用」。鼠标停在行上，能看到输入和输出 token 的拆分。

项目的额度和上限在「项目设置 → 运行环境」的「额度」一栏；没有上限时显示「当前未设置额度上限」。

## 额度用完时 {#quota-exhausted}

项目的 tokens 额度用完时，话题里出现提示「可用的 tokens 额度已用完，这轮没有执行」，标着「需要手动处理」。展开「下一步」，写着联系团队管理员或额度发放方补充额度。

- 如果这一轮还没开始，它不会执行。
- 如果这一轮已经在跑，停下前做的改动会留在工作区里。

额度补上后，重新 `@` 芝士发一条消息即可继续。

## 其他写着「额度」的提示 {#other-limits}

下面两种提示也带「额度」二字，但不是项目的 tokens 额度，补项目额度没有用：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| 本轮未完成：AI 中继余额已用完 | 平台接的 AI 服务余额用完了 | 联系平台管理员；重试没有作用 |
| 这个模型的额度已用完 | 当前模型暂时用不了 | 在项目设置或队友设置里换一个模型，或稍后再试 |
