# 额度 {#quota}

芝士每次调用模型都会消耗 tokens。项目能用多少，由团队或机构发放的额度决定：1 额度 = 10,000 tokens。团队的「工作电脑」页看总账，话题和项目设置里看各自用了多少。

## 查看团队额度 {#team-quota}

进入团队，在左侧打开「工作电脑」。团队里的每个人都能看。你名下项目的额度，在侧栏你的名字下面打开「工作电脑」查看，名称里不带「团队」二字。

| 显示项 | 意思 |
|---|---|
| 团队云端机器 | 团队正在用的云端机器数和上限 |
| 团队 tokens 额度 | 所有项目共享的额度，已用和剩余 |
| 占用云端机器、累计 tokens | 按项目列出的用量 |
| 定向额度剩余 | 机构定向发给某个项目的额度，只能这个项目用 |

界面上只能查看额度，不能发放或调整，额度由平台或发放方调整。

## 查看项目和话题用量 {#project-usage}

点话题顶部的「更多」，菜单里有「本话题」和「全项目」两行用量，每行写着「N 次运行 · N token · 费用」。鼠标停在行上，能看到输入和输出 token 的拆分。

项目的额度和上限在「项目设置 → 工作电脑」的「额度」一块；没有上限时显示「未设置额度上限」。

## 额度用完时 {#quota-exhausted}

项目的 tokens 额度用完时，话题里出现提示「可用的 tokens 额度已用完，这轮没有执行」，标着「需要手动处理」。展开「下一步」，写着联系团队管理员或额度发放方补充额度。

```demo-steps
title: 额度用完时
note: 四步走一遍：拦下这一轮、查用量、补额度、接着干
embed: quota
steps:
  - label: 交代一件事
    desc: 王长鑫在话题里 @ 芝士改周报。每跑一轮都从这个项目的 tokens 额度里扣，芝士空不空闲都一样。
  - label: 这一轮被拦下
    desc: 开跑前平台先看这个项目的额度，用完就不执行这一轮：消息还在房间里，芝士一个字都没答。
    link: /quota#quota-exhausted
  - label: 去哪里看用量
    desc: 团队左侧「工作电脑」看团队总账；话题顶部「更多」里看本话题和全项目各用了多少；项目设置 → 工作电脑里有这个项目的额度和上限。
    link: /quota#team-quota
  - label: 补上额度，接着干
    desc: 额度由团队管理员或发放方补，界面上只能看。补上后重新 @ 芝士发一条消息，它就接着干。
```

这一轮被拦下时，还没开始的不执行；已经在跑的，停下前做的改动会留在工作区里。

额度补上后，重新 `@` 芝士发一条消息即可继续。

## 个人额度 {#personal}

不在项目里、由你自己发起的 AI 调用，扣的是你的个人额度，不扣团队额度。目前有三处：文档站的「问芝士」、题目页的「问芝士」，和发题时的「从 PDF 生成」。你名下项目里的芝士也扣这份额度，房间里别人召唤芝士也一样。

- 每个月初自动发放，当月没用完的不留到下个月。
- 按实际调用的模型折算：同样长的问答，贵的模型扣得多。
- 用完后会提示「本月的芝士额度已用完」，并写明哪天重置。

## 其他写着「额度」的提示 {#other-limits}

下面两种提示也带「额度」二字，但不是项目的 tokens 额度，补项目额度没有用：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| 本轮未完成：AI 中继余额已用完 | 平台接的 AI 服务余额用完了 | 联系平台管理员；重试没有作用 |
| 这个模型的额度已用完 | 当前模型暂时用不了 | 在项目设置或队友设置里换一个模型，或稍后再试 |
