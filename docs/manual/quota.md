# 额度与算力 {#quota}

小队的「算力」页面显示设备和额度；项目和话题也提供各自的用量信息。

## 查看小队额度 {#team-quota}

小队的「算力」页面显示共享额度和各项目的用量，普通成员也可以查看。进入小队后，在左侧打开「算力」。

页面显示「团队云虚拟机」「团队 tokens 额度」，并按项目列出「占用云机器」「累计 tokens」「定向额度剩余」。

页面说明，团队额度由所有项目共享，机构定向额度只供指定项目使用。当前用户界面没有发放、修改或回收额度的入口。

## 查看项目和话题用量 {#project-usage}

话题顶部的「更多」菜单分别显示「本话题」和「全项目」的用量。指标包括「运行次数」「总 token」「输入」「输出」「费用」。

项目的额度上限显示在「项目设置 → 运行环境」。

## 额度用完时 {#quota-exhausted}

项目可用 tokens 额度用完时，话题会显示「可用的 tokens 额度已用完，这轮没有执行」，并标记「待人工处理」。这一轮不会执行，也不会产生文件改动。

当前提示没有提供补充额度的操作入口或联系人。需要继续执行时，可联系小队管理员或额度发放方核对额度。
