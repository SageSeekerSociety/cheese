# 快速开始 {#quickstart}

这一页带你走完第一次使用：在自己名下建一个项目，交给芝士一件小事，再验收结果，大约十分钟。

开始前：登录知是。芝士默认在平台的云端环境里干活，不用准备电脑；想让它用你自己电脑上的文件和工具，见[设备与环境](/devices#devices)。

## 创建项目 {#project}

新建项目分两步：先填项目信息，再给项目的 AI 队友取名字。

1. 点最左侧那一列里、项目方块下面的「＋」，鼠标停在上面会显示「新建项目」。还没有项目时，登录后落在「待办」，页面上也有「新建项目」按钮。
2. 填写「项目名称」。「归属」保持默认的你自己的名字，「代码仓库」保持默认的「平台托管（默认）」，这两项一般不用改。「你打算做什么（可选）」可以先不填。
3. 点「下一步」。
4. 在「项目的 AI 队友」里填「队友名字」，也可以点「随机取名」。
5. 点「创建项目」。

完成后：进入这个项目的频道「综合」。

## 把任务交给芝士 {#talk}

改项目里的东西在任务里做。先在「综合」里把事情说清楚，再转成任务：

1. 在底部输入框里说清要什么、做到什么程度，比如：

   > 请在项目中创建一份欢迎说明，写一句介绍这个项目的话，完成后交给我验收。

2. 按 `Ctrl/Cmd+Enter`，或点输入框旁的「交给〈队友名字〉」。芝士在这条消息的支线里回答，先复述它的理解，有不清楚的地方会问你。
3. 说清楚后，点支线顶部的「转为任务」。任务页打开，芝士把讨论整理成任务文档。
4. 看过任务文档，点「开始」。项目还没有默认审阅人时，会提示选一位「审阅人」。

完成后：芝士开始改项目，任务页右侧「现场」一行一行记下它在做什么。

![频道页：左侧是项目侧栏和频道列表，中间是频道里的讨论和两件任务的记录，右侧「概览」列出频道说明、置顶和进行中的任务](/images/room.jpg)

直接按回车发送的普通消息只留在频道里，不会让芝士开工。其余交给芝士的方式见[让 AI 队友处理消息](/agents#summon)。

## 查看结果并验收 {#result}

先看对话里的改动小结，再看右侧的验收卡：

1. 等这一轮结束，对话里出现一行「改动了 N 个文件」，带增减行数。点「查看改动」看具体内容。
2. 芝士交付时，对话里出现一行「……已提交，待〈名字〉验收」。在右侧「概览」、「待办」或「全部任务」的「待处理」里打开这件任务，验收卡上写着「待 @〈你〉 审阅」。点「审阅」看改动。
3. 满意就点「采纳」，改动进入项目；不满意就点「退回」，写清楚哪里要改。

![任务页输入框上方展开的验收卡：写着待谁审阅、推荐理由和合并后的提交标题，下方是「审阅」](/images/task-card.jpg)

完成后：最后一步被采纳的任务显示「已采纳」并结束。更多说明见[验收与采纳](/accept#accept)。

频道提示「这条会话的环境尚未配置或未连接」时，见[设备与环境 · 提示环境未配置或未连接](/devices#device-offline)。
