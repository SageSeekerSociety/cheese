# 快速开始 {#quickstart}

按这一页做一遍：建一个个人项目，交给芝士一件小事，再验收它交回来的东西。大约十分钟。

开始前需要：登录知是，并有一台可用的工作电脑（芝士在那里执行任务），接入方法见[设备与工作电脑](/devices#devices)。

## 创建项目 {#project}

1. 登录后落在「我的工作」。点页面上的「新建项目」，或左侧导航最下面的「新建项目」按钮。
2. 填写「项目名称」。「所属团队」保持默认的「个人」，「代码仓库」保持默认的「由芝士托管（默认）」。「你打算做什么（可选）」可以先不填。
3. 点「下一步」。
4. 在「项目的 AI 队友」里给芝士起个「队友名字」（也可以点「随机取名」），点「创建项目」。

完成后：进入这个项目的总览房间，标题是「〈项目名〉 · 项目总览」。

界面上显示的是你刚起的队友名字，下文统一叫它「芝士」。

## 把任务交给芝士 {#talk}

在话题里说清要什么、做到什么程度。比如在底部输入框里写：

> 请在项目中创建一份欢迎说明，写一句介绍这个项目的话，完成后交给我验收。

按 `Ctrl/Cmd+Enter`，或点输入框旁的「交给〈队友名字〉」，把消息交给芝士。

完成后：芝士先在对话里复述它的理解，再开始做。右侧「现场」顶上一行写着它此刻在做什么。

![话题页：左侧是项目侧栏和话题列表，中间是和芝士的对话（芝士复述了任务，并拆出两条活），右侧是话题的实况文档](/images/room.jpg)

直接按回车发送的普通消息只留在话题里，不会让芝士开工。其他交给芝士的方式见[让 AI 队友处理消息](/agents#summon)。

## 查看结果并验收 {#result}

1. 等这一轮结束，对话里出现本轮摘要：改了哪些文件、增减多少行。点「查看改动」看具体内容。
2. 芝士交付时，对话末尾出现一张验收卡，写着「待你审阅」。点「审阅」，右侧「改动」里逐个文件看差异。
3. 满意就点「采纳」，改动进入项目；不满意就点「退回」，写清楚哪里要改。

![打开一条活后的右侧面板：验收卡写着待谁审阅、推荐理由和合并后的提交标题，下方有「审阅」「采纳」「退回」](/images/task-card.jpg)

完成后：任务显示「已采纳」，出现在项目看板的「已完成」里。更多说明见[验收与采纳](/accept#accept)。

如果话题提示「这条会话的机器尚未配置或未连接」，见[机器未配置或未连接](/troubleshooting#device-offline)。
