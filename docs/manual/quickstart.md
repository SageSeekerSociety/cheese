# 快速开始 {#quickstart}

知是是你和 AI 队友一起做项目的地方。这一篇带你走完三步——组队、建项目、开一个话题跟它说上第一句话，十分钟左右。

走完你就能开始干活了。**这一篇不假设你是来写代码的**——很多人用知是只是和 AI 一起理事情、出方案、写东西。仓库怎么连、活怎么验收，那些等你需要时再看。

## 第一步：组一支小队 {#team}

在首页左侧栏点「小队」，进小队页面。

![「我的小队」页面：左侧栏选中「小队」，右侧列出你所在的每一支小队，顶部有「小队 / 发现 / 我的 / 待定」四个页签和一个「创建小队」按钮](/images/teams-my-teams.png)

点顶部的「创建小队」，填好名称和描述，再点弹窗里的「创建小队」。

![「创建小队」弹窗：左边是小队头像，右边填小队名称和小队描述（一个富文本编辑器），右下角是「创建小队」按钮](/images/teams-create.png)

要把人拉进来，点进这支小队，依次点「成员管理」→「邀请成员」，填对方的 UID。**UID 在对方的头像菜单里**——目前只支持按 UID 邀请。

![「邀请成员」弹窗：填 UID、选角色（默认「普通成员」）、可选填一句邀请消息，右下角是「邀请」按钮](/images/teams-invite.png)

对方在「小队 → 待定」里看到这条邀请，点 ✓ 就进来了。

一个人用也可以：**建项目时「所属团队」选「个人」**，那是只有你自己的一支小队，规则完全一样。所以这一步跳过也行，以后要拉人不用换一种用法。

更细的在[小队](/teams#teams)。

## 第二步：建一个项目 {#project}

界面最左边那条竖栏是你的项目栏，底部的 **➕** 是新建项目。要填的只有两样：**项目名称**，和**所属团队**（选刚建的那支小队，或者「个人」）。

点「创建」，界面直接进入这个项目。**项目自带一个放东西的地方**——你和芝士做出来的文件都落在那儿，你不用先准备什么。

想把自己已有的 GitHub 仓库接进来，那是[项目](/projects#upstream)那一页的事，第一趟不用管。

更细的在[项目](/projects#projects)。

## 第三步：开个话题，说一句人话 {#talk}

打开项目，第一屏是**看板**，不是聊天——看板答的是「现在该谁动」。

左侧栏顶部的 **➕（新建话题）** 开一个新房间。项目的默认队友已经在里面了；想让别的队友也参与，从房间顶部的名册里添加。

在底部输入框里，像跟同事说话那样说你想做什么，**记得 `@` 一下芝士**——没有 `@` 的消息它收不到：

> @芝士 帮我看看这个项目现在有些什么，理一份清单给我。

按回车。**到这里就算走完了。**

## 它回你之后 {#what-happens}

它会先回一句它理解的目标和第一步，然后开工。这句话值得读——理解偏了，现在说一声只损失几秒。

开工之后房间里有几处在动：**对话**是它的判断和要你拍板的选择；**施工现场**每调用一次工具多一行，那是它当下在做的事；右侧的**实况文档**是这个房间的当前全貌，隔几天回来先看它比往回翻聊天快。

**你随时可以插话**，不用等它停下来——想改方向、想补一个条件，直接说就行。
