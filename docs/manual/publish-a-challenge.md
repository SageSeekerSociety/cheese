# 发布一道题目并收作业 {#publish-a-challenge}

这一页带你开一个空间，发一道作业题，批准学生领取，再评审交上来的作业。比如你是数据结构课的助教，要发一道「B 树的插入与删除」，让全班两周内交源代码和实验报告。

开始前要知道一件事：新空间要平台管理员审核通过才能用。审核通过前，学生用邀请码加入会看到「邀请码无效、已过期或已达使用上限」，你也还不能发布和审核题目。<!-- 待确认：平台管理员审核一般要多久、找谁催 -->

:::steps

### 开一个空间 {#create-space}

空间是发作业和收作业的地方，一门课开一个。

「空间」页 →「新建空间」→ 填「空间名称」，「简介（选填）」写一句这门课是什么 →「提交审核」。

弹出「这是你的邀请码」。把这个码记下来，再点「进入空间」。审核期间，空间列在「空间」页的「我的空间申请」里。审核通过后，空间出现在探索列表里，这时才能做下面几步。

### 把学生拉进来 {#invite}

学生用邀请码加入空间。新建空间时给的码默认 50 人可用、永不过期。

把码发到课程群里，学生在首页侧栏「空间」下面点「用邀请码加入」，填这个码。

班上超过 50 人，或要给另一个班单独的码时，新建一个：空间侧栏「设置」→「邀请码」→「新建」，填「可用人数」「有效期至」和一句说明，点「生成」。

### 写题目描述 {#draft}

题目描述写清要交什么、怎么评分，学生和学生项目里的芝士都读这一段。

发题表单里没有让芝士代写的入口。想让芝士帮你起草，在你自己的项目里和它说，写好后复制进表单：

```prompt
@芝士 帮我写一道数据结构作业的题目描述：用 C 实现 3 阶 B 树的插入、删除和查找。学生交一个压缩包，里面是源代码和不超过 5 页的实验报告。评分：正确性 60 分，代码规范 20 分，报告 20 分。
```

```prompt
@芝士 这是我去年的 B 树作业说明（见附件）。保留评分标准，把交法改成「源代码和报告打成一个 zip 交」，其余照旧。
```

```prompt
@芝士 在这份题目描述末尾加一段「常见错误」，列出删除时合并和借位最容易出的三个问题，不要给出代码。
```

### 发一道题目 {#publish}

在空间里填题目、定规则，发布后等待审核。

空间侧栏「全部题目」→「发布题目」，从上往下填：

- 必填：「名称」「参与方式」「难度」「分类」。「参与方式」选个人或团队；「分类」默认有一个「General」，要更多分类在空间「设置」→「分类与话题」里建。
- 「完成期限」：在「领取后 N 天内完成」里填 N，两周就填 14。期限从你批准学生领取的那一刻开始算。
- 「描述」：贴上一步写好的描述。
- 「附件」：随题发出的材料，领了题的人能下载。

填好后点页头右边的「发布」。还有没填好的项时，页头显示还有几项，对应的格子下面标出原因。

新题默认「可多次提交 · 可编辑提交内容」，提交表单只有一个「提交文件」，一次只能传一个文件。要交两样东西，在题目描述里写明「打成一个压缩包交」。<!-- 待确认：发布页上没看到改提交次数和提交表单的入口 -->

> [!TIP]
> 手里有题目 PDF 时，点「题目内容」右上角的「从文件导入」上传它，几秒到几十秒后读出题目，一份 PDF 最多 20 道。读出几道时逐道改好、勾选要发的，再一起发布。这一步扣你的个人额度，见[个人额度](/quota#personal)。

### 审核通过题目 {#audit}

提交的题目先进「待审核」，空间的所有者或管理员通过后，学生才看得到。

你是空间所有者，自己审核即可：空间侧栏「管理」→「待审核」→ 点题目展开。展开后能看到题目描述和「提交要求」（就是学生要填的提交表单），确认后点「通过」。

题目出现在「全部题目」里，状态是「报名中」。

### 批准领取 {#approve}

学生在题目页领取题目后，进「待批准领取」，你批准了他才开始计时。

题目页 →「领取者」页签 →「待批准领取」，在学生那一行点「批准」，或点「拒绝」并写原因。批准后这一行写着他的截止日期。

### 评审作业 {#review}

学生交作业后，「领取者」页签里他那一行的状态变成「待评审」。

在那一行点「评审」，看「最新提交内容」和「历史提交」，在「是否通过」里选「通过」或「驳回」，填「评分」和「评论」，点「提交」。<!-- 待确认：「最新提交内容」里的文件是点开下载还是在线查看 -->

![题目的「领取者」页签：按「全部」「待批准领取」「待评审」「已通过」筛选，学生那一行写着状态「待评审」和最新提交的版本，右边是「评审」](/images/challenge-participants.jpg)

学生在「我的提交」里看到评审结果和评语。新题默认可多次提交，驳回后学生可以改完再交一版，见[改完再交一版](/resubmit#resubmit)。
