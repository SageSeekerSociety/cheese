# 团队 {#teams}

团队是一起使用知是的一组人，例如三位同学组成的「B 树小组」。团队成员自动成为团队下每个项目的成员，共用团队的设备和额度。

## 团队和你名下的项目 {#personal}

首页左侧栏的「团队」上方那一行是你的昵称，代表你名下的项目。展开后有「项目」「资料库」两页。这里的「资料库」只有你自己能打开，放个人笔记、草稿和文件，你附给芝士的文件和芝士发送给你的文件也保存在这里。你自己的设备、模型和额度在「个人设置」里：点这一行的「⋯」，选「设置」，或者点最左侧一列底部的头像，再点「设置」。这一行下面只有你一个人：不能邀请别人进来，也没有成员页。你名下的项目只能逐个[邀请外部成员](/projects#invite-project-member)，不能一次加入一组人。

同一组人要一起做几个项目时，先建团队，再在团队下建项目。建团队、请同学加入的完整过程见[和同学一起做一个项目](/team-project#setup)。

## 团队的页面 {#team-pages}

在首页左侧栏的「团队」下展开一个团队，依次是：

- 「项目」：团队下的项目，右上角的「新建项目」会把这个团队预先填进「归属」。
- 「资料库」：属于团队、不属于哪个项目的文档和文件，排在同一张列表里，和项目的资料库相同。团队成员都能阅读、编辑和评论文档，右上角点「新建文档」新建一份；文件可以上传、替换、移动和删除。页面上方写着已用多少空间、一共多少，上限见[团队和你自己的资料库](/files#team-library)。项目里的芝士读不到团队的文档，课程的教学设置里指定的阅读文档除外。

其余不常用的放在团队那一行「⋯」里的「设置」中。「设置」盖在整个窗口上，左上角的返回按钮或 `Esc` 关闭。左侧分两组：

- 「团队」：「基本信息」修改团队头像、名称、团队地址和简介，只有所有者和管理员能改；「成员」是加入方式、加入申请、成员和已发送邀请。
- 「资源」：「设备」是属于团队的自有设备，管理员负责接入、改名和移除，见[设备所属团队](/devices#team-device)；「模型」是团队能用的模型和连接，见[团队的模型连接](/devices#own-claude-code)；「额度」是团队本月的用量，见[团队的「额度」页](/quota#team-quota)。

最下面一项是红字：所有者看到「转让与解散」，其他成员看到「退出团队」，见[退出、转让和解散](#leave)。

团队列表在左侧栏「团队」下的「新建或加入团队」里，分「发现」「我的」「待定」三个页签。「待定」里是你发出的加入申请、收到的团队邀请和项目邀请。「发现」页的「招募广场」显示「即将推出」，目前不能发布或浏览招募信息。

## 加入团队的方式 {#join-request}

加入团队有三种方式：用团队链接申请，在「发现」里搜索后申请，或接受所有者、管理员的邀请。接受邀请后就加入团队；申请是否要等批准，由团队的设置决定。三种方式的操作见[加入别人的团队](/join-a-team#join-a-team)。

所有者和管理员在「设置 → 成员」的「加入方式」里设置怎么加入：

```demo-panel
title: 团队的加入设置
caption: 「成员」一栏上方的「加入方式」，只有所有者和管理员看得到。复制的团队链接发给要加入的人。
parts:
  - kind: head
    title: 成员
    plain: true
  - kind: line
    text: 团队链接
    button: 复制链接
    press: 1
    until: 1
  - kind: line
    text: 团队链接
    button: 已复制
    at: 1
  - kind: line
    text: 加入需要审批
  - kind: field
    label: 谁能找到
    value: 公开
  - kind: bars
    lines: 2
```

- 「加入需要审批」默认开启。申请出现在所有者和管理员「待办」的「等你处理」里，也列在「成员」一栏的「加入申请」中，点「批准」或「拒绝」。关闭后，打开链接或搜到团队的人点「加入团队」即可加入。
- 「谁能找到」选「隐身」后，「发现」里搜不到这个团队，只能用团队链接或邀请加入。
- 「重置链接」让旧的团队链接失效。

## 邀请成员 {#invite-member}

所有者和管理员在「设置 → 成员」右上角点「邀请成员」，按完整的用户名或邮箱邀请。邀请时选择对方加入后的角色「普通成员」或「管理员」，可以附上「邀请消息（可选）」。

对方在「待办」的「等你处理」里看到「〈你的名字〉 邀请你加入团队」，点「接受」后加入。同一条邀请也列在「待定」的「收到的邀请」下。发出的邀请列在「成员」一栏的「已发送邀请」里，对方处理之前点「撤回」。

## 角色 {#manage-team-members}

团队有三种角色。创建团队的人是所有者，在成员列表里标作「队长」，在其他地方写作「所有者」。

| 能做的事 | 所有者 | 管理员 | 普通成员 |
|---|---|---|---|
| 使用团队的项目和设备 | ✓ | ✓ | ✓ |
| 邀请成员、批准加入申请、改加入设置 | ✓ | ✓ | |
| 移出普通成员 | ✓ | ✓ | |
| 移出管理员、调整角色 | ✓ | | |
| 转让团队、解散团队 | ✓ | | |

所有者在成员那一行的「⋯」里选「提升为管理员」或「降级为成员」调整角色。团队成员自动出现在团队下每个项目的「成员」页。项目里另外邀请的人是外部成员，不属于团队，见[成员从哪里来](/projects#project-members)。

## 退出、转让和解散 {#leave}

这三项在「设置」最下面那一栏：所有者看到的是「转让与解散」，其他成员看到的是「退出团队」。首页左侧栏团队那一行的「⋯」（「团队操作」）菜单里也有，右键点这一行也能打开。

- 「退出团队」：所有者以外的成员都能退出。退出后看不到团队的项目，需要重新加入才能回来。
- 「转让团队」：所有者选一位成员接手，转让后对方是所有者，你成为管理员。
- 「解散团队」：所有者输入团队名确认后解散，所有成员离开团队，无法撤销。团队下的项目要先全部[归档](/projects#archive-project)。

同一个菜单里的「编辑团队资料」打开「设置 → 基本信息」。
