# 小队 {#teams}

小队是项目的归属：项目建在哪支小队下，队里的人默认就是这个项目的成员，不用再一个个邀请。

怎么建一支小队、怎么把人拉进来，[快速开始](/quickstart#team)里已经一步步走过了。这一页讲那一趟没展开的部分。

## 小队里有什么 {#inside}

点进一支小队，左侧栏是四样东西：**项目**（这支小队下的所有项目）、**成员管理**、**知识库**、**算力**。

![小队的「成员管理」页：左侧栏是「项目 / 成员管理 / 知识库 / 算力」，右上角是「邀请成员」按钮，中间是成员列表，创建者带「队长」标记](/images/teams-members.png)

成员管理里有三个页签：**成员列表**、**加入申请**（别人申请进来的）、**已发送邀请**（你发出去还没回的）。建小队的人是**队长**。

## 待处理的邀请在哪 {#pending}

你收到的邀请在「小队 → 待定」这一页，同一页也列着你发起过的申请。

![「待定」页：「收到的邀请」里有一条待处理的小队邀请，显示小队名和邀请时间，右侧一个对勾一个叉](/images/teams-pending.png)

## 一个人用也是一支小队 {#personal}

建项目时「所属团队」选「个人」，那是只有你自己的一支小队。规则和多人小队完全一样，只是队里只有你——所以以后要拉人进来，不用换一种用法。
