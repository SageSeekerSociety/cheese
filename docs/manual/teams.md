# 团队 {#teams}

团队用于管理一起使用的项目和成员。项目建在团队下时，团队的成员会自动进入这个项目，不用逐个邀请。

## 找到和创建团队 {#create-team}

在左侧导航打开「团队」，可以查找已有团队或创建团队。页面有「发现」「我的」「待定」三个页签。

![「团队」页面：列出我加入的团队，右上角可以新建团队](/images/teams.jpg)

1. 点击右上角的「创建团队」。
2. 填写「团队名称」和「团队描述」，按需上传头像。
3. 点击「创建团队」。

完成后：进入新团队的「项目」页面。团队侧栏还有「成员管理」「知识库」和「算力」。

## 邀请成员 {#invite-member}

队长和管理员可以通过 UID 邀请成员。受邀者可以在自己的头像菜单中查看 UID。

![「邀请成员」对话框：填写对方的 UID、选择角色，可附一段邀请消息](/images/teams-invite.png)

1. 在团队侧栏打开「成员管理」，点击「邀请成员」。
2. 填写对方的 UID，选择「普通成员」或「管理员」，按需填写邀请消息。
3. 点击「邀请」。

完成后：页面显示「邀请已发送」。

受邀者在「团队 → 待定」的「收到的邀请」里查看邀请，点对勾接受、点叉拒绝。邀请也会出现在右上角的通知中心。

## 申请加入团队与审核申请 {#join-request}

1. 在「团队 → 发现」里搜索团队 ID 或名称。
2. 点开搜索结果，进入这个团队的主页。
3. 需要审批的团队：填写「申请理由（选填）」，点「申请加入」，等队长或管理员批准。不需要审批的团队：直接点「加入团队」，立即加入。

设为「隐身」的团队搜不到，只能通过团队分享的链接进入。

队长和管理员在「成员管理 → 加入申请」里查看理由，选择「批准」或「拒绝」。普通成员的成员管理页只有「成员列表」。

## 管理成员 {#manage-team-members}

团队成员能做什么，由角色决定。

| 角色 | 成员管理权限 |
|---|---|
| 队长 | 邀请成员、调整成员角色、移除成员 |
| 管理员 | 邀请成员、移除成员 |
| 普通成员 | 查看成员列表 |

邀请记录在「成员管理 → 已发送邀请」中。

## 其他团队页面 {#team-pages}

「知识库」页面提供搜索、资料类型、标签和「上传资料」入口。「算力」页面显示团队的设备和额度，参见[额度与算力](/quota#quota)。

「发现」页的「招募广场」目前显示「即将推出」，还不能发布或浏览招募信息；找团队请用页面上的搜索。

## 在话题中提醒成员 {#mention-member}

在话题中 `@` 一位人类成员后，对方会在项目侧栏看到该话题的未读角标。打开话题并读到新消息后，角标会消失。
