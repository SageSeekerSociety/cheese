# 小队 {#teams}

小队用于管理共同使用的项目和成员。项目建在小队下时，小队已有成员会自动进入该项目。

## 找到和创建小队 {#create-team}

在左侧导航打开「小队」，可以查找已有小队或创建小队。页面有「发现」「我的」「待定」三个页签。

![「团队」页面：列出我加入的团队，右上角可以新建团队](/images/teams.jpg)

1. 点击右上角的「创建小队」。
2. 填写「小队名称」和「小队描述」，按需上传头像。
3. 点击「创建小队」。

创建完成后会进入新小队的「项目」页面。小队侧栏还有「成员管理」「知识库」和「算力」。

## 邀请成员 {#invite-member}

队长和管理员可以通过 UID 邀请成员。受邀者可以在自己的头像菜单中查看 UID。

![「邀请成员」对话框：填写对方的 UID、选择角色，可附一段邀请消息](/images/teams-invite.png)

1. 在小队侧栏打开「成员管理」，点击「邀请成员」。
2. 填写对方的 UID，选择「普通成员」或「管理员」，按需填写邀请消息。
3. 点击「邀请」。页面显示「邀请已发送」。

受邀者可以在「小队 → 待定」的「收到的邀请」中查看邀请，点击对勾接受或点击叉拒绝。邀请也会出现在右上角的通知中心。

## 申请加入小队与审核申请 {#join-request}

用户可以在「小队 → 发现」中查找小队并申请加入。搜索小队 ID 或名称，点击结果中的「申请加入」，填写申请理由并提交。

队长可以在该小队的「成员管理 → 加入申请」中查看理由，选择「批准」或「拒绝」。普通成员的成员管理页只显示「成员列表」。

## 管理成员 {#manage-team-members}

小队成员的管理权限由角色决定。

| 角色 | 成员管理权限 |
|---|---|
| 队长 | 邀请成员、调整成员角色、移除成员 |
| 管理员 | 邀请成员、移除成员 |
| 普通成员 | 查看成员列表 |

邀请记录在「成员管理 → 已发送邀请」中。

## 其他小队页面 {#team-pages}

「知识库」页面提供搜索、资料类型、标签和「上传资料」入口。「算力」页面显示小队的设备和额度，参见[额度与算力](/quota#quota)。

「发现」页的「招募广场」目前显示「即将推出」，还不能发布或浏览招募信息；查找小队和申请加入可使用页面上的搜索。

## 在话题中提醒成员 {#mention-member}

在话题中 `@` 一位人类成员后，对方会在项目侧栏看到该话题的未读角标。打开话题并读到新消息后，角标会消失。
