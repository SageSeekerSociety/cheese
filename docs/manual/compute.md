# 设备与算力 {#compute}

芝士干活要跑在一台机器上，这台机器就是这个房间的运行环境。

## 运行环境 {#runtime}

芝士干活要跑在一台机器上，这台机器就是这个房间的**运行环境**。

默认用平台标准配置，第一次运行时自动准备好，你不用管。想用自己的机器，Mac 或 Windows 电脑直接下载桌面端，登录后自动接入；服务器等其他机器在「我的设备」→「添加设备」里复制对应系统的安装命令（Mac/Linux 是 curl 那条，Windows 是 PowerShell 那条）到那台机器上运行，再运行 `cheesehost link connect`，按提示在浏览器里批准这台设备，之后就能在房间的运行环境里选它。

有一点要知道：**运行环境在房间首次运行之后就固定了**，之后要换配置得开新房间。
