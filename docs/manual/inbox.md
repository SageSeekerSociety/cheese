# 待办与通知 {#inbox}

芝士交付了由你审阅的「组会报名说明」，你的「待办」里随即多出一条「待审阅」；采纳之后，这一条消失。

「待办」页列出等你处理的事和发给你的消息。不在知是里时，浏览器推送和邮件把消息送到你手上；送哪些、什么时候送，在「设置 → 通知」里调整。

## 「待办」在哪里 {#where}

电脑上，点最左侧一列最上面的图标「首页」，打开的就是「待办」，左侧栏第一行也是「待办」。手机上，「待办」在底栏。

这个入口上的数字是「等你处理」的件数。没有等你处理的事、但「动态」里有未读时，入口上显示一个圆点。最左侧一列每个项目的图标上，也标着这个项目里等你处理的件数。数字在切换页面、回到窗口时刷新；你处理完一件事，比如回答了提问、采纳了改动、标了已读，不管在哪一页，数字都当场跟着变。

「待办」页分两块：上面是「等你处理」，下面是「动态」。

## 等你处理 {#waiting}

「等你处理」列出下一步在你手上的事，按项目或团队分组，最近有进展的排在前面。每一条写着要你做什么、哪件任务、所在频道和时间：

- 「待审阅」：任务交付了，等你采纳或退回，见[验收与采纳](/accept#accept)。
- 「待回答」：芝士在问你问题。
- 「待你决定」：芝士请你在几个选项里选一个，选项列在这一条下面。
- 「检查未通过」：你负责的任务没有通过平台检查，芝士无法自行解决。
- 「卡住」：芝士报告你负责的任务没有人帮忙就做不下去。
- 「退回」：你负责的任务的交付没能进入审阅（例如平台检查没有通过），目前没有人在修改。
- 「你提的需求已有交付」：你提出的事有了交付。
- 「变更提醒」：芝士告诉你项目里改了什么。
- 「待你答复」：有人邀请你加入项目或团队，在这一条上点「接受」或「拒绝」，见[加入别人的团队](/join-a-team#by-invite)。
- 「待你审批」：有人申请加入你管理的团队，在这一条上点「批准」或「拒绝」，见[团队](/teams#join-request)。
- 「N 份申请待通过」「N 份提交待评审」：你发布的题目，或你管理的空间里的题目，有人申请或提交了。这一条按空间分组，点开进题目的「参与者」页签，见[发布题目](/publish-a-challenge#approve)。

点一条打开对应的任务、支线或频道。事情办完，这一条就从列表里消失，例如采纳或退回了交付、回答或跳过了问题。「待你决定」点一个选项后消失，邀请和申请回答后消失。

「变更提醒」看过后点「标为已读」。一个项目里有 2 条以上时，项目名右边有「全部标为已读」。

已归档的频道里的事不列在这里。

## 动态 {#feed}

「动态」是发生过的事，按天分组，新的在前，读过的仍然留着。要你处理的事（芝士的问题、待你审阅的交付、邀请和申请）列在「等你处理」，不在「动态」里重复：

- 邀请和申请的结果，例如「你的加入请求已获批准」。
- 平台提示，例如额度用完了。
- 任务的提醒：你负责的任务 3 天没有进展时，收到「任务「〈任务名〉」已经 3 天没有进展」。之后有了新消息、又 3 天没有进展时，会再提醒一次。
- 自己设置的[提醒](#reminder)。
- AI 队友开始在你的设备上工作，见[自有设备](/devices#team-device)。
- 空间的公告，标着「公告」。
- 题目上的事：申请通过或未通过（例如「「B 树的插入与删除」的申请已通过」）、提交的评审结果、你的提交截止时间调整了；出题人改了题目或阶段的名称、修改了提交内容或评分要点、新增或去掉了阶段、改了某个阶段的截止时间，例如「「〈题目名〉」阶段「实现」的截止时间改为 2026-11-15 23:59（北京时间）」，改名的写出旧名和新名，例如「「〈旧题目名〉」改名为「〈新题目名〉」」，一次保存里改了几样就在一条里列出。截止时间按你浏览器所在的时区写。只调整阶段的顺序，不发通知。开始做了还没提交时，离提交截止 3 天和 24 小时各提醒一次，24 小时那条也推送到手机和桌面。你发布的题目有人过了提交截止仍未提交时，你会收到一条，写着有几个人。

打开右上角的「只看未读」，只列没读的。「全部标为已读」把「动态」里未读的都标为已读，不影响「等你处理」。

点一条打开它说的地方，同时标为已读。鼠标移到一条上，右边的时间换成「标为已读」「删除」两个按钮；手机上长按一条。删除后不能恢复。

频道里有人 `@` 你、你参与的支线有新回复，不进「动态」，而是让左侧栏这个频道的名称显示未读状态，见[频道通知](/rooms#channel-notify)。

### 提醒我 {#reminder}

「提醒我」在一个时间点给自己发一条通知，频道里的其他人看不到。

1. 在频道里点输入框左下角的「+」，选「提醒我」。
2. 选「时间」，默认是一小时后；填写「内容」，点「设置提醒」。页面提示「将在〈时间〉提醒你」。
3. 到时间后，「动态」里出现「提醒：〈内容〉」，同时按你的设置推送。点它回到那个频道。

## 通知怎么送到你 {#channels}

「设置 → 通知」的「渠道」里有 3 种：

- 「站内」：「待办」页和它的数字、圆点。默认开启。
- 「浏览器推送」：电脑或手机的系统通知，点开回到对应的任务或频道。默认开启，但浏览器要先允许知是发通知。
- 「邮件」：发到账号的邮箱，可选「即时」「摘要」「关闭」，默认「摘要」。摘要把你不在时的通知合成一封，「摘要频率」默认「每周」。

浏览器第一次被请求允许，是在芝士处理一条消息超过 1 分钟时：频道里出现「这次运行时间可能较长，完成后通知你」，点「开启通知」就是允许。每个浏览器只问一次。在「设置 → 通知」打开「浏览器推送」，也会请求允许。

芝士的问题和需要人处理的平台提示，按「渠道」的开关推送和发邮件。邀请、空间公告和有人在用你的设备这几类，还可以在「按类型」里逐类选择，见[少收一些通知](#turn-down)。

装了桌面端时，芝士的问题和需要人处理的平台提示也以系统通知弹出。离开期间积累了多条时，合成一条「离开期间有 N 条新通知」。在桌面端「设置 → 通用」打开「开机时启动」，登录电脑后桌面端在后台运行，有新通知时弹出。

## 少收一些通知 {#turn-down}

在「设置 → 通知」中，每改一项立即保存：

- 「渠道」：关掉「站内」或「浏览器推送」，或把「邮件」改成「摘要」或「关闭」。
- 「免打扰」：「安静时段」默认是 22:00 到 08:00，按你所在的时区计算，这段时间不发推送和即时邮件，摘要照常；选「不设」取消。「摘要频率」可选「每天」「每周」或「关闭」。
- 「按类型」：每一类通知单独选「站内」「推送」「邮件」。一个渠道要在「渠道」里开着、这一格也勾着，这一类才走这个渠道。

一个频道消息太多时，点频道页头的铃铛选「静音」，见[频道通知](/rooms#channel-notify)。在浏览器或系统设置里拒绝知是发通知，这个浏览器就不再弹出推送。
