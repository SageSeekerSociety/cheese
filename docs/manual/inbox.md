# 待办与通知 {#inbox}

芝士交付了由你审阅的「组会报名说明」，你的「待办」里随即多出一条「待你审阅」；采纳之后，这一条消失。

「待办」页列出等你处理的事和发给你的消息。不在知是里时，浏览器推送和邮件把消息送到你手上；送哪些、什么时候送，在「设置 → 通知」里调整。

## 「待办」在哪里 {#where}

电脑上，点最左侧一列最上面的图标「首页」，打开的就是「待办」，左侧栏第一行也是「待办」。手机上，「待办」在底栏。

这个入口上的数字是「等你处理」的件数。没有等你处理的事、但「动态」里有未读时，入口上显示一个圆点。最左侧一列每个项目的图标上，也标着这个项目里等你处理的件数。数字在切换页面、回到窗口，或在「待办」页处理完一件时刷新。

「待办」页分两块：上面是「等你处理」，下面是「动态」。

## 等你处理 {#waiting}

「等你处理」列出下一步在你手上的事，按项目分组，最近有进展的排在前面。每一条写着要你做什么、哪件任务、所在频道和时间：

- 「待你审阅」：任务交付了，等你采纳或退回，见[验收与采纳](/accept#accept)。
- 「待你回答」：芝士在问你问题。
- 「待你开始」：芝士自己想到的一件任务文档写好了，等你点「开始」放行。
- 「待你决定」：芝士请你在几个选项里选一个，选项列在这一条下面。
- 「检查未通过」：你负责的任务没有通过平台检查，芝士无法自行解决。
- 「已退回」：你负责的任务被退回，目前没有人在修改。
- 「你提的需求已有交付」：你提出的事有了交付。
- 「变更提醒」：芝士告诉你项目里改了什么。

点一条打开对应的任务、支线或频道。事情办完，这一条就从列表里消失，例如采纳或退回了交付、回答了问题、点了「开始」。「待你决定」点一个选项后消失。

「变更提醒」看过后点「标为已读」。一个项目里有 2 条以上时，项目名右边有「全部标为已读」。

已归档的频道里的事不列在这里。

## 动态 {#feed}

「动态」是发给你的消息，按时间排列，读过的仍然留着：

- 团队和项目的邀请、加入团队的申请：在这一条上点「接受」「拒绝」或「批准」，见[团队](/teams#join-request)。申请和邀请的结果也在这里，例如「你的加入请求已获批准」。
- 芝士的问题，和「等你处理」里的「待你回答」是同一件事。
- 需要人处理的平台提示，例如交付可以采纳了、额度用完了。
- 任务的提醒：你负责的任务 3 天没有进展时，收到「任务「〈任务名〉」已经 3 天没有进展」。之后有了新消息、又 3 天没有进展时，会再提醒一次。
- 自己设置的[提醒](#reminder)。
- AI 队友开始在你的设备上工作，见[自有设备](/devices#team-device)。
- 空间的公告，标着「公告」。

上方的「全部」「未读」切换显示范围，「全部标为已读」把未读的都标为已读。

点一条打开它说的地方，同时标为已读。鼠标移到一条上，可以点「标为已读」或「删除」，删除后不能恢复。

频道里有人 `@` 你、你参与的支线有新回复，不进「动态」，而是计入左侧栏这个频道的未读数，见[频道通知](/rooms#channel-notify)。

### 提醒我 {#reminder}

「提醒我」在一个时间点给自己发一条通知，频道里的其他人看不到。

1. 在频道里点输入框左下角的铃铛「提醒我」。
2. 选「时间」，默认是一小时后；填写「内容」，点「设置提醒」。页面提示「将在〈时间〉提醒你」。
3. 到时间后，「动态」里出现「提醒：〈内容〉」，同时按你的设置推送。点它回到那个频道。

## 通知怎么送到你 {#channels}

「设置 → 通知」的「渠道」里有 3 种：

- 「站内」：「待办」页和它的数字、圆点。默认开启。
- 「浏览器推送」：电脑或手机的系统通知，点开回到对应的任务或频道。默认开启，但浏览器要先允许知是发通知。
- 「邮件」：发到账号的邮箱，可选「即时」「摘要」「关闭」，默认「摘要」。摘要把你不在时的通知合成一封，「摘要频率」默认「每周」。

浏览器第一次被请求允许，是在芝士的一轮运行超过 1 分钟时：频道里出现「这次运行时间可能较长，完成后通知你」，点「开启通知」就是允许。每个浏览器只问一次。在「设置 → 通知」打开「浏览器推送」，也会请求允许。

芝士的问题和需要人处理的平台提示，按「渠道」的开关推送和发邮件。邀请、空间公告和有人在用你的设备这几类，还可以在「按类型」里逐类选择，见[少收一些通知](#turn-down)。

装了桌面端时，芝士的问题和需要人处理的平台提示也以系统通知弹出。离开期间积累了多条时，合成一条「离开期间有 N 条新通知」。在桌面端「设置 → 通用」打开「开机时启动」，登录电脑后桌面端在后台运行，有新通知时弹出。

## 少收一些通知 {#turn-down}

在「设置 → 通知」中，每改一项立即保存：

- 「渠道」：关掉「站内」或「浏览器推送」，或把「邮件」改成「摘要」或「关闭」。
- 「免打扰」：「安静时段」默认是 22:00 到 08:00，按你所在的时区计算，这段时间不发推送和即时邮件，摘要照常；选「不设」取消。「摘要频率」可选「每天」「每周」或「关闭」。
- 「按类型」：每一类通知单独选「站内」「推送」「邮件」。一个渠道要在「渠道」里开着、这一格也勾着，这一类才走这个渠道。

一个频道消息太多时，点频道页头的铃铛选「静音」，或在左侧栏这个频道的「更多操作」里点「静音」，见[频道通知](/rooms#channel-notify)。在浏览器或系统设置里拒绝知是发通知，这个浏览器就不再弹出推送。
