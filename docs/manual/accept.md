# 验收与采纳 {#accept}

芝士完成一条任务并递交成果后，话题中会出现「验收卡」。验收时先查看交付内容，再决定采纳或退回。

## 进入验收 {#open-acceptance}

待验收任务可以从话题右侧「总览」或项目看板进入。

1. 在话题右侧「总览」的待处理项，或项目看板「待处理」列中，打开相应任务。
2. 查看任务面板中的标题、状态、简报和对应的 PR（合并请求）。
3. 点击「去验收」，进入验收页面查看文件改动。

验收页面提供「差异」「编辑」页签。任务面板还提供评论框，以及「改派」「采纳」「退回」等按钮。

## 采纳交付 {#is-merge}

「采纳」用于接受当前任务的交付。确认改动符合要求后，在任务面板中点击「采纳」。采纳并合并成功后，对应 PR 的改动进入项目主线，任务显示「已采纳」，并移入看板的「已完成」。

同一话题中的多条任务可以对应不同的分支、PR 和验收卡，需要分别查看。一条任务中的多个文件可以一起交付。

## 退回交付 {#reject-delivery}

「退回」用于要求修改当前交付。点击任务面板中的「退回」后，任务会显示「交付被退回」，需要再次交付后才能重新验收。反馈时说明不符合要求的内容和期望结果，便于芝士继续处理。

## 查看交付规则 {#delivery-settings}

项目的合并要求位于「项目设置 → 交付」。页面提供合并前检查、分支与主线同步、需要的采纳人数等设置。
