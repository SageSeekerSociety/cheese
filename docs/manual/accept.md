# 验收与采纳 {#accept}

活干完，房间里会出现一张验收卡；你点采纳，这批产出当场并进项目的主线。

## 采纳就是合并 {#is-merge}

活干完，房间里会出现一张**验收卡**：它做了什么、对着你的要求逐条给了什么证据，以及一个「采纳」按钮。

**采纳就是合并本身。** 不是「标记为通过」然后还有谁去执行合并——你点下去，那批改动当场进主线。所以该看的证据要在点之前看完，别指望后面还有一道关。

「改动」不一定是代码：文档、方案、报告、一个网站，凡是芝士做出来的文件都走同一条路。

按钮灰着的时候，上方那行字会说清楚是被哪条规则拦住的（检查没过、分支落后 main、PR 上有了新提交）。这些规则在项目设置的「分支保护」里，按项目调。

一批活共用一张验收卡：**一条分支、一个 PR、一批活**，攒够了一起交，不是每干完一件就来问你一次。
