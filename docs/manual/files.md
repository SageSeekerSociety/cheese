# 文件与成果 {#files}

话题中的文件可以作为芝士处理任务的材料。生成或修改文件后，可以在话题消息和交付页面中查看改动。

## 上传文件 {#upload-file}

话题底部的「上传文件」用于提供任务所需的材料。点击后选择文件，单个文件最大 10MB。超过限制时，页面会提示无法上传。

![资料库页面：列出项目里的文件，每个文件带大小、时间，以及「下载」「删除」](/images/library.jpg)

## 查找芝士生成的文件 {#find-result}

一轮任务完成后，先查看话题中的结果消息。产生文件改动时，系统消息可能提供「查看改动」和文件名；也可以打开话题右侧的「改动」。

如果任务已进入验收，可以从任务面板点击「去验收」，在「差异」页查看文件改动。入口和步骤见[验收与采纳](/accept#open-acceptance)。

话题右侧还有可编辑文档。编辑文档会保存内容，但不会自动启动芝士。参见[编辑右侧文档](/rooms#edit-topic-document)。
