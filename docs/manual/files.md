# 文件与成果 {#files}

交给芝士的材料和它做出来的东西，都是项目里的文件。材料从话题里上传；成果在每轮结束的摘要、右侧「改动」和项目的「资料库」里找。

## 上传文件 {#upload-file}

1. 在话题底部输入框左侧点回形针按钮（悬停提示「上传文件（每个最大 10MB）」）。手机上另有一颗「照片」按钮，可以直接拍照或选图。
2. 选择文件。一条消息最多带 9 个附件，单个文件最大 10MB。
3. 写上要芝士做什么，发送。

完成后：文件跟着这条消息进入话题，芝士处理这条消息时能读到它。

文件超过 10MB 时，页面提示「〈文件名〉 超过 10MB，无法上传」。大文件请先压缩或拆分，处理办法见[常见问题与排障](/troubleshooting#upload-failed)。

## 查找芝士生成的文件 {#find-result}

- 一轮结束时，对话里的本轮摘要写着改动了哪些文件、增减多少行，点「查看改动」直接打开。
- 话题右侧的「改动」页签列出这个话题里所有改过的文件，选中一个可以看差异。
- 任务进入验收后，点验收卡上的「审阅」，同样打开「改动」，见[验收与采纳](/accept#open-acceptance)。

话题右侧的文档可以直接编辑，编辑后自动保存，但不会启动芝士，见[编辑右侧文档](/rooms#edit-topic-document)。

## 项目的资料库 {#library}

项目侧栏的「资料库」列出项目里的文件，每个文件带大小和时间，可以「下载」或「删除」。已经采纳的成果也会出现在项目首页的「做出了什么」一列。
