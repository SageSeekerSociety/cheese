# 文件与成果 {#files}

项目里的文件包括交给芝士的材料、芝士做出的成果和「资料库」里的文档。例如在频道里上传 `预算表.xlsx`，芝士根据它写出 `预算说明.md`。

## 上传文件 {#upload-file}

在频道底部输入框左侧点回形针按钮（「上传文件（每个最大 10MB）」）。选择文件，写明要芝士做什么，然后发送。手机上另有一个「发送照片」按钮，直接拍照或选图。

- 单个文件最大 10MB，一条消息最多带 9 个附件。
- 文件随这条消息进入频道，芝士处理这条消息时能读取这个文件。
- 上传的文件同时保存到项目的资料库，标明来自哪个频道。

## 文件无法上传 {#upload-failed}

页面提示「〈文件名〉 超过 10MB，无法上传」或「每条消息最多添加 9 个附件」时，这个文件没有进入频道。

压缩或拆分大文件后重新上传；附件多时分几条消息发送。

## 芝士改了哪些文件 {#find-result}

芝士修改的文件在下面几处查看：

- 这一轮的摘要：一轮结束时，对话里写着「改动了 N 个文件」和增减的行数。点「查看改动」打开。
- 任务页右侧的「改动」：列出这个任务改过的文件和每个文件的差异。点文件名跳到那一段，点「打开」查看整个文件。
- 任务页右侧「概览」的「产出」：芝士在任务中展示过的文件，点「保存到资料库」保存一份。
- 等你审阅时：输入框上方出现「待你审阅」，点它打开「改动」，查看这次交付，见[验收与采纳](/accept#open-acceptance)。

任务里的修改要等采纳后才进入项目。采纳之后的成果列在项目「总览」的「做出了什么」里，见[总览](/projects#project-home)。等你审阅的任务列在「全部任务」的「待处理」中。

## 资料库 {#library}

资料库存放项目的文档和文件，在项目左侧栏的「资料库」打开。文件夹排在前面，其余按最近修改的时间排列。文档所有项目成员都能修改，上传的文件只读。

- 顶部的「搜索标题和内容」按标题和正文找文档，按文件名找文件。
- 搜索框下方按文件类型筛选：文档、表格、PDF、图片或其他。
- 搜索和筛选的结果带完整的文件夹路径。

### 文档 {#library-docs}

资料库里的文档支持多人同时编辑，芝士也能阅读和修改。

- 点右上角的「新建文档」，资料库新建一份「未命名文档」并直接打开，在标题处输入名称。
- 在频道里让芝士写一份单独的文档，文档建在资料库里，对话中出现这份文档的卡片。在支线里写的，卡片出现在那条支线里。点卡片在右侧打开文档，芝士修改的地方逐一标出。
- 项目总览不在列表里，在「总览」、频道「综合」右侧的「概览」和「项目文档 → 章程」中打开。
- 芝士在任务里写的文档也不在列表里，搜索时列在「对话里的文档」下。点「另存为文档」把当前内容复制一份到资料库，之后两份分别修改。

文档顶部的「⋯」菜单包括修改记录、导出 Markdown、设为只读和删除文档。删除后无法恢复，历史版本和评论一起删除。

### 文件 {#library-files}

点开一个文件，右侧显示文件内容（手机上是新的一页），上方有「下载」和「替换为新版本」。从频道上传的文件还写明来自哪个频道、有几条消息引用了它。

- 「替换为新版本」：文件名不变，引用它的消息改为读取新版本。旧版本保留，在文件那一行「⋯」的「版本…」里查看。
- 「删除」在文件那一行的「⋯」里。删除后无法恢复，引用过它的消息也打不开这份文件。

在资料库里点右上角的「上传文件」，或把文件拖到页面上，也能上传。同名文件不会覆盖，第二份自动命名为 `预算表(2).xlsx`。

### 文件夹 {#library-folders}

文件可以放进文件夹，文档只能放在最上层。点文件夹进入其中，点上方的「资料库」或某一级文件夹名返回对应的层级。

- 新建：点右上角的「新建文件夹」，填名称后进入这个空文件夹，再上传文件。文件夹里有文件后才保留，未放入文件就离开时不再显示。
- 移动或重命名：在文件或文件夹的「⋯」里点「移动或重命名」，选择文件夹或修改名称。引用它的消息随之更新；目标位置已有同名文件时不能移动。
- 删除：在文件夹的「⋯」里点「删除」，其中的文件一起删除，无法恢复。
