# 完成一道题目 {#solve-a-challenge}

这一页带你领一道老师在空间里发的题目，在它的项目里和芝士一起做完，再交上去。比如老师在「数据结构课程」空间里发了一道「B 树的插入与删除」：用 C 实现一棵 3 阶 B 树，交源代码和一份实验报告。

开始前，你需要一个知是账号和老师给的邀请码。芝士在平台的云端干活，不用准备电脑。

:::steps

### 加入空间 {#join}

用老师给的邀请码进入空间，空间里列着这门课的题目。

「空间」页 → 侧栏「用邀请码加入」→ 填「邀请码」→「加入」。

页面转到空间的「全部题目」。以后这个空间也列在侧栏的「空间」下面。

### 读懂题目 {#read}

点一道题打开题目页。「说明」里是题目详情，右侧「题目信息」写着形式、截止、提交期限、提交次数和难度。

读不懂的地方，点右上角的「问芝士」，在题目页里直接问：

```prompt
这道题要交什么？「3 阶」B 树和普通二叉搜索树差在哪？
```

```prompt
做这道题要先会什么？按顺序列三件事。
```

「问芝士」只读题目本身，读不到附件，每次提问扣你的个人额度，见[问芝士讲懂一道题](/ask-about-a-challenge#ask-about-a-challenge)。

### 领取题目 {#claim}

领取后，平台给你建好一个和题目同名的项目，报名交给老师批准。

1. 点「领取这道题」。
2. 在「参与确认」里填「手机号」或「邮箱」（至少一项），「申请理由」可以不填。
3. 点「确认参与」。

页面提示「报名已提交，项目已准备好」，并转到这个项目的首页。

回到题目页，右侧「我的进度」写着「领取申请待批准」。老师在「领取者」里点「批准」后，这里显示还剩几天、交到第几版，下面列着这个项目。

![交过一版后的题目页：右上角是「问芝士」和「提交新版本」，右侧「我的进度」写着「第 2 版待评审」「还剩 30 天」，下面是从这道题建的项目和「用这道题新建项目」](/images/challenge-progress.jpg)

> [!NOTE]
> 不用再点「用这道题新建项目」，领取时已经建好一个。再点会另建一个新项目。

### 和芝士一起做 {#work}

在题目的项目里和芝士讨论、动手。点「我的进度」里的项目名进入项目，再点侧栏的「综合」。

「综合」右侧「概览」最上面的「项目总览」里有一节「赛题要求」，写着题目详情，芝士也读得到它；「项目总览」标题下方写着你的提交截止时间，按你所在的时区显示。在「综合」里点名芝士，它在那条消息的支线里回答，见[支线](/rooms#threads)。先让它讲清要做什么：

```prompt
@芝士 照着赛题要求，先说说要交什么、做到什么程度，列出要做的几步，先别写代码。
```

```prompt
@芝士 我想自己写插入。测试要覆盖哪些情况？节点分裂和删到只剩根节点各举一个例子。
```

要芝士改项目里的文件时，把这件事建成一个任务，讨论清楚后点「开始」，见[任务](/tasks#task)。完整的做法见[和同学一起做一个项目](/team-project#team-project)。<!-- 待确认：本地没有模型，芝士在题目项目里的实际回复和任务流程未实测 -->

### 提交 {#submit}

做完后，回到题目页交作品。

1. 点题目页右上角的「提交作业」。
2. 在「提交表单」里按每一项要求填写：文件项点上传，文本项直接写。
3. 点「提交」。

页面转到「我的提交」，最上面是这一版，写着「等待评审中」。

单个文件不超过 50MB，页面顶部有「提交剩余时间」倒计时。老师批准报名之前交不了，见[提交 · 不能提交时](/submissions#blocked)。

:::

> [!TIP]
> 老师驳回后，按评语改完再交一版，见[改完再交一版](/resubmit#resubmit)。
