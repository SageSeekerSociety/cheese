# 反馈中心 {#feedback}

遇到 bug、有改进建议，或者其他想告诉平台团队的事，都在反馈中心提交。提交后可以随时回来看处理到哪一步。

## 打开反馈中心 {#open}

点击顶栏右侧的「帮助与反馈」，在菜单中选择「反馈中心」。菜单里还有「我的反馈」，以及「使用文档」（就是这份文档）。

反馈中心列出所有公开的反馈，可以按「全部」「热门」「处理中」「已完成」切换。搜索框会搜标题、摘要、正文和提交人；下面还能按类型、状态、作者和时间筛选，点「清除筛选」恢复。

![反馈中心：上方是搜索框和「提交反馈」按钮，下面按「全部」「热门」「处理中」「已完成」列出反馈，每条带提交人、评论数、状态和支持数](/images/feedback.jpg)

## 提交反馈 {#submit}

点击「提交反馈」，先选这是一条什么样的反馈：

- 「Bug」：有操作出错了、坏了；
- 「建议」：希望某个地方变得更好；
- 「其他」：不属于上面两类。

然后填写「标题」和正文，这两项必填。正文这一栏的名字随类型变：Bug 是「发生了什么」，建议是「哪里不好用」，其他是「描述」。

其余都是选填，写得越具体，越容易被认领和复现：

- 「你原本期待什么」（Bug 和建议才有）：同一个操作，你原本期待的结果；
- 「怎么重现」（只有 Bug 有）：从打开页面到看见问题的最短一串操作；
- 「标签」：方便归类，比如登录、移动端，输入后按回车添加。

### 公开还是私密 {#visibility}

提交前在「可见范围」里选择：

- 「公开」：所有用户可见，其他人可以支持和评论；
- 「私密」：只有你和平台管理员可见（如果是在某个话题里提出的，那个话题里的人也能看到），不进公开列表，也不能被支持。

这个选择只能在提交时做一次，提交后不能再改成公开。反馈里涉及代码、文件路径或对话内容时，建议选「私密」。

## 让芝士帮你提 {#from-agent}

在话题里遇到问题时，芝士有时会整理好一条反馈，附上发生了什么、复现步骤和相关证据，在对话里给你一张卡片。确认内容后点提交，这条反馈的作者会记成芝士，提交人记成你。

## 跟进处理进度 {#track}

每条反馈都有状态，依次是：

1. 「已收录」：平台团队收到了；
2. 「处理中」：有人在处理；
3. 「已修复」：改好了，但还没发布；
4. 「已上线」：已经部署，可以用了。

在「我的反馈」里能看到你提过的全部反馈。有新进展或新评论时，「帮助与反馈」旁会出现未读提示。

## 支持和评论 {#support}

看到别人提的问题你也遇到了，点「支持这个反馈」。被支持得多的反馈更容易进「热门」、被优先处理；支持数按时间折算，越新的支持越算数，「热门」上方有具体说明。也可以在下面评论，补充你遇到的情况，或者说明为什么这个改动对你重要。已经办完的反馈不再接受支持。
