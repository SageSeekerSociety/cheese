# 反馈中心 {#feedback}

反馈中心用来向平台团队报告问题和提出建议，例如报告“手机上看不到上传按钮”这样的 Bug。提交之后，在同一处跟踪它的修复和上线进度。

## 打开反馈中心 {#open}

点页面顶部右侧的「帮助与反馈」，在菜单中选「反馈中心」。同一个菜单里还有「使用文档」和「我的反馈」。手机上「帮助与反馈」是顶栏右侧的一个图标。

反馈中心列出公开的反馈，分四个页签：

- 「全部」：未完成的反馈，以及已完成的建议和其他类反馈；已完成的 Bug 不在这里。
- 「热门」：支持多、尚未完成的反馈。支持数按时间折算，越新的支持分量越重，页签上方有具体的计算说明。
- 「处理中」：平台团队正在处理的反馈。
- 「已完成」：状态为「已修复」「已上线」或「不修复」的反馈。

搜索框按标题、摘要、正文和提交人搜索。下方按类型、状态、时间和作者筛选，筛选后出现「清除筛选」。

## 提交反馈 {#submit}

点「提交反馈」，先选反馈的类型：

- 「Bug」：有操作出错了、坏了；
- 「建议」：希望某个地方变得更好；
- 「其他」：不属于上面两类。

「标题」和正文必填。正文一栏的名称随类型变化：Bug 是「发生了什么」，建议是「哪里不好用」，其他是「描述」。

下面几项选填：

- 「你原本期待什么」（Bug 和建议）：做这个操作时，你原本期待看到的结果。
- 「怎么重现」（只有 Bug）：从打开页面到看见问题的最短操作顺序。
- 「标签」：用于归类，例如「登录」「移动端」，输入后按回车添加。

### 公开还是私密 {#visibility}

提交前在「可见范围」中选择：

- 「公开」：所有用户可见，其他人能支持和评论。
- 「私密」：只有你和平台管理员可见，不进公开列表，其他人不能支持。

可见范围只能在提交时选择，提交后连管理员也不能把它改成公开。反馈里有代码、文件路径或对话内容时，选「私密」。

## 芝士整理的反馈 {#from-agent}

在频道里遇到问题时，芝士可能整理好一条反馈，写明发生了什么、重现步骤和相关证据。这条反馈以卡片出现在对话中，卡片上有「查看详情」「不用」和「提交反馈」。

点「提交反馈」打开「发送这条反馈」，内容可以修改，确认后点「发送」。这条反馈的作者记为发现问题的 AI 队友，提交人记为你。选「私密」时，芝士提出这条反馈时在该频道中的成员也能看到。

## 处理状态 {#track}

每条反馈都有一个状态，正常依次经过：

1. 「已收录」：平台团队已收到。
2. 「处理中」：有人正在处理。
3. 「已修复」：已经修复，还没有上线。
4. 「已上线」：已经部署，可以使用。

平台团队决定不修改时，状态是「不修复」。原因写在评论里，例如这是有意的设计，或平台无法重现。处于「已修复」「已上线」「不修复」的反馈算作已完成。

「我的反馈」列出你提交的反馈、你替 AI 队友提交的反馈，以及指派给你的反馈。这些反馈有新状态或新评论时，「帮助与反馈」旁出现一个红点。

## 支持和评论 {#support}

遇到别人已提交的同样问题时，在反馈详情页点「支持这个反馈」。按时间折算后的支持数决定反馈能否进入「热门」。已完成的反馈不能再支持，按钮上写着「已办完，无需再支持」；私密反馈没有支持按钮。

在详情页下方评论，补充你遇到的情况，或说明这条反馈对你为什么重要。
