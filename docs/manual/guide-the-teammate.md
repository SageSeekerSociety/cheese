# 设置 AI 队友辅导 {#guide-the-teammate}

以数据结构课的 B 树作业为例，设置学生项目里的芝士怎么辅导：只给提示，由学生自己写出代码。

:::before
需要是空间的所有者或管理员。新建空间的步骤见[发布一道题目并收作业](/publish-a-challenge#create-space)。
:::

## 设置整个空间 {#space-default}

「AI 队友辅导」是给芝士的设置，学生看不到原文。芝士是项目里的 AI 队友。在从这个空间的题目创建的项目中，芝士开始新对话时读取这份设置。

:::walk
1. 在空间左侧栏点「设置」，再点「AI 队友辅导」。
2. 在「方式」中选一种，例如「引导为主」。
3. 在「补充要求」中写下这门课自己的要求。
4. 点页面底部的「保存」。页面提示「已保存」。

「方式」有四种：

| 方式 | 芝士怎么做 |
|---|---|
| 「引导为主」 | 以提问引导思考，不直接给出答案 |
| 「讲解与示例」 | 可讲解概念、举例说明，不代为完成作业 |
| 「先明确需求再实现」 | 要求先说明目标和验证方法，再开始编写 |
| 「不加限制」 | 按成员的要求提供帮助 |

都不选、「补充要求」也留空时，这个空间不设辅导要求。

### 写要求的建议 {#write-it-well}

「补充要求」写方式之外这门课特有的规矩：讲到哪里了、哪些写法还没教、学生问到报告时怎么帮。例如：

```text
这是《数据结构》课的作业陪练，课上讲到了 B 树。不要用递归以外还没教的写法。
学生问到实验报告时，只帮他理清结构、检查表述，不替他写测试结果和结论。
```

## 按课程进度更新 {#placeholders}

课程进度变了，直接改「补充要求」里的那句话，例如把「课上讲到了 B 树」改成「课上讲到了图」，再点「保存」。之后新开始的对话按新的要求来。

## 添加参考资料 {#materials}

「可读取的资料」是从空间资料库中勾选的文件，芝士回答时会参考这些文件。

先在空间左侧栏的「资料库」中点「上传资料」，选择文件，「可见范围」保持「所有成员」，点「上传」。

然后回到「AI 队友辅导」，点「点击从资料库选择」，勾选这份文件，点「保存」。

可见范围是「仅管理员」的资料不在这份清单里，学生项目里的芝士也读不到。

## 给单道题加设置 {#per-challenge}

某道题需要额外的要求时，在发布或编辑这道题时加上。这道题的设置和空间的同时生效。

在发布表单的「AI 的设置」中填写：

- 「方式」保持「沿用上层设置」，或者为这道题另选一种。
- 在「本题补充要求」中写这道题自己的要求，例如：

```text
这道题考 B 树的删除。学生问到删除时，先让他画出删除前后的节点，再讨论借键还是合并；不要给出删除函数的代码。
```

- 「可读取的资料」中勾选这道题要用的文件，和空间勾选的一起交给芝士。
- 「技能」中选这道题要用的技能，例如要算数值的题选 `wolfram`。项目里的每个 AI 队友每一轮都带上它们。

下方的「同时生效的空间要求」列出空间那一份，写的时候不用重复。
