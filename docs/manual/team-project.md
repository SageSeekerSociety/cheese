# 和同学一起做一个项目 {#team-project}

这一页带你和同学建一个团队，在团队的项目里一起让芝士干活，最后把项目导出来。

芝士是项目里的 AI 队友，你在话题里把要求交给它，它去做。开始前需要：

- 你和每位同学各有一个知是账号；
- 一台芝士能用的工作电脑，见[设备与工作电脑](/devices#devices)。

## 1. 建一个团队 {#create-team}

先建一个团队，你们组的项目都放在它下面。

1. 在首页侧栏的「团队」下面，点「新建或加入团队」。
2. 点页面顶部的「创建团队」，弹出「创建团队」对话框。
3. 填「团队名称」，比如「数据结构小组」。其余几项可以不填。
4. 点对话框里的「创建团队」。

完成后：页面转到这个团队的「项目」页，写着「还没有项目」。

侧栏的「团队」下面还没出现这个团队时，刷新页面。

## 2. 复制团队链接 {#share-link}

同学通过团队链接申请加入团队。

1. 在侧栏这个团队下面点「成员」。
2. 在「团队地址与加入」一栏，点「团队链接」旁的「复制链接」。
3. 把链接发到你们的群里。

![团队「成员」页的「团队链接」：链接右边是「复制链接」和「重置链接」，下面的「加入需要审批」默认开着](/images/team-link.jpg)

「加入需要审批」默认开着，所以同学打开链接后要先申请，再由你批准。

## 3. 同学申请加入 {#apply}

这一节由每位同学在自己的账号里做。

1. 打开团队链接。
2. 没登录时，点「登录并继续」。登录后回到团队页面，页面上写着「加入这个团队需要团队所有者或管理员批准」。
3. 点「申请加入」。「申请理由（选填）」可以不填。

完成后：页面显示「已提交申请，等待团队管理员审批」。

等你在第 4 节批准后，同学刷新这一页，页面显示「你已经在这个团队里」；点「进入团队」进入团队。

## 4. 批准申请 {#approve}

回到你自己的账号，逐个批准同学的申请。

1. 在侧栏这个团队下面点「成员」。
2. 切到「加入申请」页签。
3. 在同学那一行点「批准」。

完成后：页面提示「已批准申请」。

## 5. 在团队下建项目 {#create-project}

项目建在团队下，团队里的人不用再邀请就能进。

1. 在团队的「项目」页，点右上角的「新建项目」。
2. 填「项目名称」，比如「数据结构大作业」。其余两项保持默认（见下图）。
3. 点「下一步」。
4. 按需修改「队友名字」，或点「随机取名」。这是项目里 AI 队友的名字，界面上显示的是它，本页统称芝士。
5. 点「创建项目」。

![在团队下新建项目：「归属」是这个团队，「代码仓库」是「平台托管（默认）」，右下角是「下一步」](/images/new-project-team.jpg)

完成后：屏幕最左边那一列图标里，多出这个项目的图标。

这个项目同时出现在每位同学的最左边一列和团队的「项目」页里。项目「成员」页上，同学列在「团队成员」下面。

## 6. 把要求交给芝士 {#hand-off}

在项目的话题里写清要做什么，再交给芝士。

1. 点最左边一列里这个项目的图标，进入项目的「看板」。
2. 点「进入对话」，进入「全局」话题。
3. 在输入框里写要求，写清要交什么、做到什么程度，比如：

   > 用 C 实现一个 B 树，支持插入、删除和查找。再写一份实验报告，列出测试用例和结果。

4. 点输入框旁的「@ 交给〈队友名字〉」，消息开头会加上「@〈队友名字〉」。
5. 按 Enter 发送。

按 `Ctrl/Cmd+Enter` 等于第 4、5 两步一起做。

完成后：芝士在对话里回复，开始处理这条消息。<!-- 待确认：本地环境没有可用的工作电脑，没能看到芝士实际开工后对话里的样子 -->

话题里出现「本轮未完成：这条会话的机器尚未配置或未连接」时，见[提示机器未配置或未连接](/devices#device-offline)。芝士做完后，看板「待处理」一列会出现一张待审阅的卡，见第 8 节。

## 7. 叫同学一起看 {#mention}

同学从看板点「进入对话」，就进入同一个话题，能看到你们和芝士的全部对话。<!-- 待确认：同学在话题里发言未实测，只核对了同学能看到项目 -->要某位同学看一条消息时，在消息里提到他。

1. 在输入框里输入 `@`，从弹出的列表里选同学的名字。
2. 写上要他看什么。
3. 按 Enter 发送。

完成后：发出的消息里，同学的名字显示成「@〈名字〉」标签。

这条消息没有点名芝士，芝士不会处理它，见[让 AI 队友处理消息](/agents#summon)。

## 8. 审阅芝士做出的改动 {#review}

芝士做完一件事后，项目看板上出现一张待审阅的卡，由卡上写的那个人审阅。

1. 点侧栏顶部的项目名，打开项目「看板」。
2. 在「待处理」一列，打开标着「待审阅」的那一件。
3. 卡上写着「待 @〈名字〉 审阅」。名字是你时，点「审阅」。

完成后：右侧列出芝士改了哪些文件。<!-- 待确认：「审阅」之后右侧显示什么未实测；示例项目里这张卡的按钮是「审阅」「创建 PR」「退回」「作废」，没有「采纳」 -->

名字不是你时，由那位同学审阅；要换人，点卡上的「更换」。看完后采纳还是退回，见[验收与采纳](/accept#is-merge)。

## 9. 导出项目 {#export}

要把做好的东西交出去或者留一份，把整个项目打包下载。

1. 把鼠标停在侧栏顶部项目名右边的下拉箭头上，它显示「项目菜单」；点开它。
2. 选「项目设置」。
3. 在左边「数据」下面点「导出项目」。
4. 点「导出项目」按钮。

完成后：浏览器下载一个 `.tar` 包。按页面上的说明，包里有「代码仓库、资料库文件、各房间的文件与产物、每份文档」。

团队里的每位成员都能导出。要把作品交到老师发布的题目里，见[完成一道题目 · 提交](/solve-a-challenge#submit)。
