# 验收芝士交回来的改动 {#review-changes}

这一页带你验收芝士做完的一件任务：找到等你审阅的那一件，看清改了什么，再决定采纳、退回还是作废。比如芝士刚把你们的报名表单从 9 项必填改成 4 项，卡上写着「待你审阅」，你要确认它改对了再让改动进项目。

开始前，你得是卡上点名的审阅人。不是你的话，可以在「改动」页顶部的「⋯」里点「改由他人审阅」。

## 找到等你审阅的任务 {#find}

等你审阅的任务会出现在三个地方，从哪一处进都是同一件任务。

- 待办：「等你处理」下面一行写着任务名和「待你审阅」，点它打开任务。
- 全部任务：项目菜单 →「全部任务」→「待处理」，那一行写着「待你审阅」。
- 任务页：输入框上面有一行「待你审阅」，右边是「退回」和「采纳并完成任务」。

点「待你审阅」那几个字，右边切到「改动」页签。最上面写着这次交付的标题、检查和合并的情况，以及芝士写的审阅重点。<!-- 待确认：新版「改动」页的截图还没有补 -->

## 审阅一件任务 {#review}

先看改动，再问清楚，最后做决定。

:::steps

### 看它改了什么 {#diff}

「改动」页签里，这件任务改了的每个文件一段，差异一个接一个往下排。左边的文件列表点哪个文件就跳到哪一段；要看全文，点那一段右边的「打开」。

一件任务里的几个文件是一起交、一起采纳的，看完全部再决定。

> [!NOTE]
> 「改动」只列这件任务改过的文件。要看项目里其他没改过的文件，点「打开其他文件」，按名字找。

### 问清楚再决定 {#ask}

看不懂的地方，直接问芝士。任务的负责人和协作者在任务页左边的对话里问；你只是审阅人时，到这个任务所在的频道里 `@芝士` 问。

```prompt
@芝士 这次改了哪几个文件？每个文件用一句话说改了什么，有没有动到我没要求改的地方。
```

```prompt
@芝士 必填项为什么留的是姓名、学号、手机号、场次这四个？去掉的那几项以后从哪里来？
```

```prompt
@芝士 你是怎么确认手机上一屏能填完的？把检查的方法和结果发给我。
```

### 采纳、退回或作废 {#decide}

看清楚之后，在输入框上方那一条上选一个，作废在「改动」页顶部的「⋯」里。

- 「采纳并完成任务」：改动合进项目，任务显示「已采纳」，芝士写完总结后任务结束，在「全部任务」里点「已关闭」能看到它。芝士说明后面还有步骤时，按钮写「采纳」：改动合进项目，任务继续，芝士接着做下一步。
- 「退回」：输入框的位置换成「退回理由（可选）」，写清哪里要改，点「退回」。芝士接着改，改完会再交一张新的验收卡。
- 「作废」：结束这次审阅，不合并也不退回，在「作废理由（可选）」里写一句，点「作废」。之后可以重新提交审阅。

退回理由写清改哪里、改成什么，比如：

```prompt
「院系」不能去掉，老师要按院系统计。把它加回必填，其余保持 4 项。
```

要对着具体几行说时，在「改动」里写批注：点行号旁的「+」，按住 Shift 再点另一行可以选一段。打开「修改建议」，把选中的几行直接改成想要的样子。批注写下就存着，送出前只有你自己看得到；点「退回」时和理由一起送出，退回框里可以把某一条留到下次。芝士再提交时会逐条说明处理了没有，「改动」页顶部写着上一轮处理了几条。

交上来的是 Word、表格或幻灯片时，在「改动」里打开它：选中一段文字、点一个单元格，或在幻灯片上选中文字，就能对着那一处写批注。点「对比上一版」看这一版改了什么：Word 按段落并排，表格列出变了的格子和原来的值，幻灯片标出改过和新加的页。第一次交的和任务开始时的版本比，退回过的和退回时那一版比。待审阅时 Word 里的修订只能看，不想要的那一处写一条批注。

> [!TIP]
> 主按钮的名字会变：任务还没有合并请求（PR）时是「创建 PR」；检查没跑完或芝士还在修时，横条上没有采纳按钮。每种情况见[验收与采纳](/accept#is-merge)和[采纳按钮是灰的](/accept#accept-blocked)。

:::

## 采纳之后 {#after}

采纳之后，改动已经在项目里。芝士写完总结，任务页底部写着「任务已关闭」。

做出来的东西列在「总览」的「做出了什么」里，每一样写着第几版。采纳的是网页时，可以接着发布成网站，见[把网页发布成网站](/publish-a-site#publish-a-site)。
