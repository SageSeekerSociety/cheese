# 和队友一起做一道团队题目 {#team-challenge}

这一页带一个小组以团队身份领一道团队题目，在团队的项目里和芝士一起做，再由任何一位队员交上去。比如老师发了一道团队题「小组项目：简易数据库索引」，你和两位同学组成一队来做。

开始前，你们三人都已经用邀请码加入了这个空间，见[完成一道题目 · 加入空间](/solve-a-challenge#join)。

:::steps

### 先组好团队 {#team}

团队题只能以团队身份领取，所以先建一个团队，把队友拉进来。

- 建团队：「团队」页 →「创建团队」，填「团队名称」。
- 邀请队友：团队侧栏「成员」→「邀请成员」，填对方完整的用户名或邮箱，确认下面显示的是要邀请的人，点「邀请」。
- 队友接受：队友在「待办」的动态里点「接受」，或在「团队 → 待定」的「收到的邀请」里点对勾。

题目页右侧「题目信息」的「形式」写着每队几个人，比如「团队 · 1–10 人」。人数不在这个范围里的团队领不了。

### 以团队身份领取 {#claim}

领取时选一个团队代表你们参加，一队领一次就够了。

1. 在题目页点「领取这道题」。
2. 在「选择参与团队」里点你们的团队；能领的团队标着「可参与」。
3. 在「参与确认」里填「手机号」或「邮箱」，点「确认参与」。

![「选择参与团队」对话框：「请选择一个团队代表参与此题目」，下面一行是团队名和「可参与」](/images/team-claim.jpg)

平台给这个团队建好一个和题目同名的项目。队友不用再做什么：项目出现在每个人的侧栏里，「成员」页上列在「团队成员」下面。

> [!NOTE]
> 「参与确认」里写着「系统将记录审核通过时的队伍成员名单」。老师批准时的成员就是这次参与的名单，之后再进团队的人不算在里面。

### 分工和芝士一起做 {#work}

三个人在团队项目的「综合」里商量，点名芝士时，它在那条消息的支线里回答；各自要做的事建成任务。

先让芝士帮你们拆活：

```prompt
@芝士 照着赛题要求，把这道题拆成三块，每块写清要交什么，我们三个人各领一块。
```

```prompt
@芝士 先定下索引模块的接口：插入、删除、查找三个函数的签名和返回值各是什么？我们照着各自写。
```

每人负责的那一块建成一个任务，自己当负责人，需要帮手就把队友加成协作者，见[任务](/tasks#task)。<!-- 待确认：本地没有模型，芝士拆活和任务流程的实际回复未实测 -->

### 交作品 {#submit}

团队的作品交一次就算整队交了，任何一位队员都能交。

老师批准报名后，队员在题目页点「提交作业」，填好「提交表单」，点「提交」。交过之后按钮变成「提交新版本」。<!-- 待确认：其他队员的「我的提交」里能看到这一版未实测（本地交文件的提交显示不出来） -->

:::

> [!WARNING]
> 一个人一道题只能领一次。你已经跟着别的团队领过这道题时，这个团队就领不了，换一支没人领过的队。
