# 课程与作业 {#courses}

课程是一种空间，按周把教学排成一串「教学单元」。老师每周发布这一周讲什么、要交什么；学生在「我的课程」里看到这一周要做的事，交作业、做小测。

## 加入课程 {#join}

老师会发一条课程链接。点开后先登录，系统会自动把你加进这门课，并建好你在这门课的项目，然后进入课程首页。

第一次进入时会问「要不要找同学组队？」。可以选「先一个人」，以后随时能在「我的小组」里改。

也可以用邀请码加入，见[空间与题目 · 加入空间](/challenges#join)。

## 学生：我的课程 {#student}

课程首页「我的课程」有两块：

- **本周任务**：「第 N 周」要做什么。这一周有作业就点「去交这一周的作业」，有小测就点「去做这一周的小测」。
- **我在这门课里做的**：老师发布作业之后，你要做的东西会列在这里。

老师还没发布这一周的内容时，会显示「老师还没有发布这一周的内容」。

### 做小测 {#quiz}

在小测页答完题后点「交卷」。客观题当场出分；简答题显示「简答等老师判」，老师判完后分数会更新。截止前可以改答案，点「改完再交一次」。

### 我的小组 {#team}

「我的小组」页可以「建一个组」，也可以在「邀请我加入」里接受别人的邀请，或者撤回自己发出的申请。一个组共用一个项目。

## 老师：开一门课 {#teacher}

先[新建空间](/challenges#create)，审核通过后就是一门课。课程左侧栏有「课程总览」「教学单元」「作业与验收」「学生与分组」「共性问题」「设置」；学生看到的是「我的课程」「本周任务」「我的小组」。

### 排教学单元 {#units}

1. 打开「教学单元」，点击「加一个单元」。
2. 填写「第几周」（从 1 开始）、「这一周讲什么」（学生会看到这一句）和可选的「说明」。
3. 这一周要交作业时，在「这一周要交的东西」里选一道这门课里的题目；纯讲义的周不选。可以设「截止时间」。
4. 勾选「建好就发布」则立刻对学生可见；不勾就先存着，到了这一周再点「发布」。

没有发布的单元，学生看不到。可以先把整学期排好，每周发布一个。

### 出小测 {#make-quiz}

在单元上点「加小测」，填写小测名称和截止时间，再「加一道题」：题型有单选、多选、判断、填空和简答，每道题设分值和答案。填空题可以写多个「可接受的答案」，判分时忽略大小写和首尾空格。简答题机器不判，「参考要点」是写给你自己看的。

学生交卷后，「等着判的简答」里会列出待判的题，点「判分」给分并写评语。「全班交得怎么样」显示每个学生的分数和状态。

### 收作业、打分 {#grade}

「作业与验收」页按「待验收」「全部」列出学生交上来的作业，每人只算最新一版。点「打开」查看提交内容并打分。

### 学生与分组 {#people}

「学生与分组」页显示这门课有哪些学生、分了哪些组、谁还没有组。目前分组由学生自己完成，这一页只能查看。

### 课程参数 {#settings}

「设置」→「课程参数」里可以：

- 打开或收起课程模块。收起只是从侧栏和课程首页隐藏，地址仍能打开。
- 填写「本周教学」：当前周次、本周内容、这周还不该用的知识点、课件和知识条目编号。学生从这门课的项目新开会话时，芝士会读到这些设置。
