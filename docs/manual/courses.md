# 课程与作业 {#courses}

课程是一种空间，按周把教学排成一串「教学单元」。老师每周发布这一周讲什么、要交什么；学生在「我的课程」里看到这一周要做的事，交作业、做小测。新建的空间默认就是课程。

## 加入课程 {#join}

1. 点开老师发的课程链接。还没登录会先跳到登录页，登录后回到这条链接。
2. 页面显示「正在把你加进这门课……」：系统把你加进课程，并建好你在这门课的项目。
3. 第一次进入会弹出「要不要找同学组队？」：点「先一个人」，或点「去看看小组」。以后随时能在「我的小组」里改。

![点开课程链接加入后，弹出「要不要找同学组队？」，可以选「先一个人」或「去看看小组」](/images/join-course.jpg)

完成后：进入课程首页，左侧栏出现课程自己的几屏。

没有链接时，用邀请码加入，见[空间与题目 · 加入空间](/challenges#join)。

## 学生：我的课程 {#student}

课程首页是学生看这一周要做什么的地方，分两块：

- **本周任务**：显示「第 N 周」和老师写的那句话。有作业点「去交这一周的作业」，有小测点「去做这一周的小测」。老师还没发布时显示「老师还没有发布这一周的内容。」
- **我在这门课里做的**：你要做的每一道题和它的状态：还没交、等老师看、可以重交、没通过、已通过。

左侧栏的「本周任务」按周列出所有已发布的单元，这一周排在最前，每周的作业带着完成状态，有小测的给小测入口。

![课程首页的学生视图：本周任务卡片上有「去交这一周的作业」，下面是「我在这门课里做的」](/images/course-student-home.jpg)

打开题目以后怎么领取、提交，见[学生：在空间里完成第一道题目](/student-tutorial#claim)。

## 做小测 {#quiz}

1. 在课程首页「本周任务」里点「去做这一周的小测」。
2. 按题型作答：单选、多选点选项，判断题选「对」或「错」，填空和简答写文字。
3. 检查一遍，点「交卷」。

完成后：客观题当场出分，每题旁边显示得分，简答题显示「简答等老师判」；顶部显示「我的分数 X / Y」。

截止前交过卷也还能改：改完点「改完再交一次」，新的答案会替换上一次的。过了截止时间，作答项锁定，页面显示「这次小测已经截止，不能再改了。」

## 我的小组 {#team}

「我的小组」管你在这门课里和谁一组，一个组共用一个项目。

| 区域 | 能做什么 |
|---|---|
| 还没有组时 | 点「建一个组」，填「组名」，点「建组」 |
| 邀请我加入 | 同学邀请你时列在这里，点「加入」接受，或点「拒绝」 |
| 我在等的申请 | 你申请过的组列在这里，点「撤回」收回申请 |
| 我加入的组 | 你加入的所有组；这门课用的那个带「这门课的组」标签 |

![「我的小组」页：上面是这门课的组和成员，下面是「邀请我加入」「我在等的申请」「我加入的组」](/images/course-team.jpg)

## 老师：开一门课 {#teacher}

先[新建空间](/challenges#create)，平台审核通过后就是一门课。完整流程见[老师 / 助教：开一门课](/teacher-tutorial#tut-teacher)。

| 身份 | 左侧栏条目 |
|---|---|
| 老师（本空间管理员） | 课程总览、教学单元、作业与验收、学生与分组、共性问题 |
| 学生 | 我的课程、本周任务、我的小组 |

「设置」只对老师出现：课程参数、审核题目、管理题目模板、数据分析、管理分类话题、管理内容分类、域名组管理、邀请码。

课程里没有「全部题目」入口：发布作业题走「作业与验收」里的「去发布作业」，自己发过的题和报名情况在「我发布的题目」页（`/spaces/<空间号>/tasks/my/publishing`）。

## 排教学单元 {#units}

1. 打开「教学单元」，点「加一个单元」。
2. 填「第几周」（从 1 开始）和「这一周讲什么」（学生会看到这一句）；「说明」选填。
3. 这一周要交作业时，在「这一周要交的东西」里选一道已过审的题；纯讲义的周选「不布置作业」。
4. 需要时设「截止时间」。
5. 勾「建好就发布」则立刻对学生可见；不勾就先存着，到了这一周再点「发布」。点「保存」。

![「教学单元」页：按周次列出单元，每行有「已发布」标签和「加小测」「撤回发布」等按钮](/images/course-units.jpg)

完成后：单元显示「已发布」，学生的「本周任务」里出现它。

列表里每一行还可以「加小测」（已有小测时是「改小测」）、「撤回发布」、删除。

## 出小测 {#make-quiz}

小测挂在某一周的教学单元上。

1. 在单元那一行点「加小测」。
2. 这一周还没有小测时，点「出这一周的小测」，填「小测名称」和「截止时间」（留空表示不设截止），点「保存」。
3. 在「卷面」里点「加一道题」：选「题型」，写「题目」，设「分值」和答案。

| 题型 | 答案怎么填 |
|---|---|
| 单选 | 选项一行一个，答案填正确选项 |
| 多选 | 选项一行一个，答案填所有正确选项 |
| 判断 | 答案选「对」或「错」 |
| 填空 | 「可接受的答案」一行一个；判分时忽略大小写和首尾空格 |
| 简答 | 机器不判；「参考要点」写给你自己看 |

![小测页（老师）：卷面列出题目和答案，下面是「等着判的简答」和「全班交得怎么样」](/images/course-quiz.jpg)

完成后：这一周的小测出现在学生的「本周任务」里。

学生交卷后，在「等着判的简答」里点「判分」，填「给分（最高 N）」和「评语（可选）」，保存。「全班交得怎么样」列出每个学生的交卷时间、分数和状态。

## 通过学生的参与申请 {#approve}

学生报名后是「待审核」，你通过之后他才能交作业。

1. 打开「我发布的题目」页，在那张卡上点「处理报名」（没有这颗按钮时点「查看详情」，再点题目顶部的「参与者」页签）。
2. 切到「待审核」，点「通过」。系统按题目的「默认完成期限」给他算一个提交截止时间。
3. 不想收的点「驳回」，可以填原因；通过后还能点「设置截止时间」单独改他的截止时间。

![题目「参与者」页：按全部/待审核/已通过/已驳回筛选，每行可「通过」「驳回」](/images/task-participants.jpg)

完成后：学生那边题目顶部出现「前往提交」。

## 收作业、打分 {#grade}

「作业与验收」按学生列出交上来的作业，每人只算最新一版。

1. 打开「作业与验收」，默认在「待验收」；切到「全部」可以看所有已交的。
2. 每一行是一个学生的作业，带版本号（v1、v2……）和状态「等你看」。点右侧「看与打分」（已经看过的行显示「打开」）。
3. 在弹窗里看「最新提交内容」，可以展开「历史提交记录」。
4. 选「通过」或「驳回」，填「评分」和「评论」，点「提交」。

![「作业与验收」页：待验收列表按学生列出作业、提交时间和状态，右侧是「看与打分」](/images/course-assignments.jpg)

完成后：这份作业移出「待验收」。

## 学生与分组 {#people}

「学生与分组」页显示这门课有哪些学生、分了哪些组、谁还没有组。分组由学生自己完成，这一页只能查看。

## 课程参数 {#settings}

「设置」→「课程参数」决定这门课露出哪几块，以及芝士上课时知道什么。

- 课程模块：可以开或收起「教学单元」「作业与验收」「组队」「共性问题」。收起只是从左侧栏和课程首页隐藏，地址仍然打得开。小测、课件库、进度表、额度池还没有开关界面，页面上会单列一句说明。
- 本周教学：「课程级提示词模板」「当前周次」「本周内容」（逗号分隔）、「这周还不该用」（例如「递归」「指针」）、「课件」「知识条目」（逗号分隔的编号）。

![「课程参数」页：上面是课程模块开关，下面是「本周教学」的提示词模板、周次、内容、课件等字段](/images/course-settings.jpg)

完成后：学生从这门课的项目新开会话时，芝士就按这一周的进度回答；正在跑的会话要重新开始才换。
