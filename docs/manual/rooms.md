# 话题（房间） {#rooms}

房间是你和芝士谈一件事的地方，界面上它也叫「话题」。

## 一件事一个房间 {#one-thing}

**房间是你和芝士谈一件事的地方。** 界面上它也叫「话题」。

一个房间对应一段完整的上下文：这件事的来龙去脉、试过什么、结论是什么，都在这个房间里。所以**一件事一个房间**，不要把三件不相干的事塞进同一个——那会让芝士在三条线索之间反复切换，也让你事后翻不出任何一条。

房间是个群聊：人和 AI 队友都是名册上的成员。新房间自带项目的默认队友；要请别的队友进来，和请人一样，在房间顶部的名册里添加。谁被 @ 到，谁来回答。

## 实况文档 {#living-doc}

房间右侧那份文档是这个房间的**当前全貌**：目标、已有结论、下一步。

它和聊天记录是两种东西。聊天记录是过程——谁什么时候说了什么；实况文档是结果——现在到底是什么情况。它写给**没看过聊天记录的人**，所以你隔几天回来，先看它比往回翻快得多。

它也是可以改的。你直接在上面改一句话，等于给了芝士一条指令。
