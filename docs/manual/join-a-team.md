# 加入别人的团队 {#join-a-team}

这一页讲怎么加入同学建好的团队：拿到团队链接后申请，在「发现」里搜到后申请，或者在「待办」里接受邀请。比如组长已经建了「算法讨论组」，你要进去，才能看到团队下的项目、和大家一起让芝士干活。

你需要一个知是账号。进了团队，团队下的每个项目你都自动是成员，不用再一个个邀请。

## 用团队链接申请 {#by-link}

组长把团队链接发到群里时，用这一种。

1. 打开组长发来的链接。还没登录时，页面上有「登录并继续」，登录后回到这个团队的页面。
2. 页面写着团队名、所有者和「加入这个团队需要团队所有者或管理员批准」。「申请理由（选填）」可以写一句你是谁。
3. 点「申请加入」。

![团队页：写着团队名、所有者和成员数，下面是「申请理由（选填）」和「申请加入」](/images/team-apply.jpg)

页面变成「已提交申请，等待团队管理员审批」。组长批准后，刷新这一页，页面显示「你已经在这个团队里」和「进入团队」。

> [!NOTE]
> 团队关掉了「加入需要审批」时，这一页的按钮是「加入团队」，点了立即加入。<!-- 待确认：不需要审批的团队页未实测，按钮名取自现有功能页 -->

## 在「发现」里搜到后申请 {#by-search}

知道团队名字或团队 ID、手上没有链接时，用这一种。

首页侧栏「团队」→「新建或加入团队」，在「发现」页的「搜索团队 ID 或名称...」里输入团队名，点开搜到的团队，后面和用链接申请一样：填理由，点「申请加入」。<!-- 待确认：只核对了搜索框，搜索结果和点开后的页面未实测 -->

设为「隐身」的团队搜不到，只能用团队链接进。

## 接受邀请 {#by-invite}

组长也可以直接按你的用户名或邮箱邀请你，这时你什么都不用申请。

打开「待办」，「动态」里有一条「@〈组长名字〉 邀请你加入团队」，写着「以 MEMBER 身份邀请你加入团队 "〈团队名〉"」。点「接受」就进了团队；不想加入就点「拒绝」。

接受后，这个团队列在「团队」→「我的」里，也出现在首页侧栏「团队」下面。<!-- 待确认：接受后侧栏要换一页才出现，未确认是否会立即刷新 -->

## 组长那边怎么做 {#for-the-owner}

申请和邀请都要组长或团队管理员处理，这一节给他们看。

- 批准申请：「待办」里每条「@〈名字〉 请求加入团队」旁边点「批准」或「拒绝」；也可以在团队「成员」→「加入申请」里处理。
- 发邀请：团队「成员」→「邀请成员」，在「用户名或邮箱」里填对方完整的用户名或邮箱，下面出现这个人后选「角色」（「普通成员」或「管理员」），点「邀请」。
- 关掉审批或隐身：团队「成员」页「团队地址与加入」一栏里的「加入需要审批」和「谁能找到这个团队」。

完整说明见[团队](/teams#teams)。
