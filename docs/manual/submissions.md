# 提交 {#submit}

完成题目后，在题目的「提交」页按要求填写并上传成果。

## 提交作品 {#how}

1. 打开题目，点击顶部的「前往提交」，或切到「提交」页签。
2. 同时有个人身份和团队身份时，先在「请选择您要使用的提交身份」里选一个。
3. 按表单填写文本项、上传文件项。必填项未填会提示「此项为必填项」。
4. 点击「提交」。上传过程中会显示进度，完成后自动进入下一步。

单个文件不超过 50MB，支持常见文档和压缩包格式。

## 可以提交几次 {#times}

题目「概览」里的「提交次数」决定：

- 「可多次提交」：截止前可以多次更新作品，系统保存每一次的记录。
- 「仅可提交一次」：提交后不能修改，提交前请检查完整。

已达到上限时会提示「已达到提交次数上限」。

## 不能提交时 {#blocked}

| 提示 | 原因 |
|---|---|
| 当前不可提交，请联系题目发布者获取提交权限 | 发布者还没有开放提交 |
| 您没有可用于提交的身份 | 还没领取这道题，或领取申请还没被通过 |

## 查看提交记录 {#records}

「提交记录」页列出你的每一次提交和截止时间。

## 发布者查看提交 {#review}

发布者在题目的「参与者」页对每个参与者点「查看提交」，可以看到「最新提交内容」和「历史提交记录」。课程里的作业也可以在「作业与验收」页统一查看，见[课程与作业 · 收作业、打分](/courses#grade)。
