# 提交 {#submit}

做完题目后，在题目的「提交」页按要求填写、上传成果。

## 提交作品 {#how}

1. 打开题目：课程里从首页「本周任务」→「去交这一周的作业」；或者点题目顶部的「前往提交」。
2. 同时有个人身份和团队身份时，先在「请选择您要使用的提交身份：」里选一个。
3. 按「提交表单」填写：文件项点上传，文本项直接写。必填项没填会提示「此项为必填项」。
4. 点「提交」。上传时显示「正在上传提交内容」和进度。

完成后：跳到「提交记录」，最上面是这一版。

页面提示单个文件不超过 50MB。提交页顶部有「提交剩余时间」倒计时，截止时间是老师通过你的报名时，按题目的「默认完成期限」算出来的。

## 可以提交几次 {#times}

看题目「概览」里的「提交次数」：

| 提交次数 | 含义 |
|---|---|
| 可多次提交 | 截止前可以反复交，系统保存每一版 |
| 仅可提交一次 | 交过之后再交会被拒绝，页面提示「提交失败：……」。提交前请检查完整 |

## 不能提交时 {#blocked}

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 当前不可提交，请联系题目发布者获取提交权限。 | 发布者没有开放提交，比如题目已结束 | 联系发布者 |
| 无可用身份 | 还没领取这道题，或报名还在「待审核」 | 先领取题目，或等发布者在「参与者」里点「通过」 |
| 该题目不允许重复提交，您已经提交过作品。 | 这道题仅可提交一次，你已经交过 | 点「查看我的提交记录」回看 |

报名还没被通过时，题目顶部只有「退出题目」，没有「前往提交」。

## 查看提交记录 {#records}

「提交记录」页列出你的每一版提交：

- 最新一版在最上面，带版本号和提交时间；下面的「历史提交」可以展开看每一版。
- 每一版右侧是评审状态：「未评审」「通过」或「驳回」。被驳回时，如果题目允许多次提交，可以改完再交一版。
- 具体截止时间在题目「概览」的「时间信息」里。

![「提交记录」页：最新提交卡带版本号和提交时间，下面是可展开的历史提交](/images/task-submissions.jpg)

## 发布者查看提交 {#review}

1. 打开题目的「参与者」页，在某个参与者那一行点「查看提交」。
2. 弹窗里看「最新提交内容」，展开「历史提交记录」看每一版。
3. 要打分，选「通过」或「驳回」，填「评分」和「评论」，点「提交」。评审过之后表单变成「修改评审」，也可以「撤销评审」。

完成后：参与者的提交记录里显示评审结果。

课程里的作业也可以在「作业与验收」页统一查看、打分，见[课程与作业 · 收作业、打分](/courses#grade)。
