# 任务与看板 {#tasks}

项目看板用于查看芝士创建的任务及其当前状态。你可以从看板打开任务，查看进度和交付内容。

## 打开看板 {#open-board}

项目侧栏的「看板」汇集项目中的任务。话题右侧也有看板区域，可以查看当前话题的任务。

## 任务如何产生 {#task}

芝士可以根据话题中的要求创建任务。一条任务可以包含多个文件的改动；较复杂的工作也可能作为一条任务处理。需要分别交付时，可以在要求中说明为各项工作分别创建任务。

当前看板没有手动新建任务的入口。

## 看板显示什么 {#board}

看板按任务状态组织内容，主要列为「施工中」「交付中」「待处理」。页面另有「做出了什么」和可展开的「已完成」。任务的具体状态显示在卡片上。

![项目看板：「施工中」「交付中」「待处理」「做出了什么」四列，每张卡片写着任务名、所在话题和负责人](/images/board.jpg)

点击任务卡片，可以查看任务标题、状态、指派人、简报和相关 PR。任务面板还提供评论框。待验收的任务可以从这里进入[验收与采纳](/accept#accept)。

## 等待人工处理 {#needs-attention}

「待人工处理」表示当前需要人工介入，具体原因要结合话题中的提示判断。任务等待验收时，可以从看板的「待处理」打开任务，查看交付并决定采纳或退回。

额度耗尽也可能显示「待人工处理」，但此时不代表有一条待验收的任务。遇到额度提示时，参见[额度与算力](/quota#quota)。

## 任务状态如何变化 {#task-status}

任务状态随交付和验收操作变化。芝士递交成果后，任务可以进入「等待验收」；采纳完成后显示「已采纳」，退回后显示「交付被退回」。

看板目前没有拖拽任务或手动选择状态的入口。

一轮工作结束时，话题中的「运行状态」会概述本轮结果。当前界面没有名为「结论卡」的独立功能。
