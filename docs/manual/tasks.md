# 任务与看板 {#tasks}

这一页讲任务和项目看板。任务是频道里一段单独的对话，用来把一件事从讨论做到交付；项目看板按「下一步在谁手上」把任务分成几列。

## 打开看板 {#open-board}

点侧栏项目名下面的「看板」，进入项目首页，看板就在这里。频道右侧「总览」里也有一格「看板」，只列当前频道的任务。

## 任务如何产生 {#task}

任务只能由人创建，创建的人就是负责人。有四个入口：

- 在频道的 ⋯ 菜单里点「新建任务」。
- 在频道的「全部任务」页右上点「新建任务」。
- 在一条消息上点「转为任务」，芝士会带着这条消息和前面的讨论开始写任务文档。
- 芝士在频道里提议任务时，点提议卡上的「创建任务」；不需要就点「不用」。

芝士不会自己创建任务。看板上不能拖拽卡片或手动改状态。

## 任务名称 {#task-name}

任务的名字按创建方式来定：

- 创建时填了名字，就用你填的，平台不会再改它。
- 从芝士的提议创建的任务，沿用提议卡上的标题。
- 没填名字的任务先叫「新任务」。负责人发出第一条有内容的消息后，平台给它起名；只说「在吗」这类话时会等下一条。芝士第一次回复后，平台再结合对话核对一次。

平台起的名字和芝士提议的标题，只在任务方向明显变了时才会改，改名不在任务里发消息。

项目管理员可以在「项目设置 → 任务命名」中选择「手动命名」。之后没填名字的任务保持「新任务」，平台不再给任何任务起名或改名。

## 任务页 {#task-page}

点看板、侧栏或频道总览里的任务，打开任务页。左边是负责人、协作者和芝士的对话，右边是「总览」「现场」「改动」「预览」四个页签。「现场」是芝士在这个任务里执行的每一步，「预览」是它在这个任务里最后摆出来的那一样。

- 负责人和协作者能在任务对话里和芝士说话，其他人能看，有话去频道里说。
- 「总览」里是任务文档：要做什么、做到哪、定了什么。负责人、协作者和芝士都能改，其他人只能看。
- 讨论清楚后，负责人点「开始」。开始之前芝士只讨论、只写文档，不改项目；开始之后才动手改。项目没有默认审阅人时，点「开始」后会提示选一位「审阅人」。
- 开始后，总览顶部写着谁在什么时候开始的；点「与开始时相比」可以对照开始那一刻和现在的任务文档。
- 点页头的负责人可以看到这个任务由谁负责、谁在协作、哪位 AI 队友在做、在哪台工作电脑上做。任务第一次需要工作电脑时用频道当时那一台，之后频道再换也不跟着变；负责人可以在这里单独更换。只加进了这个项目、没有共享给团队的电脑算登记人自己的，只做登记人负责的任务。
- 负责人在任务信息的「协作者」一栏选人后点「添加协作者」，把频道里的人拉进任务，点「移除」请出去；协作者可以自己点「退出协作」。协作者和负责人一样能说话、改文档，开始、转交和关闭只有负责人能做。
- 负责人在任务页右上的 ⋯ 里可以「转交」给频道里的另一个人，或「关闭任务」；芝士也可以关闭任务。关闭时留了结论算「已完成」，没留算「已关闭」，频道里会出现一条说明。改动被采纳后任务自动结束。

侧栏在每个频道下面先列你负责的任务，再列你协作的，各自按最近有动静的排在前面，一共最多 5 个。你负责或协作的任务里有人说了你还没读的话，那一行加粗，后面是条数；芝士在任务里说的话不算。最后一行「全部任务」后面是这个频道里还在进行的任务数；点开后按「全部」「我负责的」「我协作的」「其他人的」筛选，点「已关闭」看已经结束的。

## 看板显示什么 {#board}

看板从左到右是五列，前四列是一类「下一步在谁手上」：

![项目看板：「未开始」「进行中」「检查中」「待处理」「做出了什么」五列，每张卡片写着任务名、所在频道和负责人](/images/board.jpg)

| 列 | 意思 | 卡片上可能出现的状态 |
|---|---|---|
| 未开始 | 还在讨论，负责人还没点「开始」 | 讨论中 |
| 进行中 | 已经开始，还没交付 | 运行中、已开始 |
| 检查中 | 已经交付，平台和芝士在处理，你不需要操作 | 检查运行中、等待检查、修复检查、解决冲突、平台更新分支 |
| 待处理 | 下一步在人手上 | 待审阅、检查未通过、已退回、待回答 |
| 做出了什么 | 项目里已经采纳的成果，以及发布的网站 | |

采纳、完成或关闭的任务收进底部可展开的「已完成」。「只看我的」在页面右上方，打开后只显示在等你的那几条。

每张卡片写着任务名、所在频道、负责人和状态；已开合并请求的还显示 PR 编号。点卡片打开[任务页](#task-page)。待审阅的任务从这里进入[验收与采纳](/accept#accept)。

## 需要你处理的事 {#needs-attention}

需要你处理的事集中在「待办」（手机在底栏，电脑在左侧栏），每条写着理由：待你审阅、待你回答，或你提的需求已有交付。

频道和任务里的平台提示如果标着「需要手动处理」，说明这一步平台不会自己继续，比如额度用完。它不代表有任务在等验收，处理方法见[额度](/quota#quota)和[常见问题与排障](/troubleshooting#troubleshooting)。

## 一轮结束时看什么 {#turn-summary}

一轮工作结束，对话里会出现本轮摘要：改动了几个文件、增减多少行，点「查看改动」直接打开右侧「改动」页签。右侧「总览」的「进度」列出这一轮做了哪几步。
