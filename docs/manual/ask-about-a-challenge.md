# 让芝士讲懂一道题 {#ask-about-a-challenge}

以「B 树的插入与删除」为例，在题目页向芝士提问。先明确这道题要交什么、要先会什么，卡住时只要下一步的提示。

:::before
需要先加入出题老师的空间，见[完成一道题目](/solve-a-challenge#join)。不用先领取题目。
:::

## 在题目页提问 {#open}

「问芝士」是题目页上的提问面板。芝士在面板里读过这道题的说明、要求和题目信息，但不读附件。

:::walk
1. 打开题目页，点标题右侧的「问芝士」。宽屏上面板在页面右侧打开，手机上从底部升起。
2. 点面板中列出的一个问题，例如「做这道题要先会什么？」；或者在「问一个关于这道题的问题…」中输入，按回车发送。
3. 芝士在面板中回答。在输入框中接着追问。

芝士的回答由 AI 根据题目生成，可能有误。与题目原文或出题老师的说明不一致时，以题目原文和出题老师的说明为准。附件里的数据和要求，需要复制到问题中。

### 提问的建议 {#ask}

一次问一件事。先让芝士用自己的话复述题目，确认理解一致，再问做法：

```prompt
用三四句话说明这道题要我提交什么，评分最看重哪一项。
```

不知道从哪里学起时，让芝士按先后顺序列出要先会的知识，并说明每一样用在哪一步：

```prompt
做这道题要先会哪些知识？按先后排，每一样说一句它用在题目的哪一步。
```

卡住时，要求芝士只给下一步的提示，并写明不要代码：

```prompt
这是我的思路：删除时先找到键所在的叶子，删掉后如果键数不够，就向左边的兄弟借一个。这样做有什么问题？只指出问题，不要给改好的代码。
```

## 换一段对话 {#conversations}

面板中的对话会保存，仅本人可见。下次打开面板时，接着这道题上一次的对话。

- 点面板顶部的对话标题，在「这道题的对话」中切换到另一段。
- 点面板标题右侧的笔形按钮，开始一段「新对话」。

## 额度 {#quota}

「问芝士」使用个人额度，不用团队额度。个人额度用完时不能再提问。面板中提示「本月额度已用完」和重置日期，并附「查看用量」，见[个人额度](/quota#personal)。
