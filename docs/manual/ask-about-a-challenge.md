# 让芝士讲懂一道题 {#ask-about-a-challenge}

以「B 树的插入与删除」为例，在题目页向芝士提问。先明确这道题要交什么、要先会什么，卡住时只要下一步的提示。

:::before
需要先加入出题老师的空间，见[完成一道题目](/solve-a-challenge#join)。不用先申请做这道题。
:::

## 在题目页提问 {#open}

「问芝士」是题目页上的提问面板。芝士在面板里读过这道题的说明、要求和题目信息；开始做（申请制的题是申请通过）之后，也能读取这道题的材料。

:::walk
1. 打开题目页，点页面右上角的芝士头像（「问芝士」）。宽屏上面板在页面右侧打开，手机上从底部升起。
2. 点面板中列出的一个问题，例如「做这道题要先会什么？」；或者在「问一个关于这道题的问题…」中输入，按回车发送。
3. 芝士在面板中回答。在输入框中接着追问。


芝士的回答由 AI 根据题目生成，可能有误。与题目原文或出题老师的说明不一致时，以题目原文和出题老师的说明为准。附件里的数据和要求，需要复制到问题中。

### 提问的建议 {#ask}

一次问一件事。先让芝士用自己的话复述题目，确认理解一致，再问做法：

```prompt
用三四句话说明这道题要我提交什么，评分最看重哪一项。
```

不知道从哪里学起时，让芝士按先后顺序列出要先会的知识，并说明每一样用在哪一步：

```prompt
做这道题要先会哪些知识？按先后排，每一样说一句它用在题目的哪一步。
```

卡住时，要求芝士只给下一步的提示，并写明不要代码：

```prompt
这是我的思路：删除时先找到键所在的叶子，删掉后如果键数不够，就向左边的兄弟借一个。这样做有什么问题？只指出问题，不要给改好的代码。
```

## 对话与新话题 {#conversations}

题目页上的面板就是全站的芝士面板。在左侧导航栏底部点芝士的头像，或按 `Ctrl/Cmd+J`，可以在其他页面打开同一个面板；手机上点顶栏右侧的芝士头像。芝士按你的权限读你能看到的项目、频道和文档，也能代你发消息、开任务交给项目的 AI 队友、处理审阅、答复邀请和入团申请、管理项目、团队和空间的成员，改项目和你管理的空间的设置，在空间发公告、审核待审核的题目。这类其他人看得到的操作，你没有明确提出过时，芝士不会直接执行：它先在回复里问你，或在面板里放一张卡片，你点「确认」后才执行。在「个人设置 → 芝士」里设置哪些操作需要确认、哪些无需确认，查看芝士最近代你执行的操作。

你也可以让芝士定时或在某件事发生时做一件事，芝士为此建一条自动化。回答里出现一张卡片，写着什么时候、做什么，和它现在的状态。

- 只做一次的，比如「等任务『接入搜索』提交审阅了，帮我先过一遍改动」「明早 8 点提醒我交报告」。卡片上写「等待中」，旁边有「取消」。事情发生时，对话里出现一行「任务「接入搜索」提交审阅了」，芝士在这段对话里接着做，做完通知你；14 天内没有发生就不再等，也会通知你。
- 反复做的，比如「每天早上八点把我的待办发给我」「以后我提的任务被退回，就把审阅意见整理成待办」。卡片上写「已开启」，旁边有「暂停」。每次运行开一段新对话，结果通知你。

能等的事有：到某个时间；有人 @ 你或回复你参与的支线，可以只看某几个人、某个频道或任务；有审阅等你处理；某个任务或你提的任务提交审阅、被采纳或退回；空间题目快到截止；收到邀请。

运行时需要你确认的操作会留在那段对话里，保留 3 天。自动化列在「个人设置 → 芝士 → 自动化」里：等待中的可以查看对话和取消，反复做的可以暂停、恢复和删除；只做一次的做完后不再列出。

芝士会记下以后用得上的事，比如你在带哪门课、给老师写东西要用书面语；你说「记住……」时它一定记。每记一次，面板里出现一张「记忆」卡片，可以撤销。记下的内容在「个人设置 → 芝士 → 记忆」里查看、修改和删除，也可以关闭记忆。记忆只给你自己的芝士用，频道里的 AI 队友读不到。

面板中的对话会保存，仅本人可见。在哪一页打开，都接着上一次说的内容；在哪一页提问，芝士就读取哪一页。

- 点面板顶部右侧的笔形按钮，开始「新话题」。之前的内容留在上方，芝士之后不再读取。
- 往上翻到顶，面板接着读出更早的消息和更早的话题，或点「更早的消息」「更早的话题」。

## 告诉芝士你指的是什么 {#point}

芝士默认读取你提问时所在的页面。输入框里和附件同一行有一个带眼睛图标的标签，写着这一页的名字；芝士读不到的页面，比如首页和个人设置，没有这个标签。

- 这一问和眼前的页面无关时，点这个标签上的 ×。名字划掉，这一问不带这一页；点 + 带回来，换到另一页也会自动带上。
- 在页面上选中一段字，旁边出现「问芝士」。点它，面板打开，这段字成为输入框里一个带引号图标的标签，随下一句交给芝士；点标签上的 × 去掉。项目文档里选中文字时出现的是项目 AI 队友的选区框，没有「问芝士」。
- 在输入框里打 `@`，或点输入框下方的 `@` 按钮，引用一个任务、频道、文档、资料库文件或题目。刚打 `@` 时列出最近去过的几样和「任务」「频道」「文档」「资料库文件」四类；接着打字，按名字或拼音首字母查找。挑中的一样在输入框里显示为一个标签，一句最多引用 5 样。
- 发出的问题下方各占一行，列出附上的选中内容和提问时所在的页面。

例如在助教项目的页面上，引用另一个项目的频道提问：

```prompt
@组会 这周组会谁讲什么？
```

## 交给芝士一件长的事 {#long-work}

芝士能接一件要做几十分钟到几个小时的事，比如把 40 份实验报告按评分标准各打一个分再汇总成表。

- 要做好几步的事，芝士先在回答上方列出步骤，做完一步勾一步。全部做完后，清单收成一行「N/N 项已完成」。
- 能各自做完的部分，芝士派分身同时做，比如每个分身给 10 份报告打分。每个分身是回答里的一行「派出分身」，后面写着「进行中」「已完成」「已停下」或「失败」；点这一行，看它做过的每一步。分身拿不准的地方会先问芝士，做完把结论交给芝士。分身只读资料、上网查和用芝士的电脑，以你的名义做的事都由芝士自己做。
- 芝士在做的时候，输入框里照样能打字。发出的话，芝士在下一步之前读到，比如「第 30 份以后的不用打了」。输入框为空时，发送按钮是停止按钮，点它停下这次回答和所有分身。
- 一次回答最长 4 小时。快到时芝士写下做到哪里、结果在哪、还剩什么；到时停下，面板显示「运行时间达到 4 小时上限，已停止」。
- 回答用了 2 分钟以上，结束时你没在看这段对话，你会收到一条通知「芝士已完成「话题名」」，点开就是这段对话。

## 额度 {#quota}

「问芝士」使用个人额度，不用团队额度。个人额度用完时不能再提问。面板中提示「本月额度已用完」和重置日期，并附「查看用量」，见[个人额度](/quota#personal)。
