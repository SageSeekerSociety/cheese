# 让芝士讲懂一道题 {#ask-about-a-challenge}

这一页带你在题目页用「问芝士」把一道题问明白：它要什么、要先会什么、从哪里下手，而不是直接要答案。比如老师在空间里发了一道「运输路线优化问题」，你读完题目还不知道该用什么方法。

开始前，你要能打开这道题：先加入老师的空间，见[空间与题目 · 加入空间](/challenges#join)。不用先领取题目。

## 打开问芝士 {#open}

在题目页标题下面点「问芝士」，宽屏上面板停在右边，手机上从底部升起。

![题目页右边的「问芝士」面板：顶上写着芝士读过题目的说明、要求和题目信息，不读附件；下面是三个现成的问题和输入框](/images/ask-panel.jpg)

面板里有三个现成的问题：「做这道题要先会什么？」「从哪里入手比较好？」「这道题难在哪里？」，点一个就是问它；也可以在「问一个关于这道题的问题...」里自己写。

## 把题问明白 {#ask}

一次问一件事，问完再顺着它的回答追问。

:::steps

### 先弄清题目要什么 {#what}

先让它用自己的话复述题目，确认你们理解的是同一件事。

```prompt
用三四句话说说这道题到底要我交什么，评分最看重哪一部分。
```

```prompt
题目里说的「车辆容量限制」具体是什么意思？举一个三个配送点的小例子。
```

### 问清要先会什么 {#prerequisites}

不知道从哪学起时，让它列出要先会的东西，并说清每一样用在题目的哪一步。

```prompt
做这道题要先会哪些知识？按先后排，每一样说一句它用在哪一步。
```

```prompt
我只学过贪心和最短路，没学过遗传算法。只用我会的，能做到什么程度？
```

### 要提示，不要答案 {#hints}

卡住时只要下一步的提示，自己做出来才算学会。

```prompt
我想自己做，只给我第一步的提示，不要写代码。
```

```prompt
这是我的思路：先按距离把配送点分组，再在每组里找最短路线。这样做有什么问题？只指出问题，不要给改好的方案。
```

```prompt
我算出来的路线总长比别人多 20%。可能是哪一步出了问题？给我两个检查的方向。
```

:::

> [!WARNING]
> 芝士只读过这道题的说明、要求和题目信息，读不到附件。回答由 AI 生成，可能有误，以题目原文和出题人的说明为准。附件里的数据和要求，自己贴进问题里。

## 换一段对话 {#conversations}

对话会保存，只有你自己看得到。下次打开面板时接着这道题上次的对话。

- 点面板顶上的标题，换到这道题的另一段对话接着聊。
- 点笔形按钮，开一段新对话。

## 用的是你的个人额度 {#quota}

每次提问扣你的个人额度，不扣团队的。额度用完后会提示「本月额度已用完」，旁边有「查看用量」，见[个人额度](/quota#personal)。

## 在项目里接着问 {#in-project}

领取题目、建了项目之后，在项目的频道里 `@芝士` 接着问。项目里的芝士能读项目里的文件，也按老师给 AI 队友写的指导回答。

```prompt
@芝士 这是我写的分组函数（见附件），帮我看看在配送点很少的时候会不会出错，只指出问题。
```

领取和建项目见[完成一道题目](/solve-a-challenge#solve-a-challenge)，老师给 AI 队友写的指导见[空间与题目 · 给 AI 队友的指导](/challenges#teaching)。
