# 题目 {#challenges}

题目是空间里一份可以申请做、提交和评审的作业，例如数据结构课空间里的「B 树的插入与删除」。空间是老师或组织发布题目的地方，管理空间和出题见[空间](/spaces#spaces)。

## 加入空间 {#join}

加入空间要用邀请码，由管理空间的老师提供。在首页左侧栏「空间」下点「用邀请码加入」，填入邀请码；加入后，这个空间列在首页左侧栏的「空间」下。完整步骤见[完成一道题目](/solve-a-challenge#join)。

## 题目列表 {#find}

空间左侧栏最上面是「公告」，下面是「全部题目」和空间的各个分类。题目列表顶部有三个范围：「全部」是已经上板、对成员可见的题目，「我参与的」是你申请过或做过的题目，「我发布的」是你发布的题目，包括还在审核中的。

「全部」先列出还能申请的题目；报名已截止、名额已满或已经结束的题目收在列表末尾一行「已截止或名额已满」，点开才列出。上次打开题目列表之后有新题目发布时，左侧栏「全部题目」旁边写着新题目数，打开列表后清零。这个数记在当前浏览器里，换一台设备从头算。

在任意一页按 `Ctrl/Cmd+K` 打开搜索，输入题目名称里的词，结果的「题目」一组列出你加入的各个空间里的题目，下面一行写着所在空间。

前两个范围可以按标签筛选、搜索和排序。标签贴在题目上，选几个标签时，列出带其中任意一个的题目。范围和分类都写在页面地址里，复制地址发给别人，打开的是同一个列表。

置顶且未到期的公告显示在题目列表顶部。

## 题目页 {#detail}

题目页最上面是题目名、状态（例如「可申请」「可开始」「已截止」）、发布者和简介，右上角是「问芝士」和开始做题的按钮：发布者选了直接开始的题是「开始做这道题」，申请制的题是「申请做这道题」。已经有这道题的项目时，按钮换成「继续做」，点它进入项目；可以提交时，旁边还有「提交作业」。

「说明」页签是题目详情和材料，材料在开始做这道题之后才能下载。开始做这道题时平台建一个项目（申请制的题在申请通过时建），项目的资料库有一个只读的「题目」文件夹，放着这道题的材料和一份`题目说明.md`，项目里的芝士也读得到，见[题目文件夹](/files#task-folder)。开始做之后多出「我的提交」页签，见[提交记录](/submissions#records)。

右侧一栏上面是「我的进度」，开始做或申请之后才出现；下面是「题目信息」，列出形式、截止、限时、提交次数、难度和参与人数。其中「截止」是整道题的截止日期；「限时」只有申请制的题才有，写作「14 天，从申请通过那天算起」；「参与人数」只算已经开始做的人。

## 问芝士 {#ask}

「问芝士」是题目页上的提问面板。芝士是平台的 AI 队友，在面板中读取这道题的说明、要求和题目信息；开始做之后（申请制的题要申请通过），也能读取这道题的材料。没有开始做也能提问；对话只有本人看得到，每次提问使用[个人额度](/quota#personal)。提问的做法见[让芝士讲懂一道题](/ask-about-a-challenge#ask-about-a-challenge)。

## 申请与批准 {#claim}

题目怎么开始由发布者选，分两种：

- 直接开始：点「开始做这道题」，在「参与确认」中填手机号或邮箱，团队题先选代表参与的团队。确认后，页面提示「已开始，项目已准备好」，平台创建一个与题目同名的项目并进入它。
- 申请制：点「申请做这道题」，同样填写「参与确认」。确认后，页面提示「申请已提交，等待出题人通过」，你留在题目页，按钮变为「已申请，等待通过」。发布者批准后，平台才创建与题目同名的项目。

申请制的题，批准之前没有「提交作业」，也没有项目。截止时间的算法看开始方式：

- 直接开始的题，所有人的截止时间都是题目的截止日期。发布者改了题目的截止日期，所有人跟着改，发布者单独调整过的人除外。
- 申请制的题，截止时间是批准时间加上「限时」的天数，所以每个人的截止时间不同。

截止时间按你所在的时区显示在「我的进度」的「我的提交截止：」和项目「项目目标」标题下方的「提交截止：」中；发布者还能单独调整。

批准时项目偶尔没能建成，这时按钮是「开始做这道题」，点它就建好项目并进入。

发布者拒绝时，按钮变为「申请未通过」。申请通过后要退出，在「我的进度」右上角的「⋯」中点「退出这道题」退出。

### 无法申请时 {#claim-blocked}

不满足条件时，题目页顶部出现「暂时无法参与」或「团队不满足参与条件」，写明是哪一条：

- 「这道题需要实名信息才能参与」：点「前往填写」补全实名信息。
- 「你需要创建或加入一个团队才能参与这道题」：团队题只能以团队身份申请，点「管理我的团队」，或见[团队](/teams#teams)。
- 「这道题要求团队至少 N 人」或「最多 N 人」：调整团队人数后再申请。
- 「团队里有人已经通过别的团队申请过这道题」：一个人对一道题只能申请一次，换一个没有成员申请过这道题的团队。

还没到报名时间、报名已截止或人数已满时，按钮换成不可点的「未开始」「已截止」或「人数已满」。名额只算已经开始做的人，还在等通过的申请不占名额。直接开始的题在点「开始做这道题」时看名额，名额已满时提示「这道题的 N 个名额已满」。

## 题目的项目 {#project}

开始做这道题时创建的项目是做这道题的地方，芝士、文件和讨论都在里面：直接开始的题在点「开始做这道题」时创建，申请制的题在发布者批准时创建。项目列在「我的进度」中，点项目名或题目页的「继续做」进入。项目的「项目目标」中有一节「赛题要求」列出题目描述，芝士在每段对话中读取它。

「我的进度」下方的「用这道题新建项目」另外创建一个项目，做同一道题时无需再点。新项目只能建在做这道题的那一方名下：个人做的建在你自己名下，团队做的建在那个团队下。

## 提交 {#submit}

开始做之后（申请制的题要等申请通过），点题目页的「提交作业」提交。提交表单、提交次数和评审结果见[提交](/submissions#submit)。
