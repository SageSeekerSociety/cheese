# 空间与题目 {#spaces}

空间是老师或组织发布题目的地方：里面有题目、公告，以及管理员用来管理它的一组页面。

参与者可以领取空间里的题目并提交，在从题目建出的项目里和芝士一起完成。

## 加入空间 {#join}

1. 点左侧导航最上面的「首页」，在侧栏「空间」下面点「用邀请码加入」。手机上在底栏「首页」里。
2. 填写「邀请码」，点「加入」。

完成后：直接进入这个空间的题目列表；以后它也列在首页侧栏的「空间」下面。

## 找到题目 {#find}

进入空间后，左侧栏最上面一行是空间名，点前面的「‹」回到首页。下面是：

| 左侧栏 | 用途 |
|---|---|
| 全部题目、各个分类 | 这个空间里已经上板的题目，可以按分类看，顶部可以「在当前空间中搜索」 |
| 我发布的题目 | 你发布的题目，以及各自的报名与提交情况 |
| 我参与的题目 | 你已经领取的题目 |
| 公告 | 管理员发布的通知，置顶的排在最前；过了到期日的收进「已到期」 |

置顶且没到期的公告也列在题目列表顶上，点一行打开公告页。管理员发布公告时，空间里的其他人会在首页「动态」里收到一条通知；之后修改公告不再通知。

点一道题目打开题目页：

- 左边是题目本身：简介、视频（只支持 Bilibili）、材料，以及「题目详情」正文；领取按钮也在这里。
- 右边「领取进度」写着领取人数、截止时间、形式（个人或团队）、难度、提交次数（「可多次提交」或「仅可提交一次」），以及领取后多少天内要交。
- 右边「项目」一栏是从这道题目建出来的项目。
- 你是这道题的发布者或空间管理员时，还能看到「领取者」名单、「领取走势」，以及「单题分析」和「参与者管理」两个入口。

## 领取题目 {#claim}

领取题目要填一次参与确认；确认后报名进入待审核。

题目页顶部提示条件不满足时，先按下面处理，再领取：

| 提示 | 怎么办 |
|---|---|
| 这道题需要实名信息才能参与 | 点「前往填写」补全实名信息 |
| 你需要创建或加入一个团队才能参与这道题 | 团队任务要以团队身份领取，先建团队或加入别人的团队，见[团队](/teams#teams) |
| 这道题要求团队至少 / 最多 N 人 | 调整团队人数 |
| 这道题的名额已满 | 这道题不能再领取了 |

1. 在题目页点「领取这道题」。
2. 在「参与确认」对话框里填手机号或邮箱（至少一项）和「申请理由」，点「确认参与」。团队题先选代表参与的队伍。

![「参与确认」对话框：联系方式至少填一项，下面是申请理由和「确认参与」按钮](/images/task-join-dialog.jpg)

完成后：报名进入「待审核」。发布者在「参与者管理」里点「通过」之后，题目页才会出现「提交作业」。领取后想放弃，在题目页点「退出这道题」。

## 从题目创建项目 {#project}

题目页右边的「项目」一栏列出从这道题目建出来的项目，点名字直接进。要新建时点「用这道题新建项目」；已经有了再点，会另建一个新项目，一般不需要。项目自带话题和芝士，怎么交代任务见[快速开始](/quickstart#talk)。

## 提交 {#submit}

点题目页的「提交作业」，按表单填写、上传作品，点「提交」。详见[提交](/submissions#submit)。

## 新建空间 {#create}

1. 打开「空间」页，点「新建空间」。
2. 填「空间名称」，选填「简介」和「头像」，点「提交审核」。
3. 弹出「这是你的邀请码」，点「进入空间」。

完成后：平台管理员审核通过后，才能发布题目、邀请成员。你是这个空间的所有者，左侧栏多出「管理」一段。

## 邀请码 {#invite-codes}

邀请码在左侧栏「管理」→「邀请码」里管理。

- 点「新建」时可以设定「可用人数」和「有效期至」（不填表示永不过期），还可以写一句说明。
- 已有的码可以「调整」人数和有效期，也可以「撤销」；撤销要点两下，撤销后这个码对所有人失效。
- 码是共享的，贴到公开场合等于谁拿到都能加入。

## 成员 {#members}

左侧栏「管理」→「成员」列出这个空间的所有者、管理员和成员，以及每个人是用哪个邀请码加入的。所有者可以把成员设为管理员、取消管理员，也可以把所有者转让给一位管理员；转让后自己成为管理员。

## 发布题目 {#publish}

空间里的人都可以发布题目，发布后要经所有者或管理员审核才对参与者可见。

1. 进入发布页：在「全部题目」页点「发布题目」，或直接打开 `/spaces/<空间号>/tasks/publish`。
2. 空间配过题目模板时，先到「选择题目模板」：选一个模板，或点「从空白题目开始」。
3. 页头右边选「手写一道」或「从 PDF 生成」。
4. 手写时按下表填表单，填完点右边的「提交审核」。

| 卡片 | 要填什么 |
|---|---|
| 基本信息 | 「题目名称」、「参与者类型」（个人/团队）、「题目难度」、「参与者人数限制」或「队伍数量限制」；团队题还要选「队伍成员锁定策略」并填「最小队伍人数」「最大队伍人数」 |
| 基本信息里的开关 | 「允许多次提交」：勾上学生才能在截止前反复交；「允许编辑提交」：勾上已交的那一版可以改 |
| 时间设置 | 「报名开始日期」（留空表示不限制）、「报名截止日期」、「默认完成期限」（领取后多少天，通过报名时按它算截止时间） |
| 实名信息要求 | 开启后参与者必须补全实名信息才能参与 |
| 权限设置 | 用域名组限制只有指定邮箱域名的用户能看到和参与 |
| 题目描述 | 题目正文，可以带视频链接 |

右边「提交前」列出表单还拦着你的地方，全部解决后「提交审核」才能点。

完成后：题目进入待审核，在「管理」→「审核题目」里等通过。

有 PDF 题目时，两种做法：

- 「手写一道」页顶部的「PDF 快速发布」：上传题目 PDF（不超过 15MB），点「解析预览」，确认识别出的草稿（一次最多 20 道），在下方表单统一填发布参数后批量发布。
- 「从 PDF 生成」：上传后逐条改标题和题干、勾掉不要的，确认后就地给出回执。

## 给 AI 队友的指导 {#teaching}

在左侧栏「管理」→「管理内容分类」里，每个分类的「⋮」菜单有「给 AI 队友的指导」：填角色设定、当前周次、目前的内容范围、暂时不该用到的写法，以及材料和知识条目编号。从这个分类的题建出的项目，AI 队友开新对话时会读到这些内容；单道题可以另行设置。

## 审核题目 {#audit}

发布的题目要先过审，参与者才看得到。

1. 打开「管理」→「审核题目」。
2. 点题目展开详细信息，选「通过」或「驳回」；驳回要填「驳回理由」。

![「审核题目」页：待审核的题目展开显示详细信息，底部是「通过」和「驳回」](/images/task-audit.jpg)

完成后：通过的题目出现在「全部题目」里。未通过时，题目页显示「审核未通过」和驳回理由。

## 管理参与者 {#participants}

题目的「参与者管理」页按「待审核」「已通过」「已驳回」筛选申请，每一条申请可以：

| 操作 | 说明 |
|---|---|
| 通过 | 报名生效，系统按「默认完成期限」给他设提交截止时间 |
| 驳回 | 可以填写原因（选填） |
| 设置截止时间 | 单独改这个参与者的提交截止时间 |
| 查看提交 | 看他的「最新提交内容」和「历史提交记录」，可以当场评审 |

![题目「参与者」页：筛选器加每行的「通过」「驳回」「设置截止时间」「查看提交」](/images/task-participants.jpg)
