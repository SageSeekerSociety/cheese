# 题目 {#challenges}

题目是空间里一份可以领取、提交和评审的作业，例如数据结构课空间里的「B 树的插入与删除」。空间是老师或组织发布题目的地方，管理空间和出题见[空间](/spaces#spaces)。

## 加入空间 {#join}

加入空间要用邀请码，由管理空间的老师提供。在首页左侧栏「空间」下点「用邀请码加入」，填入邀请码；加入后，这个空间列在首页左侧栏的「空间」下。完整步骤见[完成一道题目](/solve-a-challenge#join)。

## 题目列表 {#find}

空间左侧栏最上面是「公告」，下面是「全部题目」和空间的各个分类。题目列表顶部有三个范围：「全部」是已经上板、对成员可见的题目，「我参与的」是你领取过的题目，「我发布的」是你发布的题目，包括还在审核中的。

前两个范围可以按话题筛选、搜索和排序。话题是题目上的标签，选几个话题时，列出带其中任意一个的题目。范围和分类都写在页面地址里，复制地址发给别人，打开的是同一个列表。

置顶且未到期的公告显示在题目列表顶部。

## 题目页 {#detail}

题目页最上面是题目名、状态（例如「报名中」「已截止」）、发布者和简介，右上角是「领取这道题」或「提交作业」，旁边是「问芝士」。

「说明」页签是题目详情和材料，材料在领取之后才能下载。领取获批后多出「我的提交」页签，见[提交记录](/submissions#records)。

右侧一栏上面是「我的进度」，领取后才出现；下面是「题目信息」，列出形式、截止、提交期限、提交次数、难度和已领取人数。其中「截止」是整道题的报名截止，「提交期限」是领取获批后可用于提交的天数。

## 问芝士 {#ask}

「问芝士」是题目页上的提问面板。芝士是平台的 AI 队友，在面板中读取这道题的说明、要求和题目信息，不读附件。不领取也能提问；对话只有本人看得到，每次提问使用[个人额度](/quota#personal)。提问的做法见[让芝士讲懂一道题](/ask-about-a-challenge#ask-about-a-challenge)。

## 领取与批准 {#claim}

领取是报名做一道题。领取时在「参与确认」中填手机号或邮箱，团队题先选代表参与的团队。确认后，平台创建一个与题目同名的项目，领取申请交给发布者批准。

发布者拒绝时，按钮变为「领取申请被拒绝」。已获批准的领取，在「我的进度」右上角的「⋯」中点「退出这道题」退出。

### 无法领取时 {#claim-blocked}

不满足条件时，题目页顶部出现「暂时无法参与」或「团队不满足参与条件」，写明是哪一条：

- 「这道题需要实名信息才能参与」：点「前往填写」补全实名信息。
- 「你需要创建或加入一个团队才能参与这道题」：团队题只能以团队身份领取，点「管理我的团队」，或见[团队](/teams#teams)。
- 「这道题要求团队至少 N 人」或「最多 N 人」：调整团队人数后再领取。
- 「团队里有人已经通过别的团队领了这道题」：一个人对一道题只能领取一次，换一个没有成员领取过的团队。

还没到报名时间、报名已截止或领取人数已满时，按钮换成不可点的「未开始」「已截止」或「人数已满」。

## 题目的项目 {#project}

领取时创建的项目是做这道题的地方，芝士、文件和讨论都在里面。领取获批后，项目列在「我的进度」中，点项目名进入。项目的「项目总览」中有一节「赛题要求」列出题目描述，芝士在每段对话中读取它。

「我的进度」下方的「用这道题新建项目」另外创建一个项目，做同一道题时无需再点。

## 提交 {#submit}

领取获批后，点题目页的「提交作业」提交。提交表单、提交次数和评审结果见[提交](/submissions#submit)。
