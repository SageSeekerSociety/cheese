# 题目 {#challenges}

题目是空间里一份可以申请做、提交和评审的作业，例如数据结构课空间里的「B 树的插入与删除」。空间是老师或组织发布题目的地方，管理空间和出题见[空间](/spaces#spaces)。

## 加入空间 {#join}

加入空间要用邀请码，由管理空间的老师提供。在首页左侧栏「空间」下点「用邀请码加入」，填入邀请码；加入后，这个空间列在首页左侧栏的「空间」下。完整步骤见[完成一道题目](/solve-a-challenge#join)。

## 题目列表 {#find}

空间左侧栏最上面是「公告」，下面是「全部题目」和空间的各个分类。题目列表顶部有三个范围：「全部」是已经上板、对成员可见的题目，「我参与的」是你申请过或做过的题目（就是「全部」最上面那一组），「我发布的」是你发布的题目，包括还在审核中的。

「全部」最上面一组是「我参与的」，列出你申请过或开始做的题目，不收起。每一行写着你这一份的状态（「已申请」「在做」「已提交」「已通过」「已过期」）和你自己的「提交截止」。其余题目排在下面：先列还能申请或开始的；申请已截止、名额已满或已经结束的收在末尾一行「已截止或名额已满」，点开才列出。这些题目的日期，申请制的题写「申请截止」，直接开始的题写「截止」。上次打开题目列表之后有新题目发布时，左侧栏「全部题目」旁边写着新题目数，打开列表后清零。这个数记在当前浏览器里，换一台设备从头算。

在任意一页按 `Ctrl/Cmd+K` 打开搜索，输入题目名称里的词，结果的「题目」一组列出你加入的各个空间里的题目，下面一行写着所在空间。

前两个范围可以按标签筛选、搜索和排序。标签贴在题目上，选几个标签时，列出带其中任意一个的题目。范围和分类都写在页面地址里，复制地址发给别人，打开的是同一个列表。

置顶且未到期的公告显示在题目列表顶部。

## 题目页 {#detail}

题目页最上面是题目名、题目的状态（例如「可申请」「申请已截止」「可开始」「已截止」）、发布者和简介。这个状态说的是题目本身，每个人看到的都一样；你自己这一份走到哪了，写在右侧「我的进度」里。页面右上角的芝士头像打开「问芝士」。

简介下方只有一个主按钮：发布者选了直接开始的题是「开始做这道题」，申请制的题是「申请做这道题」，已经有这道题的项目时是「继续做」，点它进入项目。可以提交时，旁边还有一个文字按钮「提交作业」。

「说明」页签是题目详情和材料，材料在开始做这道题之后才能下载。点「开始做这道题」时平台用这道题建一个项目（申请制的题要先申请通过），项目的资料库有一个只读的「题目」文件夹，放着这道题的材料和一份`题目说明.md`，项目里的芝士也读得到，见[题目文件夹](/files#task-folder)。开始做之后多出「我的提交」页签，见[提交记录](/submissions#records)。

右侧一栏上面是「我的进度」，开始做或申请之后才出现，写着你这一份的状态（「已申请，等待通过」「可以开始」「进行中」、最新一版的批改结果或「已过期」）和「提交截止」，后面是还剩几天；下面是「题目信息」，列出形式、截止、限时、提交次数、难度和参与人数。其中「截止」在直接开始的题上是整道题的截止日期，可以不设，这时写「不限」；在申请制的题上叫「申请截止」，过了不再收新的申请；「限时」只有申请制的题才有，写作「14 天，从申请通过那天算起」；「参与人数」只算已经开始做的人。

## 问芝士 {#ask}

「问芝士」是题目页上的提问面板。芝士是平台的 AI 队友，在面板中读取这道题的说明、要求和题目信息；开始做之后（申请制的题要申请通过），也能读取这道题的材料。没有开始做也能提问；对话只有本人看得到，每次提问使用[个人额度](/quota#personal)。提问的做法见[让芝士讲懂一道题](/ask-about-a-challenge#ask-about-a-challenge)。

## 申请与批准 {#claim}

题目怎么开始由发布者选，分两种：

- 直接开始：点「开始做这道题」，在「开始做这道题」确认框中填手机号或邮箱，团队题先选代表参与的团队，再点「开始做」。页面提示「已开始，项目已准备好」，平台创建一个与题目同名的项目并进入它。
- 申请制：点「申请做这道题」，在「申请做这道题」确认框中填手机号或邮箱，可以写申请理由，点「提交申请」。页面提示「申请已提交，等待出题人通过」，按钮变为不可点的「等待通过」。发布者批准后，按钮变为「开始做这道题」；点它，在确认框中点「开始做」，平台才创建与题目同名的项目并进入它。

题目设了导师时，确认框在点「开始做」之前写明导师会加入你的项目。申请制的题在申请时不问，在申请通过后开始做时问。

申请制的题，批准之前没有「提交作业」，也没有项目。截止时间的算法看开始方式：

- 直接开始的题，所有人的截止时间都是题目的截止日期；题目没设截止日期，就没有截止时间。发布者改了题目的截止日期，所有人跟着改，发布者单独调整过的人除外。
- 申请制的题，截止时间是批准时间加上「限时」的天数，所以每个人的截止时间不同。

截止时间按你所在的时区显示在「我的进度」的「提交截止」和项目「项目目标」标题下方的「提交截止：」中；发布者还能单独调整。

建项目偶尔失败，这时按钮仍是「开始做这道题」，再点一次就建好项目并进入。

题目的截止日期只挡还没有这道题的人：直接开始的题过了截止，不能再开始；申请制的题过了申请截止，不能再申请。已经开始做或申请通过的人只看自己的截止时间：没到就能点「开始做这道题」、接着做和提交，包括申请截止之后才通过的人。自己的截止时间过了，还没开始的人不能再开始，按钮是不可点的「已过期」；已经开始做的人照常点「继续做」进入项目，但不能再提交。

发布者拒绝时，按钮变为不可点的「未通过」。申请通过后要退出，在「我的进度」右上角的「⋯」中点「退出这道题」退出。

### 无法申请时 {#claim-blocked}

不满足条件时，题目页顶部出现「暂时无法参与」或「团队不满足参与条件」，写明是哪一条：

- 「这道题需要实名信息才能参与」：点「前往填写」补全实名信息。
- 「你需要创建或加入一个团队才能参与这道题」：团队题只能以团队身份申请，点「管理我的团队」，或见[团队](/teams#teams)。
- 「这道题要求团队至少 N 人」或「最多 N 人」：调整团队人数后再申请。
- 「团队里有人已经通过别的团队申请过这道题」：一个人对一道题只能申请一次，换一个没有成员申请过这道题的团队。

还没开放、截止或名额已满时，按钮换成不可点的「未开始」、「申请已截止」（申请制）或「已截止」（直接开始）、「名额已满」。名额只算已经开始做的人（申请制的题算申请通过的人），还在等通过的申请不占名额。名额满了，直接开始的题不能再开始，申请制的题也不再收新的申请，提示「这道题的 N 个名额已满」；已经在等的申请不受影响。

## 题目的项目 {#project}

点「开始做这道题」创建的项目是做这道题的地方，芝士、文件和讨论都在里面。用一道题建项目只有这一条路，每一份申请只建一个项目：个人做的建在你自己名下，团队做的建在那个团队下。项目列在「我的进度」中，点项目名或题目页的「继续做」进入。项目的「项目目标」中有一节「赛题要求」列出题目描述，芝士在每段对话中读取它。

## 提交 {#submit}

开始做之后（申请制的题要等申请通过），点题目页的「提交作业」提交。提交表单、提交次数和评审结果见[提交](/submissions#submit)。
