# 空间与题目 {#spaces}

空间是老师或组织发布题目的地方：里面有题目、成员，以及管理它的一组页面。新建的空间默认是课程：题目按周排进教学单元，学生从「本周任务」进来交作业，见[课程与作业](/courses#courses)。

你可以领取空间里的题目并提交，从题目建的项目里和芝士一起完成。

## 加入空间 {#join}

加入空间要用创建者给的邀请码或课程链接。

1. 打开「我的工作」，在顶部「我加入的空间」一排点「用邀请码加入」。
2. 填写「邀请码」，点「加入」。

完成后：直接进入这个空间（是课程就落在课程首页）；以后它也出现在「我加入的空间」一排里。

收到课程链接（形如 `/spaces/join/<码>`）时直接点开：先登录，然后自动加入并进入课程，见[课程与作业 · 加入课程](/courses#join)。

## 找到题目 {#find}

题目在哪一屏，看这个空间是课程还是题目板。

| 空间类型 | 找题的入口 |
|---|---|
| 课程（新建的空间默认是课程） | 学生：课程首页「本周任务」→「去交这一周的作业」；教师：「我发布的题目」页、「教学单元」里那一周 |
| 题目板 | 左侧栏「全部题目」，可以按分类筛选，顶部可以「在当前空间中搜索」；「我参与的题目」只列你已经领取的题目 |

打开一道题目，顶部页签有「概览」和「启星研导」；你是这道题的发布者或空间管理员时，还多一个「参与者」；领取并获通过后，才出现「提交记录」和「提交」。

「概览」里写着：

- 「题目详情」和「题目视频」（有的话，只支持 Bilibili）
- 「题目信息」：「提交类型」（个人任务或团队任务）、「难度等级」、「提交次数」（「可多次提交」或「仅可提交一次」）、「参与者人数限制」或「队伍数量限制」
- 「时间信息」：「报名截止时间」和「默认提交期限」（领取后多少天内要交）
- 「项目」：从这道题目建出来的项目

![题目「概览」页：题目详情、题目信息、时间信息和项目四块](/images/task-overview.jpg)

## 领取题目 {#claim}

1. 在题目顶部点「领取题目」。
2. 在「参与确认」对话框里填手机号或邮箱（至少一项）和「申请理由」，点「确认参与」。团队题先选代表参与的队伍。
3. 确认后，系统给你建好一个项目，并把你带进去。

![「参与确认」对话框：联系方式至少填一项，下面是申请理由和「确认参与」按钮](/images/task-join-dialog.jpg)

完成后：项目建好了，报名进入「待审核」。发布者在「参与者」里点「通过」之后，题目顶部才会出现「前往提交」。领取后想放弃，在题目顶部点「退出题目」。

领取前有条件时，「概览」顶部会说明原因：

| 提示 | 怎么办 |
|---|---|
| 此题目需要提供实名信息才能参与 | 点「前往填写」补全实名信息 |
| 您需要创建或加入一个团队才能参与此题目 | 团队任务要以团队身份领取，先建团队或加入别人的团队，见[团队](/teams#teams) |
| 此题目要求团队最少 / 最多 N 人 | 调整团队人数 |
| 该题目参与名额已满，请关注其他题目。 | 这道题不能再领取了 |

## 从题目创建项目 {#project}

领取题目时，系统已经建好一个项目，要交的作品就在里面做。

「概览」的「项目」一栏列出从这道题目建出来的项目，点名字直接进。这一栏没有项目时，可以点「从这道题目创建项目」；已经有了再点，会另建一个新项目，一般不需要。项目自带话题和芝士，怎么交代任务见[快速开始](/quickstart#talk)。

## 提交 {#submit}

点题目顶部的「前往提交」，按表单填写、上传作品，点「提交」。详见[提交](/submissions#submit)。

## 发布题目 {#publish}

空间管理员可以发布题目，发布后要过审才对参与者可见。

1. 进入发布页：题目板在「全部题目」页点「发布题目」；课程在「作业与验收」页点「去发布作业」，或直接打开 `/spaces/<空间号>/tasks/publish`。
2. 空间配过题目模板时，先到「选择题目模板」：选一个模板，或点「从空白题目开始」。
3. 按下表填各卡片，点「提交」。

| 卡片 | 要填什么 |
|---|---|
| 基本信息 | 「题目名称」、「参与者类型」（个人/团队）、「题目难度」、「参与者人数限制」或「队伍数量限制」；团队题还要选「队伍成员锁定策略」并填「最小队伍人数」「最大队伍人数」 |
| 基本信息里的开关 | 「允许多次提交」：勾上学生才能在截止前反复交；「允许编辑提交」：勾上已交的那一版可以改 |
| 时间设置 | 「报名开始日期」（留空表示不限制）、「报名截止日期」、「默认完成期限」（领取后多少天，通过报名时按它算截止时间） |
| 实名信息要求 | 开启后参与者必须补全实名信息才能参与 |
| 权限设置 | 用域名组限制只有指定邮箱域名的用户能看到和参与 |
| 题目描述 | 题目正文，可以带视频链接 |

![「发布题目」页：顶部是 PDF 快速发布，下面依次是基本信息、时间设置、实名信息要求、权限设置和题目描述](/images/task-publish.jpg)

完成后：题目进入待审核，在「设置」→「审核题目」里等通过。

有 PDF 题目时，用发布页顶部的「PDF 快速发布」：上传题目 PDF（不超过 15MB），点「解析预览」，在「解析预览结果」里确认识别出的草稿（一次最多 20 道），再在下方表单统一填发布参数，点「提交」批量发布。

## 审核题目 {#audit}

1. 打开「设置」→「审核题目」。
2. 点题目展开详细信息，选「通过」或「驳回」；驳回要填「驳回理由」。

![「审核题目」页：待审核的题目展开显示详细信息，底部是「通过」和「驳回」](/images/task-audit.jpg)

完成后：通过的题目出现在「全部题目」或这一周的作业里。未通过时，题目「概览」顶部显示「您的题目未通过审核」和驳回理由。

## 管理参与者 {#participants}

题目的「参与者」页按「待审核」「已通过」「已驳回」筛选申请，每一条申请可以：

| 操作 | 说明 |
|---|---|
| 通过 | 报名生效，系统按「默认完成期限」给他设提交截止时间 |
| 驳回 | 可以填写原因（选填） |
| 设置截止时间 | 单独改这个参与者的提交截止时间 |
| 查看提交 | 看他的「最新提交内容」和「历史提交记录」，可以当场评审 |

![题目「参与者」页：筛选器加每行的「通过」「驳回」「设置截止时间」「查看提交」](/images/task-participants.jpg)

## 新建空间 {#create}

1. 打开「空间」页，点「新建空间」。
2. 填「空间名称」，选填「简介」和「头像」，点「提交审核」。
3. 弹出「这是你的邀请码」，点「进入课程」。

![「新建空间」对话框：顶部是「默认课程模板」标签，填名称后点「提交审核」](/images/space-create.jpg)

完成后：你是这门课的教师和创建者。平台管理员审核通过后，才能发布题目、邀请成员。开课的完整流程见[老师 / 助教：开一门课](/teacher-tutorial#tut-teacher)。

## 邀请码与课程链接 {#invite-codes}

邀请码在左侧栏「设置」→「邀请码」里管理。

- 「生成新码」时可以设定「可用次数」和「有效期至」（留空表示永久有效）。
- 课程顶部还有一张「课程链接」卡片，点「复制链接」发到群里：学生点开后自动加入课程、建好自己的项目。
- 码是共享的，别贴到公开场合。

![「邀请码」页：顶部「课程链接」卡片带「复制链接」，下面是邀请码列表和「生成新码」](/images/invite-codes.jpg)
