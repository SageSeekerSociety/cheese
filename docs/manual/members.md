# 成员 {#members}

项目成员来自它所属的团队：团队里的人自动能进团队的所有项目，不需要一个个邀请。团队以外的人可以被邀请成为某个项目的外部成员。

## 外部成员 {#external}

外部成员是团队以外、只参与某一个项目的人，名字旁边带「外部」标记。

项目所有者和团队的所有者、管理员可以邀请外部成员：在项目的成员页点「邀请外部成员」，输入对方完整的用户名或邮箱，找到后发出邀请。对方接受后才会加入。外部成员只能看到这一个项目，看不到团队的其他项目；能进项目里的公开房间，私密房间要被房间管理员单独加进去。

外部成员可以自己退出项目，也可以被管理者移出。团队成员不能单独退出某个项目，要离开就退出团队。

## 点名某个人 {#mention}

在消息里 `@` 一个人的名字，他会收到提醒；只写名字不加 `@` 只是普通文字，不会通知到人。

同一条规则也适用于[芝士](/agents#summon)：`@` 它才会动。
