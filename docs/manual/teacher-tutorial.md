# 老师 / 助教：开一门课，收作业、打分 {#tut-teacher}

这篇教程带你从零开一门课：建课程、发布并审核第一道作业题、排第一周、邀请学生、通过报名，最后收作业打分。

开始前你需要：一个知是账号。新建的课程要经过平台管理员审核。

## 1. 建课程 {#create}

在「空间」页新建空间，新建出来的空间默认就是课程。

1. 打开「空间」页，点「新建空间」。
2. 填「空间名称」（例如「程序设计练习」），「简介」和「头像」选填。
3. 点「提交审核」。对话框里标着「默认课程模板」：建出来就是课程，你是这门课的教师和创建者。
4. 提交后弹出「这是你的邀请码」，点「进入课程」。
5. 申请状态在「我的空间申请」里显示「待审核」。通过前课程页是空的，会提示「这门课还在平台审核中。」

![「新建空间」对话框：顶部是「默认课程模板」标签，填写空间名称后点「提交审核」](/images/space-create.jpg)

完成后：课程出现在「空间」页里；平台审核通过后，题目、成员这些页面才有内容。

## 2. 课程的左栏与各屏 {#nav}

课程有自己的几屏，教师和学生看到的条目不同。

| 身份 | 左侧栏条目 |
|---|---|
| 教师（本空间管理员） | 课程总览、教学单元、作业与验收、学生与分组、共性问题 |
| 学生 | 我的课程、本周任务、我的小组 |

「设置」那一块只对教师出现：课程参数、审核题目、管理题目模板、数据分析、管理分类话题、管理内容分类、域名组管理、邀请码。

课程里没有「全部题目」这个入口。发布作业题走「作业与验收」里的「去发布作业」；看自己发过的题和报名情况，打开「我发布的题目」页（`/spaces/<空间号>/tasks/my/publishing`）。

![课程总览：在册成员、作业单元、报名学生、待我验收四个数字，下面是各屏的入口按钮](/images/course-teacher-home.jpg)

完成后：知道自己要用的几屏在哪一格。

## 3. 发布第一道作业题 {#task}

从「作业与验收」进入发布页，填完基本信息、时间和描述后提交。

1. 打开「作业与验收」。这门课还没有作业时，页面上有「去发布作业」，点它进入发布页；也可以直接打开 `/spaces/<空间号>/tasks/publish`。
2. 空间配过题目模板时会先到「选择题目模板」页：选一个模板，或点「从空白题目开始」。
3. 在「基本信息」里填「题目名称」，选「参与者类型」（个人或团队）、「题目难度」，按需要填「参与者人数限制」或「队伍数量限制」。
4. 团队题目还要选「队伍成员锁定策略」（「允许自由调整」或「审核通过后锁定」），并填「最小队伍人数」「最大队伍人数」。
5. 勾「允许多次提交」，学生才能反复交；「允许编辑提交」决定已交的那一版能不能改。
6. 在「时间设置」里填「报名开始日期」「报名截止日期」和领取后的「默认完成期限」（天数）。
7. 按需在「实名信息要求」里开启「要求参与者提供实名信息」；在「权限设置」里用域名组限制只有指定邮箱域名的用户能看到。
8. 填「题目描述」，点「提交」。

![「发布题目」页：基本信息里填题目名称、参与者类型、题目难度，下面依次是时间设置和题目描述](/images/task-publish.jpg)

完成后：页面跳到「我发布的题目」。这道题还没过审，同时出现在「设置」→「审核题目」里。

## 4. 审核题目 {#audit}

题目要过审，学生才看得到、才能领取。自己发的题，也要自己审一下。

1. 打开「设置」→「审核题目」。
2. 找到刚发布的题，点「通过」。
3. 这道题不打算发了，就点「驳回」并填写「驳回理由」。

![「审核题目」页：待审核的题目展开后显示详细信息，底部是「通过」和「驳回」](/images/task-audit.jpg)

完成后：题目从待审核列表消失，可以挂到教学单元上了。

## 5. 排第一周 {#unit}

教学单元按周次排课，每一周写着讲什么、要不要交东西。

1. 打开「教学单元」，点「加一个单元」。
2. 「第几周」填 1，「这一周讲什么」写一句话（学生会看到它），「说明」选填。
3. 在「这一周要交的东西」里选上一步那道题；纯讲义的周选「不布置作业」。
4. 需要时设「截止时间」。
5. 勾「建好就发布」，点「保存」。

没发布的单元学生看不到，可以先把整学期排好，每周发布一个。

![「教学单元」页：按周次列出单元，每行有「已发布」标签和「加小测」「撤回发布」等按钮](/images/course-units.jpg)

完成后：单元显示「已发布」，学生的「本周任务」里出现「第 1 周」和「去交这一周的作业」。

## 6. 邀请学生 {#invite}

把课程链接发到班级群，学生点开就进课。

1. 打开「设置」→「邀请码」。
2. 顶部的「课程链接」卡片里点「复制链接」，把它发到班级群。学生点开后先登录，然后自动加入课程、建好自己的项目，直接进课程首页。
3. 要单独发码时点「生成新码」，设「可用次数」和「有效期至」（留空表示永久有效）。

![「邀请码」页：顶部是「课程链接」卡片和「复制链接」按钮，下面是邀请码列表和「生成新码」](/images/invite-codes.jpg)

完成后：学生陆续出现在「学生与分组」页。

## 7. 通过学生的参与申请 {#participants}

学生报名后是「待审核」，你通过之后他才能交作业。

1. 打开「我发布的题目」页，在要处理的那张卡上点「处理报名」（没有这颗按钮时点「查看详情」，再点题目顶部的「参与者」页签）。
2. 切到「待审核」，看每个申请的申请理由和联系方式（题目要求实名时还会显示实名信息）。
3. 点「通过」。通过时系统按题目的「默认完成期限」给他算一个提交截止时间。
4. 不想收的点「驳回」，可以填驳回原因。
5. 通过之后，还可以在这一行点「设置截止时间」单独改他的截止时间，点「查看提交」看他的作品。

学生从课程链接进来时，系统已经把他登记在这门课最早那道已过审的题上；他在别的题上点「领取题目」也会新建一条待审核记录。两种都在这里通过。

![题目「参与者」页：按全部/待审核/已通过/已驳回筛选，每行可「通过」「驳回」](/images/task-participants.jpg)

完成后：学生那边题目顶部出现「前往提交」。

## 8. 收作业、打分 {#grade}

「作业与验收」按学生列出交上来的作业，每人只算最新一版。

1. 学生提交后，打开「作业与验收」，默认在「待验收」。
2. 每一行是一个学生的作业，带版本号（v1、v2……）和状态「等你看」。点右侧「看与打分」（已经看过的行显示「打开」）。
3. 在弹窗里看「最新提交内容」，可以展开「历史提交记录」。
4. 选「通过」或「驳回」，填「评分」和「评论」，点「提交」。

![「作业与验收」页：待验收列表按学生列出作业、提交时间和状态，右侧是「看与打分」](/images/course-assignments.jpg)

完成后：这份作业移出「待验收」。

## 9. 课程参数与模块开关 {#settings}

「设置」→「课程参数」决定这门课露出哪几块，以及芝士上课时知道什么。

- 课程模块：可以开或收起「教学单元」「作业与验收」「组队」「共性问题」。收起只是从左侧栏和课程首页隐藏，地址仍然打得开。
- 本周教学：填「课程级提示词模板」「当前周次」「本周内容」「这周还不该用」「课件」「知识条目」。学生从这门课的项目新开会话时，芝士会读到这些设置。
- 保存后，学生新开的会话立刻生效；正在跑的会话要重新开始才换。

![「课程参数」页：上面是课程模块开关，下面是「本周教学」的周次、内容、课件等字段](/images/course-settings.jpg)

完成后：这门课只露出你要的几块，芝士知道现在教到哪一周。
