# 老师 / 助教：开一门课，收作业、打分 {#tut-teacher}

这篇教程带你从零开一门课：建课程、排第一周的单元、把学生拉进来、收作业并打分。

开始前你需要：一个知是账号。新建的课程要经过平台管理员审核。

## 1. 建课程 {#create}

在空间列表页点击「新建空间」，填写「空间名称」（例如「程序设计练习」），点击「提交审核」。新建的空间默认就是课程，你是这门课的教师。

完成后：页面显示「提交后等待平台管理员审核」。审核通过后才能继续后面几步。

## 2. 布置第一道作业题 {#task}

在课程的「全部题目」页点击「发布题目」，选择「从空白题目开始」，填写题目名称、参与者类型、截止时间和题目描述，点击「提交」。详见[发布题目](/challenges#publish)。

完成后：题目出现在「全部题目」里。

## 3. 排第一周 {#unit}

打开「教学单元」，点「加一个单元」：第几周填 1，写一句这一周讲什么，在「这一周要交的东西」里选上一步的题目，勾选「建好就发布」，保存。

完成后：单元显示「已发布」，学生的「本周任务」里会出现它。

## 4. 邀请学生 {#invite}

打开「设置」→「邀请码」，复制「课程链接」发到班级群。学生点开后会登录、自动加入课程、建好自己的项目。

完成后：「学生与分组」页里陆续出现学生。

## 5. 收作业、打分 {#grade}

学生提交后，打开「作业与验收」，在「待验收」里点「打开」查看每一份作业并打分。

完成后：这份作业移出「待验收」。

## 接下来 {#next}

课开起来之后，还可以做这两件事。

- 给这一周加一个小测，见[出小测](/courses#make-quiz)
- 在「课程参数」里写好本周教学内容，学生用芝士时它会按这一周的进度回答，见[课程参数](/courses#settings)
