# 常见问题与排障 {#troubleshooting}

出问题时，话题里通常会有一行平台提示，写明发生了什么。按提示的原文在这一页找到对应的一节：先看它是什么意思，再照着处理。

## 提示机器未配置或未连接 {#device-offline}

现象：话题里出现「这条会话的机器尚未配置或未连接」。

意思：这个话题选的运行设备现在不在线，或者还没有选。

处理：

1. 点头像打开「我的设备」，看设备是否「在线」。不在线的话，在那台机器上打开桌面端，或重新运行 `cheesehost link connect`。
2. 用的是团队设备时，到团队「算力」页确认它已经加进团队。
3. 设备在线但还是这个提示：这个话题可能已经固定在另一台机器上了（运行过的话题不能换机器）。新开一个话题，在第一次运行前选好运行环境。

设备接入和运行环境见[设备与运行环境](/devices#devices)。

## 提示本轮未完成或意外中断 {#turn-failed}

现象：话题里出现以「本轮未完成：」开头的一行，或者「本轮意外中断，平台不会自动重试」这类提示。

意思：这一轮没有跑完。展开行尾的详细说明，能看到原因和服务返回的原话。

| 提示 | 怎么办 |
|---|---|
| 无法连接 AI 服务，这一步未完成 / AI 服务暂时过载，这一步未完成 | 稍等片刻，点提示上的「重试」 |
| 本轮意外中断，平台不会自动重试 | 点「重试」；没有重试按钮时，重新 `@` 芝士说「继续」 |
| 上一轮 N 分钟没有任何输出，已强制停止 | 芝士卡住了。重新 `@` 它，说明从哪里接着做 |
| N 次工具调用没有返回结果，平台不会自动重试 | 同上；重复出现时，检查设备是否掉线 |
| 本轮未完成：AI 中继余额已用完 | 重试没有作用，联系平台管理员，见[额度与算力](/quota#other-limits) |
| 一个工具无法使用 | 配置问题，重试没有作用；把提示原文反馈给平台团队 |

有「重试」按钮的提示，点它会从中断处接着做，不会重复执行已经完成的部分。

## 让芝士停下 {#stop}

现象：芝士一直显示「正在处理…」或「正在交给芝士…」，想让它停下。

意思：在对话里说「停」会排在这次运行后面；运行卡住时，这句话送不进去，只会提示「消息未能送达进行中的会话，已加入队列」。

处理：点「正在处理…」旁边的「停止」。这次运行立即结束，房间里出现一行「某某停止了这次运行」，已经交给它的消息不会再重发。之后需要它接着做，重新 `@` 它说明要做什么。

## 提示消息未送达 {#undelivered}

现象：对话里出现「消息未送达」，或某条消息旁标着「未送达」。

意思：这条消息没有送进芝士的会话，它没看到。

处理：点提示上的「重试」，或重新发送。平台部署时偶尔会自动重发，并写明「上一轮被平台部署中断，消息未送达，已重新发送」，这时不用再发。

## 提示正在排队 {#queued}

现象：「项目同时运行的轮次已满，本轮正在排队，前面还有 N 个」。

意思：这个项目同时在跑的话题太多，这一轮在排队。前面的结束后会自动开始，不用重发。

## 提示额度已用完 {#quota-exhausted}

现象：「可用的 tokens 额度已用完，这轮没有执行」。

处理：联系团队管理员或额度发放方补充额度，补上后重新 `@` 芝士。界面上只能查看额度，不能自己加。详见[额度与算力](/quota#quota-exhausted)。

## 云机器已达上限 {#cloud-limit}

现象：申请云机器时提示「团队云虚拟机已使用 N / N 台，请先释放不再使用的机器」。

处理：到团队「算力」页释放不再用的云机器。停止或休眠不会腾出名额，只有释放才归还。

## 采纳按钮是灰的 / 检查没通过 {#accept-blocked}

现象：验收卡上写着「平台检查未通过」或「平台检查未能执行」，「采纳」点不了。

处理：

- 鼠标停在「采纳」上，提示会写明「现在采纳不会合并」的原因。
- 检查没通过时，卡上写着「检查未通过，未提交审阅」，芝士会自己修复后重新提交，等它就好。
- 确认可以放行时，项目设置里「人工放行的人」可以点「仍要采纳」并写明理由。

见[验收与采纳](/accept#is-merge)。

## 文件无法上传 {#upload-failed}

现象：「〈文件名〉 超过 10MB，无法上传」，或「每条消息最多添加 9 个附件」。

处理：压缩或拆分文件后再传；附件多时分几条消息发。上传入口见[文件与成果](/files#upload-file)。

## 无法提交作业 {#submission-unavailable}

现象：题目的「提交」页显示「当前不可提交，请联系题目发布者获取提交权限。」，或者题目顶部没有「前往提交」。

意思：你的参与申请还没被通过，或者这道题已经过了提交期限。

处理：请发布题目的老师在题目的「参与者」里通过你的申请。详见[提交](/submissions#blocked)。

## 找不到芝士的结果 {#result-not-found}

结果在发起任务的那个话题里：

- 改过文件：点本轮摘要的「查看改动」，或打开右侧「改动」。
- 在等验收：对话末尾的验收卡，或项目看板的「待处理」列。
- 已经采纳：项目首页的「做出了什么」和「资料库」。

更多说明见[文件与成果](/files#find-result)。
