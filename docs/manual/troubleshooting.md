# 常见问题与排障 {#troubleshooting}

出问题时，频道里通常有一行平台提示，写明发生了什么。按提示原文在这一页找到对应的一节：先看它是什么意思，再照着处理。

## 提示机器未配置或未连接 {#device-offline}

现象：频道里出现「这条会话的机器尚未配置或未连接」。

意思：这个频道选的运行设备现在不在线，或者还没有选。

处理：

1. 点头像打开「设置 → 设备」，看设备是否「在线」。不在线的话，在那台机器上打开桌面端，或重新运行 `cheesehost link connect`。
2. 用的是团队设备时，到团队「工作电脑」页确认它已经加进团队。
3. 设备在线但还是这个提示：这个频道可能用的是另一台机器。打开成员名册，在底部「本频道运行在」那一行点「改」，换一台在线的。

设备接入和工作电脑见[设备与工作电脑](/devices#devices)。

## 提示本轮未完成或意外中断 {#turn-failed}

现象：频道里出现以「本轮未完成：」开头的一行，或者「本轮意外中断，平台不会自动重试」这类提示。

意思：这一轮没有跑完。展开行尾的详细说明，能看到原因和服务返回的原话。

处理，按提示原文对照：

| 提示 | 怎么办 |
|---|---|
| 无法连接 AI 服务，这一步未完成 / AI 服务暂时过载，这一步未完成 | 稍等片刻，点提示上的「重试」 |
| 本轮意外中断，平台不会自动重试 | 点「重试」；没有重试按钮时，重新 `@` 芝士说「继续」 |
| 上一轮 N 分钟没有任何输出，已强制停止 | 芝士卡住了。重新 `@` 它，说明从哪里接着做 |
| N 次工具调用没有返回结果，平台不会自动重试 | 同上；重复出现时，检查设备是否掉线 |
| 本轮未完成：AI 中继余额已用完 | 重试没有作用，联系平台管理员，见[额度](/quota#other-limits) |
| 一个工具无法使用 | 配置问题，重试没有作用；把提示原文反馈给平台团队 |

有「重试」按钮的提示，点它会从中断处接着做，不会重复执行已经完成的部分。

## 提示消息未送达 {#undelivered}

现象：对话里出现「消息未送达」，或某条消息旁标着「未送达」。

意思：这条消息没有送进芝士的会话，它没看到。

处理：点提示上的「重试」，或重新发送。平台部署时偶尔会自动重发，并写明「上一轮被平台部署中断，消息未送达，已重新发送」，这时不用再发。

## 提示正在排队 {#queued}

现象：「项目同时运行的轮次已满，本轮正在排队，前面还有 N 个」。

意思：这个项目同时在跑的频道太多，这一轮在排队。

处理：不用重发，前面的结束后会自动开始。

## 提示额度已用完 {#quota-exhausted}

现象：「本月额度已用完，11月1日重置。这一轮没有执行。」，或「5 小时内的用量已达上限，……恢复。这一轮没有执行。」

意思：项目所属团队本月的额度用完了，或者方案的用量上限暂时满了。

处理：等到提示里写的时间，或联系团队管理员或额度发放方补充额度，补上后重新 `@` 芝士。界面上只能查看额度，不能自己加。详见[额度](/quota#quota-exhausted)。

## 云端资源紧张 {#cloud-busy}

现象：芝士要动手时提示「云端资源紧张，暂时无法准备沙箱，请稍后再试」。

意思：平台的云端到了容量上限，这一刻没有空位给新的沙箱。这不是团队或项目的名额，没有什么需要你释放。

处理：稍后再让芝士继续。对话和平台工具不受影响。

## 采纳按钮是灰的 / 检查没通过 {#accept-blocked}

现象：「采纳」点不了（灰的）。鼠标停在上面，提示会写明「现在采纳不会合并：〈原因〉」，比如「必须通过的检查未通过：lint」。更早的卡上还可能写着「平台检查未通过」或「平台检查未能执行」。

意思：平台检查没过，这一版现在采纳不会合并。

处理：

- 卡上标着「芝士正在处理」时，这一版还得它改，等它重新提交后再看。
- 确认可以放行、且任务已经创建 PR（项目连了 GitHub 仓库）时，项目设置里「人工放行的人」可以点「仍要采纳」并写明理由。

见[验收与采纳](/accept#is-merge)。

## 文件无法上传 {#upload-failed}

现象：「〈文件名〉 超过 10MB，无法上传」，或「每条消息最多添加 9 个附件」。

处理：压缩或拆分文件后再传；附件多时分几条消息发。上传入口见[文件与成果](/files#upload-file)。

## 无法提交作业 {#submission-unavailable}

现象：题目的「提交」页显示「当前不可提交，请联系题目发布者获取提交权限。」，或者题目顶部没有「前往提交」。

意思：你的参与申请还没被通过，或者这道题已经过了提交期限。

处理：让发布题目的老师在题目的「参与者」里通过你的申请。详见[提交](/submissions#blocked)。

## 找不到芝士的结果 {#result-not-found}

结果在发起任务的那个频道里：

- 改过文件：点本轮摘要的「查看改动」，或打开右侧「改动」。
- 在等验收：对话末尾的验收卡，或项目看板的「待处理」列。
- 已经采纳：项目首页的「做出了什么」和「资料库」。

更多说明见[文件与成果](/files#find-result)。
