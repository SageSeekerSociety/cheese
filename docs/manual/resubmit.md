# 改完再交一版 {#resubmit}

这一页带你看老师对你上一版的评审，照着评语让芝士帮你改，再交一个新版本。比如你交的 B 树作业被驳回，评语是「删除操作在节点合并时会丢键，报告缺复杂度分析」。

只有题目「提交次数」写着「可多次提交」时才能再交；「仅可提交一次」的题交过就不能再交。

:::steps

### 看评审结果 {#read-review}

老师的评审写在你那一版提交下面。

题目页 →「我的提交」。最上面是最新的一版，右上角是评审状态：「未评审」「通过」或「驳回」；驳回时下面写着「已驳回」和「评语」。

![「我的提交」页：最新一版标着「未评审」和「等待评审中」，下面「历史提交」里是标着「驳回」的第 1 版；右上角是「提交新版本」](/images/submission-reviewed.jpg)

右侧「我的进度」也写着这一版的结果，比如「第 1 版未通过」。

### 照着评语改 {#fix}

回到题目的项目，把评语交给芝士，让它先说怎么改。

```prompt
@芝士 老师驳回了第 1 版，评语是：删除操作在节点合并时会丢键，报告缺复杂度分析。先找出删除里丢键的原因，说说打算怎么改，先别动代码。
```

```prompt
@芝士 补一组测试：连续删除直到只剩根节点，每删一次都检查剩下的键都还在。
```

```prompt
@芝士 实验报告里补一节复杂度分析，插入、删除、查找各一行，用表格。
```

要芝士改文件时，把这件事建成任务，讨论清楚后点「开始」，见[任务](/tasks#task)。<!-- 待确认：本地没有模型，芝士按评语修改的实际回复未实测 -->

### 交新版本 {#submit-again}

改好后，在题目页再交一次，旧的那一版会留在「历史提交」里。

1. 点题目页右上角的「提交新版本」。
2. 按「提交表单」重新上传文件、填写文本。
3. 点「提交」。

页面回到「我的提交」：最上面是新的一版，写着「等待评审中」；上一版收进「历史提交」，点它展开看当时交的内容和评审。

:::

> [!WARNING]
> 新版本要在「提交剩余时间」结束前交。提交页顶部有倒计时，截止时间按老师批准报名时的「提交期限」算。
