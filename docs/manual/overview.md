# 知是是什么 {#overview}

知是（Cheese）是一个和 AI 队友一起做事的地方：你在话题里把一件事交代清楚，AI 队友「芝士」去做，你随时插话补充，最后看它交回来的东西，满意就采纳。学生用它做作业，老师用它开课收作业，团队用它推进项目和写代码，办公室用它整理材料。

这一页只讲「有哪些东西、怎么连在一起」。想马上动手，直接看[快速开始](/quickstart#quickstart)。

## 一张图看懂 {#map}

```text
团队 ─┐                          空间（课程） ─ 题目 ─ 领取
      │                                                │
      └──► 项目 ◄──────────────────────────────────────┘
            │   成员 · AI 队友 · 资料库 · 看板 · 设置
            │
            ├── 话题：和芝士讨论、交代一件事的地方
            │     │
            │     └── 芝士干活（在一台机器上：你的电脑、服务器或云机器）
            │           │
            │           ├── 任务：拆出来并行推进的一条条活
            │           │     │
            │           │     └── 验收卡 ──► 采纳：改动进入项目
            │           │                └► 退回：写明原因，芝士再改
            │           │
            │           └── 成果：文件、网页、改动（可发布成网站）
            │
            └── 额度：芝士调用模型花掉的 tokens，由团队或机构发放
```

| 项目 | 装一件长期要做的事：话题、成员、AI 队友、文件、看板都在里面 | [项目](/projects#projects) |

## 一件事是怎么做完的 {#flow}

1. **交代**：在话题里写清要什么、给谁、做到什么程度，`@` 芝士或按 `Ctrl/Cmd+Enter` 交给它。见[与芝士协作](/working-with-cheese#working-with-cheese)。
2. **执行**：芝士先复述它的理解，再在运行环境里读写文件、跑命令，必要时拆成几条任务并行推进。右侧「现场」能看到它在做什么。
3. **插话**：做的过程中随时补一句，执行中的消息会并进正在进行的这一轮。
4. **交付**：芝士做完会递一张验收卡，写着改了什么、推荐谁审。
5. **验收**：点「审阅」看改动，满意就「采纳」，不满意就「退回」并写明原因。
