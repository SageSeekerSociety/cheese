# 知是是什么 {#overview}

知是（Cheese）是一个和 AI 队友一起做事的地方：在频道里说清要什么，AI 队友「芝士」去做。做完后检查它的结果，满意就采纳。学生用它做作业，老师用它收作业，团队用它写代码、推进项目。

## 各部分怎么连起来 {#map}

团队、空间、项目、频道、任务、成果、额度之间的从属关系：

```text
团队 ─┐                          空间 ─ 题目 ─ 领取
      │                                                │
      └──► 项目 ◄──────────────────────────────────────┘
            │   成员 · AI 队友 · 资料库 · 看板 · 设置
            │
            ├── 频道：人说话的地方，默认有一个「综合」
            │     │
            │     └── 芝士干活（在它的工作电脑上：云端，或你的电脑、服务器）
            │           │
            │           ├── 任务：频道里单独推进的一件事
            │           │     │
            │           │     └── 验收卡 ──► 采纳：改动进入项目
            │           │                └► 退回：写明原因，芝士再改
            │           │
            │           └── 成果：文件、网页、改动（可发布成网站）
            │
            └── 额度：芝士调用模型花掉的 tokens，由团队或机构发放
```

## 核心概念 {#concepts}

图里出现的每个词，一句话解释和完整说明在这里：

| 概念 | 一句话 | 详细说明 |
|---|---|---|
| 团队 | 一群一起用知是的人；项目建在团队下，团队成员自动进项目 | [团队](/teams#teams) |
| 项目 | 装一件长期要做的事：频道、成员、AI 队友、文件、看板都在里面 | [项目](/projects#projects) |
| 频道 | 项目里人说话的地方，按人群或领域划分，数量少；一件要做成的事放进频道下的任务 | [频道](/rooms#rooms) |
| 芝士（AI 队友） | 替你干活的 AI；每个项目至少一位，名字在建项目时取 | [AI 队友](/agents#agents) |
| 任务 | 频道里一段单独的对话，有一位负责人，可以拉协作者，有负责人和自己的文档，把一件事从讨论做到交付；在看板上按「下一步在谁手上」排列 | [任务与看板](/tasks#tasks) |
| 验收与采纳 | 芝士交活时递一张验收卡；你审阅后采纳，改动才算进了项目 | [验收与采纳](/accept#accept) |
| 文件与成果 | 你交给芝士的材料，和它做出来的东西 | [文件与成果](/files#files) |
| 工作电脑 | AI 队友干活的那台机器：云端，或你的电脑、服务器 | [设备与工作电脑](/devices#devices) |
| 额度 | 芝士调用模型的花费，按所用模型的单价折算 | [额度](/quota#quota) |
| 空间 | 老师或组织发布题目的地方 | [空间与题目](/challenges#spaces) |

## 一件事是怎么做完的 {#flow}

一件事从交代到采纳要走五步，每一步在哪个页面操作写在后面：

1. 交代。在频道里写清要什么、给谁、做到什么程度，然后交给芝士。交给它的方式见[与芝士协作](/working-with-cheese#start-work)。
2. 执行。芝士先复述它的理解，再在工作电脑上读写文件、跑命令，必要时提议拆成几条任务，由你决定是否创建（见[任务与看板](/tasks#task)）。右侧「现场」能看到它在做什么。
3. 补充要求。做的过程中随时补一句，执行中的消息并进正在进行的这一轮。
4. 交付。芝士递一张验收卡，写着改了什么、推荐谁审。
5. 验收。点「审阅」看改动，满意就「采纳」，不满意就「退回」并写明原因。

## 接下来读什么 {#next}

第一次用知是，先读[快速开始](/quickstart#quickstart)，再按要做的事挑一篇：

| 要做的事 | 读这一篇 |
|---|---|
| 和同学一起做一个项目 | [和同学一起做一个项目](/team-project#team-project) |
| 在空间里领一道题目，做完后提交 | [完成一道题目](/solve-a-challenge#solve-a-challenge) |
| 发布题目、批准领取、评审提交 | [发布一道题目并收作业](/publish-a-challenge#publish-a-challenge) |
| 检查并采纳芝士做的改动 | [验收芝士交回来的改动](/review-changes#review-changes) |
| 把芝士做的网页发布出去 | [把网页发布成网站](/publish-a-site#publish-a-site) |
| 让芝士用你自己的电脑或服务器干活（可选） | [让芝士用你自己的电脑干活](/use-your-computer#use-your-computer) |

遇到问题，按提示原文在[常见问题与排障](/troubleshooting#troubleshooting)里找对应的一节。发现哪里写错或不好用，去[反馈中心](/feedback#feedback)提。
