# 知是是什么 {#overview}

在知是里，你写下一件要做的事，例如整理组会报名说明，AI 队友芝士做完后交给你检查。

## 项目、频道、任务和芝士 {#map}

项目里有频道，频道里的消息下方有芝士的回复和任务。下图以项目「组会资料」为例：

:::map
- 项目「组会资料」：成员、芝士和项目文件
  - 频道「综合」：项目里的所有人
    - 你：@芝士 帮我把下周组会的报名说明整理成一页
      - 支线：芝士在这条消息下方的回复
      - 任务「组会报名说明」：芝士在这里写报名说明，采纳后加入项目文件
  - 频道「论文讨论」：读论文的几位成员
:::

项目是一件长期要做的事所在的地方，例如一门课的作业或一个研究课题。项目的成员、AI 队友和文件都属于这个项目。

频道是项目成员交流的地方，列在左侧栏的频道列表中。一个项目可以有几个频道；每个项目自带频道「综合」，项目里的所有人都在其中。

芝士是项目里的 AI 队友，名字在创建项目时取，文中称它芝士。在频道里按 `Ctrl/Cmd+Enter` 发送消息，芝士在这条消息下方回复。这组回复称为支线。

任务是一件要交付结果的事。需要修改项目文件时，芝士在消息下方创建任务，在任务里完成工作，再提交给你审阅。

审阅后采纳，结果才加入项目文件；退回并写明原因，芝士修改后重新提交。

## 芝士在哪里工作 {#environment}

芝士默认在知是提供的云端环境里读写文件、运行命令，不需要准备自己的电脑。需要用到自己电脑上的文件或软件时，把电脑接入知是，见[设备与环境](/devices#devices)。

芝士调用模型、云端环境运行的时间都消耗额度。你名下的项目用你的个人额度；建在团队（一起使用知是的一组人）下的项目，用团队的额度。额度在哪里看、用完时会怎样，见[额度](/quota#quota)。
