# 设备与运行环境 {#devices}

芝士执行任务需要可用的运行环境。你可以在「我的设备」中接入自有设备，并在项目或话题中查看运行环境设置。

## 接入自有设备 {#add-device}

接入自有设备需要完成安装、登录和网页批准，再运行连接命令。

1. 点击右上角头像，打开「我的设备」，选择「添加设备」。复制弹窗提供的安装命令，在要接入的机器上运行。
2. 按提示运行 `cheesehost auth login`，在浏览器中打开「批准这台设备」页面。
3. 检查设备名称，点击「批准并绑定到我」。页面会提示设备已绑定到你。
4. 按批准页面的提示，回到命令行运行 `cheese link connect`，让设备保持在线并接受任务。

连接成功后，在「我的设备」页面确认设备显示「在线」。设备名旁有重命名入口，设备行提供「解绑」。

## 将设备用于小队 {#team-device}

已接入的自有设备可以添加到小队，供小队项目使用。在小队侧栏打开「算力」，找到「自有设备」区域，通过「添加自有设备」选择已接入的设备。

添加后，设备会出现在小队的设备列表中。该区域同时显示设备数量和在线数量。

## 选择话题运行环境 {#topic-environment}

话题首次运行前，可以在「选择运行环境」中改选可用资源。入口位于话题顶部的「更多 → 运行环境」。

「自动选择」的界面说明为「首次运行时选择在线设备」。「项目默认」标记表示当前选择与项目默认设置一致。

项目默认设置位于「项目设置 → 运行环境 → 默认与常用算力」。新话题会使用该默认设置。
