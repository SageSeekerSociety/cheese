# 让芝士用你自己的电脑干活 {#use-your-computer}

这一页带你把自己的电脑或服务器接入知是，让芝士在上面干活。比如你的课程项目要在实验室服务器的 GPU 上训练模型，数据也只放在那台服务器上。

不接自己的电脑，芝士就在平台的云端环境里干活。下面几种情况才需要接：

- 要用的文件很大，或者只能留在本地；
- 要用你电脑或服务器上装好的软件、显卡；
- 要连学校内网里的服务。

在自己的电脑上跑不收算力费；芝士调用模型照常消耗额度，见[额度](/quota#compute)。

要跑 Docker、要装系统软件时，用平台的整台云虚拟机也行，不用接自己的电脑，见[设备与环境](/devices#devices)。

## 接入电脑 {#connect}

接入的入口在「设置 → 设备 → 添加设备」：点左下角的头像，选「设置」，再点「设备」。

![「添加设备」对话框：上面是 Mac 或 Windows 电脑的桌面端下载，下面是服务器用的安装命令和说明](/images/devices-add.jpg)

按你的机器选一种接法，两种只做一种。

- Mac 或 Windows 电脑：在「添加设备」里下载桌面端（「Mac（Apple 芯片）」「Mac（Intel 芯片）」或「Windows」），装好后打开，登录知是，再打开「设置 → 设备 → 添加设备」，点「接入这台电脑」。
- 服务器或不想装桌面端的电脑：在「服务器或未安装桌面端的电脑」下复制对应系统的安装命令，在那台机器上运行；装好后运行 `cheesehost link connect`。命令会打印一个链接，在你已登录知是的电脑浏览器里打开它，页面写着「批准这台设备」，核对设备名后点「批准并绑定到我」。

接好后回到「设置 → 设备」，这台机器出现在「已接入的设备」里，显示「在线」。<!-- 待确认：本地没有真的接入机器，「在线」字样取自现有说明 -->

> [!TIP]
> 桌面端第一次打开被系统拦下时：Mac 到「系统设置 → 隐私与安全性」点「仍要打开」；Windows 点「更多信息 → 仍要运行」。

## 让芝士用这台电脑 {#use}

接入后芝士仍在云端环境里干活，要在设置里给它指定这台电脑。

:::steps

### 先把电脑给团队 {#to-team}

团队的项目要用这台电脑，先把它加进团队。

团队侧栏「设备」→「添加自有设备」，选这台电脑。你名下的项目，在侧栏你的名字下面的「设备」里加。

### 选在哪里用它 {#pick}

在哪一层选，就在哪一层生效；任务的选择最优先，其次是频道，最后是项目默认。

| 范围 | 在哪改 | 影响什么 |
|---|---|---|
| 一个任务 | 任务页右上角的负责人 →「环境」那一行的「改」→「这个任务的环境」 | 只有这个任务；任务默认写着「跟随频道」 |
| 一个频道 | 频道的成员名册底部「本频道运行在：……」旁的「改」→「这个频道的环境」 | 这个频道和跟随它的任务；「综合」没有成员名册，用项目默认那一台 |
| 整个项目 | 项目菜单 →「项目设置」→「环境」→「新 AI 队友默认使用」 | 只影响以后才开始运行的 AI 队友，已经在跑的不跟着换 |

一个任务第一次用到环境时，用的是频道当时那一个；之后频道再换，这个任务不跟着换。

换电脑前，平台先把芝士已做的改动存回项目（推送到它的分支）；存不成功就不换，并显示原因。

### 告诉芝士这台机器上有什么 {#tell}

换好之后，在任务里告诉芝士要用这台机器做什么。芝士会先检查环境，再开始做。<!-- 待确认：芝士在自有设备上开工时的实际回复没有核对，本地没有可运行的模型 -->

```prompt
这个任务现在跑在实验室服务器上，有一张 GPU。先确认 GPU 能用、显存有多少，再跑 train.py。
```

```prompt
这台电脑能连学校内网。从内网的课程数据库导出本学期的作业提交记录，存成 CSV。
```

```prompt
数据我放进了你在这台机器上的工作目录，在 data/ 下。只读不改，统计每个文件的行数，结果写到 results/summary.csv。
```

:::

## 芝士在你电脑上的访问范围 {#access}

默认是「隔离环境」：芝士只能看到自己的工作目录，看不到你电脑上的其他文件、装在你用户目录里的软件，也看不到别的频道。

芝士的工作目录在这台机器的 `~/.cheese/home/<项目编号>/<频道编号>/room`。两个编号就是浏览器地址里 `/projects/` 和 `/topics/` 后面那两串。<!-- 待确认：任务用的工作目录用的是不是任务自己的编号 -->

要让芝士用到你自己的数据和工具，选一种：

- 把数据复制进芝士的工作目录，或者把软件装到系统里；
- 电脑主人打开「整台电脑」：在频道的成员名册底部点「改」，在「这个频道在……上能看到什么」里选「整台电脑」。选了之后芝士能看到、改动这台电脑上的一切，频道顶部一直写着「能访问整台电脑」。

> [!WARNING]
> 「整台电脑」只有电脑主人本人能开，频道里的其他人和芝士都只能把它改回「隔离环境」。只在你信任这个频道里每个人时打开。每种系统的要求见[自有设备上 AI 队友能看到什么](/devices#machine-access)。
