# 让芝士在你自己的电脑上工作 {#use-your-computer}

以一份只存在你电脑上的实验数据为例，介绍如何把自己的 Mac 或 Windows 电脑接入知是，让芝士在这台电脑上统计这份数据。

:::before
你需要是项目所属团队的管理员，并有一台能安装软件的 Mac 或 Windows 电脑。服务器和 Linux 机器用命令行接入，见[接入服务器或其他机器](/devices#add-device)。
:::

## 接入这台电脑 {#connect}

接入的电脑称为自有设备。芝士平时在平台的云端环境中工作，接入后才能在你的电脑上工作。

:::walk
1. 打开项目所属团队的「设备」页，点「接入设备」。
2. 点「下载桌面端」，安装对应系统的版本。
3. 登录桌面端。这台电脑没接入过时，桌面端自己接入你的个人团队，显示每一步和下载进度。
4. 接入完成后，点「完成」。团队的「设备」页列出这台电脑，显示「在线」。

第一次接入接到你的个人团队。要用在别的项目上，去那个团队的「设备」页点「接入这台电脑」，选那个团队、点「接入」，这会为它建一次独立的接入。接入进行中关掉对话框就停下来，不会在后台接着接；之后从团队的「设备」页再点一次「接入这台电脑」即可。第一次打开桌面端被系统拦下时，按[下载页的说明](/apps#download)打开。

接好后，桌面端在后台下载 AI 队友在这台电脑上要用的程序，对话框里显示进度。点「完成」后下载照常继续，AI 队友第一次在这台电脑上工作时不用再等它。

## 让芝士改用这台电脑 {#use}

芝士在哪台电脑上工作，按每位 AI 队友设置：换一位不影响别的队友。

1. 打开项目的频道「综合」，点频道顶部右侧的成员头像，打开成员名册。
2. 在芝士那一行点「改」，打开「芝士 的环境」。
3. 选沙箱规格「团队设备」，芝士就在这台电脑上的沙箱里工作；或者选「指定我的电脑」和这台电脑，芝士直接在这台电脑上运行，不隔离。
4. 点「使用这个环境」。名册里芝士那一行写着新的环境。

以后新加入这个频道的 AI 队友也想用这台电脑时，在名册里把「新 AI 队友的默认环境」改成同样的环境。只想让一个任务用这台电脑时，在任务里改，见[任务的环境](/environment#task-environment)。

## 把数据交给芝士 {#tell}

芝士的环境是「团队设备」时，它在这台电脑上的沙箱里工作：只看得到自己的工作目录，看不到你的其他文件。要让它处理实验数据，先把数据复制进它的工作目录。

1. 在频道中问芝士工作目录的位置：

   ```prompt
   告诉我你在这台电脑上的工作目录的完整路径。
   ```

2. 把实验数据复制到这个目录下的 `data/` 文件夹。
3. 把要做的事交给芝士：

   ```prompt
   我把实验数据放进了你工作目录下的 data/ 文件夹。只读取、不修改这些文件，统计每个文件有多少行，结果写到 results/summary.csv。
   ```

芝士在你的电脑上运行，不产生算力费用；芝士调用模型照常消耗额度，见[额度](/quota#compute)。

团队管理员可以给芝士选「指定我的电脑」，不用复制数据：在名册里芝士那一行点「改」，选「指定我的电脑」和这台电脑。

> [!WARNING]
> 选了「指定我的电脑」，芝士能看到、改动这台电脑上的一切，包括其他 AI 队友的文件；频道里的每个成员都能通过芝士读写这些文件。完整说明见[自有设备上 AI 队友能看到什么](/devices#machine-access)。

## 适合用自己电脑的情况 {#when}

- 文件很大，或者只能留在本地；
- 要用这台电脑上装好的软件或显卡；
- 要访问只有校园网里才连得上的服务。

只是需要 Docker 或系统软件时，不必接入自己的电脑：AI 队友的环境可以选「虚拟机沙箱」，见[两种环境](/environment#kinds)。
