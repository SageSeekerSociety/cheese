## 目标

把「项目 / 工作区 / 顶层页面」这 24 个文件里写死的颜色换成语义 token，让这些页面在深色主题下不再出现白底、黑字、浅灰边框。

这一组覆盖的是新一代知是界面：项目总览、工作区、市场、成员、设备、日历、项目设置——产品主路径。

## 换法（判断依据，不是查找替换）

主力模式是 `rgba(0, 0, 0, α)`——半透明黑，在深色底上等于没画。按 <&docs/design-system.md> §1.3–§1.6 分档：

| 原写法 | 语义 | 换成 |
|---|---|---|
| `rgba(0,0,0,.06~.09)` 边框 | 发丝线 | `var(--line)` |
| `rgba(0,0,0,.10~.15)` 边框 | 较重分隔线 | `var(--line-2)` |
| `rgba(0,0,0,.85)` 文字 | 标题 | `var(--ink)` |
| `rgba(0,0,0,.75~.8)` 文字 | 正文 | `var(--text)` |
| `rgba(0,0,0,.6~.7)` 文字 | 次要文本 | `var(--muted)` |
| `rgba(0,0,0,.01~.02)` 底 | 凹陷区块 | `var(--canvas)` |
| `rgba(0,0,0,.03~.04)` 底 | 悬停 / 内嵌 | `var(--fill)` |
| `rgba(0,0,0,.05~.08)` 底 | 再重一档 | `var(--fill-2)` |
| `rgba(255,255,255,.8)` 毛玻璃底 | 半透明面 | `rgba(var(--v-theme-surface), .8)` |
| `box-shadow: 0 Npx rgba(0,0,0,α)` | 浮层投影 | `var(--shadow-1)` / `var(--shadow-2)` |
| `color="grey-darken-1"` 小图标 | 中性图标 | `color="on-surface-variant"` |
| `color="grey-lighten-2"` 空状态大图标 | 占位提示 | `var(--faint)`（去掉 color 属性，加 `.empty-state-icon` 类） |
| `var(--x, #hex)` 兜底值 | —— | 直接 `var(--x)`（兜底 hex 是死代码） |

## 修掉的三个真缺陷

这三处不是「深色下不变色」，是**本来就坏或深色下会坏**：

1. **`MemberView` 的 96px 大头像在深色下彻底看不见**。底色是 `var(--ink)`（浅色近黑、深色近白），字却写死 `#fff` —— 深色下白底白字，**1.10:1**。改成 `var(--surface)`（--ink 的对面）后：浅色 17.41:1 / 深色 15.35:1。
2. **琥珀开关上的白字两个主题都读不出来**（`WorkspaceView .summon-chip--on`、`MyDevicesView .steps__n`）。琥珀两个主题下都是亮橙，白字对它只有 **2.65:1 / 1.94:1**。改成钉死的深墨 `#23242a`：**5.84:1 / 7.98:1**，两边过 AA。
   - 这里踩了一个坑：我一开始用 `rgb(var(--v-theme-on-primary))`，以为 Vuetify 会按底色推出深墨。**实测推翻了**——`getForeground('#F57F17')` 返回 `#fff`，只有深色的 `#FFA733` 才返回 `#000`，等于浅色侧根本没修。所以改用波次 1.5 在 `RailItem.vue` 里的做法：把墨钉死。
3. **`WorkspaceView` 的 `@` 下拉菜单边框引用了一个全仓不存在的变量** `var(--border, #e0e0e0)`——永远走兜底的浅灰，深色下是一圈亮边。换成 `var(--line)`。
