
## 现在是什么情况

深色模式下**全局外壳白底浅灰字**的问题已经改完，三件事都做了：外壳换语义色、RailItem 的 hex 修掉、补上了拦这类写法的机器闸门。沙箱里能跑的检查全绿。

**还差一步人来做**：深色下的实际观感我没法验证（沙箱渲染不了页面），需要 <@pengwenbo> 打开页面看一眼。另外有 1 个对比度问题需要拍板，见下面「待拍板」。

## 根因（一句话）

不是写死的 `#hex`，是**第二类硬编码：Vuetify 的固定调色板名**——`color="grey-lighten-5"` 恒等于 `#FAFAFA`，两个主题下都不变。它不带 `#`，所以「244 处 hex」那份统计没数到；它在 `<template>` 里，所以波次 1 加的 stylelint 也看不见（stylelint 只解析 CSS）。外壳底色被钉死在近白，外壳里的文字却跟着主题变浅 → 白底浅灰字。

## 改了什么

**① 全局外壳，8 个文件**（`grey-lighten-5` → `background`，`white` → `surface-bright`）

<&frontend/src/App.vue>、<&frontend/src/components/common/Navigation/AppBar.vue>、<&frontend/src/components/common/Navigation/LeftAppRail.vue>、<&frontend/src/components/common/Navigation/MobileAppBar.vue>、<&frontend/src/components/common/Navigation/BottomAppBar.vue>、<&frontend/src/components/common/Navigation/SecondaryNavigation.vue>（prop 默认值）、<&frontend/src/views/user/settings/SettingsSidebar.vue>

**② <&frontend/src/components/common/Navigation/RailItem.vue> 的 4 组 hex**

| 原来 | 现在 | 理由 |
|---|---|---|
| `#e2e4ea` 首页方块底 | `rgba(var(--v-theme-on-surface), 0.12)` | 浅色下算出来 `#E0E1E3`，和原来的 `#E2E4EA` 几乎一样；深色下自动变成 `#2B2C2E`，**方块仍然看得出是方块**（对底色 1.31:1，比浅色的 1.23:1 还清楚一点） |
| 品牌橙黄渐变 `#ff9500→#ffe600` | **保留不变** | 品牌漆，两个主题下就该一样。但把上面的 logo 字形从 `on-primary`（Vuetify 按主题推导，可能翻成白色）钉成固定深墨 `#23242a` → 两个主题下都是 7.0–12.2:1 |
| `#f57f17` 选中环 / 指示条 | `rgb(var(--v-theme-primary))` | 浅色下值完全不变；深色下自动提亮到 `#FFA733`（2.49:1 → 9.42:1） |
| 悬浮提示 `#23242a` / `#fff` | 组件内局部变量 + `[data-theme='dark']` 分支 | 这是**故意反色**的元素（浅色下是深色气泡）。深色下 `#23242a` 会和 `#141517` 页面糊在一起，改成 `#3a3d44` 才浮得起来 |

`LeftAppRail.vue` 里的 `color: #fff` **故意保留**：它的底色是 `avatarColor()` 算的 `hsl(色相,55%,55%)`，两个主题下同一个值，所以上面的白字也不该变。已在代码里写清楚为什么，防止下一个人"顺手修好"它。

**③ 机器闸门**：<&.claude/scripts/check-repo-rules.sh> 加了 Rule 6，拦 `<template>` 属性、class 工具类和 `<script>` prop 默认值里的固定调色板名。带 111 处存量冻结基线 <&frontend/palette-baseline.json>（40 个文件，全是波次 2 的地盘），只拦新增。`--update-palette-baseline` 会**拒绝**把基线调高。

顺带修了一个会让这道闸门形同虚设的问题：<&.github/workflows/repo-guards.yml> 的路径过滤器里**没有 `frontend/**`** —— 而这条规则要拦的改动按定义就是纯前端 diff，不加的话 CI 上根本不会启动。（验收卡的质量闸门走 check.sh，不受这个影响。）

**④ 文档**：<&docs/design-system.md> 新增 §1.2「不带 `#` 的写死颜色」+ 替换对照表 + 第 7 节闸门表；<&.claude/rules/frontend.md> 同步。

## 顺手修的一个 AA 问题

顶部标题栏的 12px 标题，浅色下 **3.68:1**（AA 要 4.5）。原因是 Vuetify 给整条 `v-system-bar` 加了 `opacity: 0.62`。这是**改动前就有的**（旧底色下是 3.70:1），但它落在本任务的验收标准里，所以修了——只改 <&frontend/src/components/common/Navigation/AppBar.vue> 自己，不动色板：把 opacity 还原成 1，文字改用 `on-surface-variant`（就是 `--muted`，本来就该是这一档）→ 浅色 4.81:1 / 深色 7.11:1。
