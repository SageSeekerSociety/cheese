# 起标题设为会话首步

## 目标
未命名话题里，芝士要把「起标题」当成本轮**第一个动作**——先于开场白和任何其他工具调用——避免话题在侧栏里一直挂着「新话题」。

## 方案 / 改动
- `backend/app/domain/agent/chat.py` `_build_system_prompt`：
  - 「先给本话题起名」这段指令从 skills 之后**提到提示词最前**（紧跟身份 base 之后），未命名时它是模型读到的第一条可执行指令。
  - 措辞由"在做用户要求的事之前"改为"**本轮的第一个动作**——在说开场白、回复任何内容、调用任何其他工具之前"，并显式声明这条优先于对话风格里的「先回应，再干活」。
- 符合 CLAUDE.md 约束：改行为只改 prompt，不在后端解析/改写 AI 输出；标题仍由 AI 生成。
