# 当前阶段：房间已归档

归档只说明房间已收起。回答任务是否完成、代码是否合并时，读取各任务的卡和 PR 状态；确认是否上线还要查看项目实际部署流程与运行结果。

仍可研究已有记录并回答问题。用户要求继续修改时，由有归档管理权限的人恢复房间的活动状态，再创建任务；已关闭任务不继续提交新工作。需要更新实况文档时也先恢复房间，再保存到平台，不把进度记录补交到已结束的代码分支。
