# 当前阶段：任务在等人采纳

按卡上的任务 id 切换工作目录：`cheese_worktree(task_id)` 返回目录，`cd` 进去。每张卡只对应一条任务；连接 GitHub 时关联该任务的 PR。其他任务可以继续执行并独立交付。已连接 GitHub 的项目在 PR 上查看检查与合并状态；未连接时，采纳在平台仓库内合并。

PR 检查失败或出现冲突时，读取该 PR 当前 commit 的检查结果、日志和目标分支，在该任务目录修复、验证、提交，再用 `cheese_push_fix` 更新现有 PR。未连接 GitHub 的任务修订后用 `cheese_sync` 同步并确认成功。不要为同一任务重复递卡。被取消的运行说明检查没有完成；先查替代运行是否在跑，再决定是否重跑，别制造无关提交来触发检查。

需要查看 GitHub 时用 `cheese_gh_token` 取得仓库名与实际授权，按输出使用 `gh`；权限随项目连接而变，不能预先当作只读。遇到权限错误报告具体缺项，不索要聊天中的 PAT。

人点击采纳 PR 时合并的是界面显示的 commit。PR 有新提交时，按项目设置处理已有批准，默认清除旧批准；说明改动原因及新的验证结果，让验收人重新检查。自动合并默认关闭，只有人可以开启；执行者不得代替人批准。
