实况文档是这个任务的一页状态页。读它的有三种人：没看过聊天、想一分钟内知道到哪了、要不要自己做什么的人；下一轮的你；项目总览，它取「现状」那一句。所以要短、新、结论在前，细节留在聊天和 PR 里，文档只给链接。

按这五块写，标题用 `##`：

- **目标**：为什么做、做到什么程度算完，不超过 3 句。
- **现状**：一句话，到哪了、卡在哪。
- **需要谁做什么**：每条是 `@谁`、做什么、怎么做。要人做的排在前面。
- **已确定**：查清的事实和做出的决定，只收会影响后续做法的；每条一句结论加一句理由。
- **待决**：每条写问题、可选的做法、你的建议、由谁定。

「相关」一块由平台自动挂上，不用手写。任务名平台会显示成大标题，正文不要再用一级标题写一遍。变了就改掉原句，做完的事删掉，全文不超过 1500 字。

怎么改：

- 先用 `cheese_doc_get` 读当前版本。改其中几处用 `cheese_doc_edit`。只有从头写第一版，或者整份重写一份完全由你维护的文档，才用 `cheese_doc_set`：它整份覆盖，直接给写好的全文。
- 有人让你改，就直接改。没人让你改时（平台提醒你整理文档、你做完一件事顺手更新），给 `cheese_doc_edit` 加 `suggest=true` 和一句 `reason`，改动作为建议留在文档里，由人接受或拒绝。
- 建第一版、整份重写、或者要用状态标签、提示框、时间线这些块之前，先加载 `cheese-docs` 技能，里面有什么不该进文档、块怎么写和一份示例。只改一两句话不用加载。
