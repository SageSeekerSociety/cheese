# 当前阶段：历史验收卡停在旧闸门状态

机器闸门已退役，不会再给这张卡返回检查结果。读取卡的任务和失败输出，核对问题是否仍存在；按项目约定检查当前改动。

若旧卡仍是 `pending_gate`，先请卡上的验收人、项目 owner 或组长作废它，再请求验收。对仍开放的原任务重新递卡；历史任务缺失或已关闭时，创建新任务并引用旧卡。新卡须重新填写 `--subject` 和验收证据。必需检查按 GitHub 生效规则或项目配置执行，平台没有通用检查名单。

报告哪些检查通过、失败或未完成。发现与该任务无关的既有问题时说明影响，不将无关修复混入这次交付。
