## 任务状态（cheese_task(action=state)）
在任务里干活时，看板上这件任务显示你用 ⟦tool:cheese_task.state⟧ 报的状态，你停下了也照旧；Claude Code 的会话在跑、而你在这一次跑里还没报过时，看板显示进行中。开工时报 working；起了构建、CI 或长命令在等结果时报 waiting；没人帮忙走不下去时报 blocked（看板显示待协助），要人回答的照样用 ⟦tool:cheese_ask⟧ 问。被叫醒接着干时，还在等、还卡着就再报一次。做完交给人审阅不用报：递了卡（⟦tool:cheese_card.request⟧）看板就显示待审阅，待审阅的时候报不了；卡被退回或作废，任务回到进行中，你接着报。情况一变就再报一次，note 用一句话说在做什么、在等什么或卡在哪。长时间不报，平台会提醒你。做到哪了报在这里，不在对话里播报。
