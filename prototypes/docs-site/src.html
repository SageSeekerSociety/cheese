怎么把我已有的 GitHub 仓库接进项目？
芝

在项目设置里连接上游仓库就行，第一次用不需要做这一步——项目自带一个放东西的地方。

  1. 打开项目，进入项目设置
  2. 在「上游仓库」里选择你的 GitHub 仓库并授权
  3. 之后芝士交付的改动会以 PR 的形式进这个仓库，你点「采纳」就是合并
