# 空间与题目 {#spaces}

空间是老师或组织发布题目的地方，一个空间里有公告、题目和讨论区。你可以领取空间里的题目，按要求提交；也可以从题目直接建一个项目，和芝士一起完成。

## 加入空间 {#join}

加入空间需要空间创建者给你的邀请码或课程链接。

1. 登录后打开「我的工作」，在顶部「我加入的空间」一排点击「用邀请码加入」。
2. 填入「邀请码」，点击「加入」。

加入后，这个空间会出现在「我加入的空间」一排里，点击即可进入。收到的是课程链接时直接点开即可，见[课程与作业 · 加入课程](/courses#join)。

## 找到题目 {#find}

进入空间后，左侧栏的「全部题目」列出空间里的所有题目，可以按分类筛选，也可以用顶部的「在当前空间中搜索」。「我参与的题目」只列你已经领取的题目。

打开一道题目，顶部依次是「概览」「参与者」「提交记录」「提交」几个页签。「概览」里写着：

- 题目详情，有时附一段 Bilibili 视频
- 提交类型：「个人任务」或「团队任务」
- 难度等级、提交次数（「可多次提交」或「仅可提交一次」）、人数或队伍数量限制
- 报名截止时间和默认提交期限

## 领取题目 {#claim}

在题目顶部点击「领取题目」。

有些题目领取前有条件，不满足时「概览」顶部会说明原因：

| 提示 | 怎么办 |
|---|---|
| 此题目需要提供实名信息才能参与 | 点「前往填写」补全实名信息 |
| 您需要创建或加入一个团队才能参与此题目 | 团队任务要以团队身份领取，先建团队或加入别人的团队，见[团队](/teams#teams) |
| 此题目要求团队最少 / 最多 N 人 | 调整团队人数 |
| 该题目参与名额已满 | 这道题不能再领取了 |

如果发布者设置了审核，领取后要等发布者在「参与者」里通过申请。通过后，题目顶部的按钮会变成「前往提交」。

## 从题目创建项目 {#project}

想和芝士一起完成题目，在「概览」的「项目」一栏点击「从这道题目创建项目」。项目建好后自带一个话题和芝士，你可以直接在话题里说明要做什么，见[快速开始](/quickstart#talk)。

这一栏会列出已经从这道题目建出来的项目，不会重复建。

## 提交 {#submit}

完成后点击「前往提交」，按题目要求填写并上传。详细说明见[提交](/submit#submit)。

## 发布题目 {#publish}

空间的管理员可以发布题目。

1. 在「全部题目」页点击「发布题目」。
2. 选择一个题目模板，或点「从空白题目开始」。
3. 填写「基本信息」：题目名称、参与者类型（个人或团队）、题目难度、人数或队伍数量限制。团队题目还要选「队伍成员锁定策略」：「允许自由调整」或「审核通过后锁定」。
4. 填写「时间设置」：报名开始日期、报名截止日期、领取后的「默认完成期限」。
5. 按需开启「要求参与者提供实名信息」，或在「权限设置」里用域名组限制只有指定邮箱域名的用户能看到。
6. 填写「题目描述」，点击「提交」。

题目要经过空间管理员在「审核题目」里通过后才对参与者可见。未通过时，题目「概览」顶部会显示「您的题目未通过审核」和驳回理由。

有 PDF 题目时，可以用「快速发布」：上传题目 PDF（不超过 15MB），系统会解析出题目草稿，统一填写发布参数后批量发布。

## 管理参与者 {#participants}

题目的「参与者」页按「待审核」「已通过」「已驳回」筛选申请。对每个申请可以「通过」或「驳回」（驳回时可填写原因），也可以「设置截止时间」、「查看提交」。

## 新建空间 {#create}

在空间列表页点击「新建空间」，填写「空间名称」和选填的简介、头像，点击「提交审核」。新建的空间默认就是课程空间，你是它的教师和创建者。

提交后要等平台管理员审核。通过后，空间会出现在探索列表中，页面上会给出这个空间的邀请码，发给要邀请的人即可。

空间的邀请码可以在左侧栏「设置」→「邀请码」里管理：「生成新码」时可以设定「可用次数」和「有效期至」。
