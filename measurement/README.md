# 首提交至首次递卡：第一版测量

这份切片只测量，不递验收卡、不合并，也没有开始耗时优化。

## 口径

- 样本：原报告的 124 条建线中，90 条有首次递卡。
- 截止：2026-10-14 08:31:00Z。
- 旧冻结缓存已随机器回收丢失；数据按原命令重取。
- 08:28:09.669Z 至 08:31:00Z 没有新增验收卡。
- 原报告首提交至首次递卡合计保留为 9717.9495743 分钟，四舍五入为 9718 分钟。

原 cohort 和重取说明在 `source/`。平台阶段证据在 `platform-v2/`，GitHub 检查快照在 `ci/`；这些脱敏快照不随代码提交。`report/combined-evidence.json` 是合并后的脱敏证据包。

含重叠列不能相加。CI 运行不等于等待 CI；缺少起点或终点的记录不补成等待。审查一行的零表示没有可计入的完整观测，不是审查没有耗时。后台审查完整起止、纯等待、模型思考时长均拿不到。

6802 条观察没有可信完整起止，其中包含 69 条结束早于开始的检查记录；原时刻保留在 `report/anomalies.json`。调用起点是平台记录的工具调用时刻，返回点是平台最后收到输出的时刻，不是进程的真实退出时刻。

采集覆盖 90 条任务的历史页，共 43,980 条调用记录，以及 5,219 条检查运行记录。只识别简单命令；带引号、复杂脚本、混合命令保守归入其他工具。PR 当前提交列表不能找回被强推移除的历史提交；API 查询完成不等于历史记录完整。

显式等待命令的 717.54 分钟含与 CI 等活动重叠的时间，不能全算可节省耗时。47.41% 未知且其他工具仍未细分，目前不能给出最大可控瓶颈的可靠排序。
